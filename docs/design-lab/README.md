# معمل التصميم — نماذج مرئية قبل أي كود إنتاجي

> **الحالة: غير إنتاجي.** ملفات HTML ساكنة للمعاينة والاعتماد فقط — لا تُستورد في `web/`، ولا تلمس الاختبارات، ولا تُبنى مع التطبيق.
>
> **البروتوكول:** نماذج → عيون المالك → اعتماد اتجاه → W0 يحوّله إلى رموز تصميم → الموجات تنفّذ. (التفويض والبوابات: الأطلس §١٧)

## الدفعة الأولى — غرفة الدرس (قلب التجربة)

| الملف | الاتجاه | الوصف |
|---|---|---|
| `01-lesson-room-day.html` | أ — «نهار دافئ» | ورقي كريمي + أخضر مصري + نحاسي — حرارة تعليمية |
| `02-lesson-room-night.html` | ب — «ليل فخم» | داكن `#0A0908` + ذهبي `#D9A95C` + خط `IBM Plex Sans Arabic` — لغة عائلة الفاروق حرفيًا |

**نفس الشاشة ونفس المحتوى في الاتجاهين — الهوية فقط تتغيّر** (مقارنة نقية).

## ما الذي يعرضه النموذج (الرؤية المعتمدة)
- ترويسة مضغوطة + شريحة تقدم («الخطوة ٢ من ٥»)
- شريط المعلّم الحيّ (حالة «يشرح الآن» + زر استمع)
- **سبورة المعلّم** — بديل «مسرح الكتاب» (مبدأ §١٥: لا عرض للكتاب): شرح + رسم + أدوات قلم/ممحاة
- **شريط المرجع:** «كتابك — صفحة ٦/٧» — إشارة لكتاب الطالب الورقي
- فقاعات المعلّم + شريط المعرفة أسفل كل رد (يستند إلى المنهج · كتابك صفحة ٦/٧ · استمع)
- أزرار «فهمت / مش فاهم»
- مُدخل: نص + **صوّر صفحتك** (الطالب يصوّر كتابه بنفسه) + صوت

## أرقام توضيحية
الدرس «خواص الجمع» (الصف السادس — الإبدال/التجميع من المنهج الفعلي)، والأرقام وأرقام الصفحات توضيحية للنموذج.

## القرار المطلوب من المالك
1. أي اتجاه يمثل «سلاح الفرعون»؟ (أ / ب / مزيج)
2. أي عنصر تريد تعديله أو إضافته قبل W0؟

## بعد الاعتماد
W0 (الأساسات) يحوّل الاتجاه إلى رموز تصميم (ألوان/خطوط/مسافات/حركة)، ثم W1+ تنفّذ الشاشات — مع لقطات قبل/بعد في كل موجة.
