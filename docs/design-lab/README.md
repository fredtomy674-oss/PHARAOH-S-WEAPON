- الخط: `IBM Plex Sans Arabic` (+ `Space Grotesk` للاتيني) — نفس خطوط المنظومة
- الذهبي أساسي: الهوية، الأزرار، فقاعات الطالب، الشارات — والأخضر لمسة دلالية محدودة
- كل الألوان محققة تباين WCAG على الخلفية الداكنة: ذهبي ≈9.3:1 · أخضر ≈10:1 · حبر ≈16.8:1 (AA/AAA)
