# معمل التصميم — نماذج مرئية قبل أي كود إنتاجي

> **الحالة: غير إنتاجي.** ملفات HTML ساكنة للمعاينة والاعتماد فقط — لا تُستورد في `web/`، ولا تلمس الاختبارات، ولا تُبنى مع التطبيق.
>
> **البروتوكول:** نماذج → عيون المالك → اعتماد → W0 يحوّله إلى رموز تصميم → الموجات تنفّذ. (التفويض والبوابات: الأطلس §١٧)

## ✅ القرار المعتمد (المالك — 2026-10-16)

**الهوية البصرية = هوية الفاروق بالضبط، بلا أي ألوان جديدة، والذهبي هو اللون الأساسي.**

- الأساس: `#0A0908` داكن + ذهبي أساسي `#D9A95C` (وعميق `#B98A41`) + حبر فاتح `#F0EBE2` + هامد `#9AA69D`
- الخط: `IBM Plex Sans Arabic` (+ `Space Grotesk` للاتيني) — نفس خطوط المنظومة
- الذهبي أساسي: الهوية، الأزرار، فقاعات الطالب، الشارات — **لا أخضر ولا أي لون خارج العائلة**
