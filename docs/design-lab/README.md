- **الألوان:** `#0A0908` داكن + ذهبي أساسي `#D9A95C` (وعميق `#B98A41`) + حبر فاتح `#F0EBE2` + **هامد فاتح `#B3BDB4`**

  - **`IBM Plex Sans Arabic`** للواجهة (اللافتات، الأزرار، الشرائح، المُدخل) — هوية العائلة

- **وضعا العرض (مبدّل حرّ للطالب):**
