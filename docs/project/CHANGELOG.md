- PHASE 148 — Comprehensive avatar "life" layer: the avatar no longer only blinks and sways. New `web/src/avatar/lifeLayer.ts` is a purely functional, deterministic motion layer (same instant ⇒ same pose, so it unit-tests in node) that is *additive on the explicit state* — it never invents a mood, and silence stays silence. Each frame it layers breathing (~3.8 s, chest/shoulders), body sway (~5.2 s) and a slow weight shift (~9 s, hips/spine); head/neck/eye micro-life from bounded deterministic noise with independent per-axis seeds plus a small gaze drift on the eye bones; and per-state gestures (a nod for correct, a soft tilt for partial, a gentle head shake for incorrect, an occasional attentiveness nod while listening, a light hand beat while speaking — only on the known Z axis, never the unverified elbow axis).
