**الأولوية القصوى:** إضافة باقي الصفوف الدراسية من ملفات PDF الموجودة.

### خطة التنفيذ خطوة بخطوة

1. **الصف الثاني الإعدادي الترم الأول (G8 T1)** – البدء بـ **الرياضيات** أولاً كنموذج
   - استخراج TOC (جدول المحتويات) من PDF
   - تحديد `BOOK_TO_PDF_OFFSET` من الفوتر
   - استخراج المفاهيم (نواتج/أهداف الدرس) بالترتيب المطبوع
   - إنشاء ملف Spec: `server/src/db/egyptMathG8T1.ts` بنمط G9/G7
   - توليد ملفات OCR في `server/data/curriculum-ocr/math-g8-t1/`
   - ربط في `seed.ts` مع أكواد `l-g8-math-*`
   - التحقق: `isConsistent()` + `assertTreeMatchesTheBook()`

2. **بعد نجاح رياضيات G8 T1 كاملًا** – تكرار نفس القالب لباقي مواد G8 T1 (عربي، إنجليزي، علوم، دراسات، تربية دينية، ICT...)

3. **الصف الثالث الإعدادي الترم الأول (G9 T1)** – استكمال حسب الحاجة

4. **الثانوي** – بعد استقرار الإعدادي

### مبادئ أثناء التنفيذ

- **صف واحد ينجح كاملًا أولاً** قبل الانتقال للصف التالي
- **نأخذ من PDF مباشرة** (مصدر الحقيقة الرسمي)
- **نحافظ على الترتيب المطبوع** للمفاهيم
- **نستخدم نفس النمط الموجود** للـ specs + OCR + تحقق
- **نتحقق من `npm run check`** قبل أي انتقال
- **نبقى ملتزمين بـ «لا نخمن أبدًا»** في أي تعديل مستقبلي
