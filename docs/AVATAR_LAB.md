# مختبر الصورة الرمزية (Avatar Lab) — Phase 1

صفحة اختبار معزولة لمعلم AL FAROUQ البشري (VRM ثلاثي الأبعاد). لا تمس الدرس ولا الصوت ولا المناهج.

## التشغيل

```bash
# التطوير (الصفحة تُخدم دائمًا في وضع التطوير للاختبار)
npm run dev --workspace web
# → http://localhost:5173/avatar-lab.html

# بناء يتضمن المختبر (للمختبِر فقط)
VITE_AVATAR_LAB=1 npm run build --workspace web

# بناء الطلاب العادي (بدون أي أثر للأفاتار)
npm run build --workspace web
```

## التعطيل والإزالة (Rollback)

1. الإيقاف الفوري: أعد البناء بدون `VITE_AVATAR_LAB=1` — حزمة الطلاب لا تتغير إطلاقًا.
2. الإزالة الكاملة: احذف `web/avatar-lab.html` + `web/src/avatarLabMain.tsx` + `web/src/avatar/` + كتلة `build.rollupOptions` من `web/vite.config.ts`، ثم `npm install --workspace web` بعد إسقاط الاعتماديات الثلاث من `web/package.json`.

## النموذج والترخيص

- **نموذج مرفق واحد:** `web/src/avatar/assets/egyptian-teacher.vrm` (نموذج VRM 1.0 عيّني منشور من pixiv Inc.).
- الترخيص موثّق في السجل (`src/avatar/characterRegistry.ts`) من داخل بيانات VRM المدمجة نفسها:
  - المؤلف: `pixiv Inc.` · حقوق النشر: `(c) 2022 pixiv Inc.`
  - `licenseUrl`: https://vrm.dev/licenses/1.0/
  - `commercialUsage: corporation` (استخدام تجاري بواسطة شركة مسموح)، `avatarPermission: everyone`
  - `allowRedistribution: true` (إعادة التوزيع مسموحة)، `modification: allowModificationRedistribution` (التعديل وإعادة التوزيع مسموحان)
  - `creditNotation: unnecessary` (لا يلزم ذكر المصدر)
- **ملاحظة سياق:** بيانات VRM تسمح أيضًا ببعض الاستخدامات (عنف/جنس مبالغ)؛ المنصة تستخدم النموذج في سياق تعليمي محايد فقط ولا تروّج لذلك. لا تُعدّل بيانات ترخيص ملفٍ لجهة خارجية.
- **الاستبدال المستقبلي:** شخصية «المعلمة المصرية» المخصّصة تستبدل الملف + خانتَه في السجل دون أي تغيير في العارض (الملف مُشار إليه من السجل فقط).
- **الاستيراد:** الملف يُحمَّل عبر `import ... ?url` داخل رسم وحدة المختبر فقط، فلا تدخل بايتاته في حزمة الطلاب إطلاقًا. زر اختيار ملف `.vrm` يستبدله محليًا دون حفظ في المستودع.
- **لا ترخيص مجهول:** أي نموذج بترخيص مجهول مرفوض؛ لا يُضاف إلا بعد تسجيل المصدر ونص الإذن و`commercialUse: "verified"`.

## المظهر (تعديل مشروع مسموح)

الترخيص يسمح بالتعديل وإعادة التوزيع، فطُبِّق مظهر «المعلمة المصرية» على النموذج الأساسي في طبقتين:

1. **إعادة تلوين مدمجة في الملف** (`assets/egyptian-teacher.vrm`): بشرة دافئة/زيتونية، شعر أسود، قميص كريمي، بنطال كحلي. تمت بأداة لمرة واحدة (canvas) ثم أُعيد تجميع GLB — لا مكتبة صور جديدة، ولا مكتبة وقت التشغيل.
2. **الحجاب** (`src/avatar/teacherLook.ts`): جسم هندسي مُولَّد (قبّة بفتحة بيضاوية للوجه + عباءة كتف بحاشية مطويّة) بلون بنفسجي هادئ، مُقاس من حدود وجه النموذج نفسه، ويُخفي مواد الشعر. لا أصل خارجي ولا ترخيص إضافي.

الناتج **تقريب فني بأسلوب كرتوني**، لا نموذج ثلاثي الأبعاد احترافي؛ الشخصية المخصّصة تحدّثه لاحقًا عبر استبدال الملف + خانته في السجل (وقد تُزال طبقة الحجاب الهندسية إن كانت مدمجة في النموذج الجديد).

## ما يختبره المختبر (وما لا يدّعيه)

| الاختبار | المصدر | الادعاء |
|---|---|---|
| مزامنة الفم — صوت الخادم | `fetchSpeechAudio` لردّ موجود + محلل Web Audio | حركة الفك على المظروف الحقيقي |
| مزامنة الفم — الميكروفون | صوت المختبر نفسه عبر المحلل | إثبات خط الحركة من إشارة حقيقية، بلا TTS |
| أصوات المتصفح ar/en/fr/de/it | `speechSynthesis` على الجهاز | **تقريبي فقط** (حدود الكلمات) + توثيق غياب الصوت |
| الحالات السبع | أحداث صريحة | لا استنتاج مشاعر من الصمت |
| FPS + fallback | عدّاد + `LOW_FPS_THRESHOLD` | إرشادي على جهاز التطوير، لا ضمان هاتف |

## الحدود المعروفة (ليست عيوبًا خفية)

- حركة الفم **سعة-مبنية** (amplitude)، ليست تمييز أصوات دقيقة (phonemes) — خيار مرحلة مقصود (لا مزود جديد).
- الإيطالية **غير مدعومة في المنتج** (لا `it` في الـtutor/voice) — زر المختبر استطلاعي فقط.
- لم يُختبر على هاتف حقيقي ولا قياس ذاكرة ميداني بعد.
- العرض الحي جرى بنموذج VRM 1.0 مرخّص (النموذج المرفق)؛ تبديل النموذج المخصّص لا يغيّر خط الأنابيب.
