LESSON 2
Changing Place Values

Learning Targets
• I can explain how the value of a digit changes as it moves to the left in a number.
• I can describe the patterns I see as a digit changes value.

ACCESS
Multiplying by Ten Use your Tens rods to explore patterns in multiplying by 10.
1. What quantity is represented by your Tens rods? Draw a picture, write an equation, or write a number to show the quantity.
2. What quantity is represented by your group’s Tens rods? Draw a picture, write an equation, or write a number to show the quantity.

BUILD
What Is My Value? Follow the steps to explore how a digit’s value changes when its location changes.
• Choose one digit and enter it in the Ones place.
• Record the value of the digit.
• Continue moving the digit card to the left on the place value chart, recording its new value each time.
