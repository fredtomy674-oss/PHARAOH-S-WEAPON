أَتَذَوَّقُ المَسْمُوعَ، وَأَنْقُدُهُ

أ أُصَنِّفُ الجُمَلَ الآتِيَةَ إِلَى حَقِيقَةٍ أَوْ رَأْيٍ، كَمَا هُوَ مُوَضَّحٌ بِالجَدْوَلِ:

| الجُمْلَةُ | حَقِيقَةٌ | رَأْيٌ |
| :--- | :---: | :---: |
| ١. الذَّكَاءُ الاصْطِنَاعِيُّ يَعْتَمِدُ عَلَى البَيَانَاتِ وَالمَعْلُومَاتِ. | ✓ | |
| ٢. العُقُولُ وَالمَوَاهِبُ تَخْتَلِفُ مِنْ إِنْسَانٍ إِلَى آخَرَ. | | |
| ٣. الإِنْسَانُ يَمْتَلِكُ تَجَارِبَ وَمَشَاعِرَ وَآمَالًا وَآلَامًا. | | |
| ٤. الِاخْتِيَارُ السَّلِيمُ هُوَ الَّذِي يَجْمَعُ بَيْنَ الإِمْكَانَاتِ وَالشَّغَفِ بِالتَّعَلُّمِ وَالعَمَلِ. | | |
| ٥. الذَّكَاءُ لَهُ مَجَالَاتٌ مُتَعَدِّدَةٌ (أَدَبِيٌّ، فَنِّيٌّ، رِيَاضِيٌّ، عَمَلِيٌّ). | | |
| ٦. الاكتِفَاءُ بِرَأْيِ الآلَةِ دُونَ تَفْكِيرٍ أَفْضَلُ طَرِيقٍ لِلنَّجَاحِ. | | |

ب أَضَعُ عَلَامَةَ (✓) أَمَامَ مَا يَتَّصِلُ بِالنَّصِّ، وَعَلَامَةَ (✗) أَمَامَ مَا لَا يَتَّصِلُ بِه:

| الفِكْرَةُ | تَتَّصِلُ بِالنَّصِّ | لَا تَتَّصِلُ بِالنَّصِّ |
| :--- | :---: | :---: |
| ١. تَنَوُّعُ العُقُولِ وَالمَوَاهِبِ بَيْنَ النَّاسِ. | | |
| ٢. تَوْظِيفُ الذَّكَاءِ الاصْطِنَاعِيُّ فِي الإِصْرَارِ بِالبَشَرِ. | | |
| ٣. تَعَدُّدُ مَجَالَاتِ الذَّكَاءِ، وَعَدَمُ حَصْرِهِ فِي الدِّرَاسَةِ. | | |
| ٤. تَمَيُّزُ الإِنْسَانِ عَنِ الذَّكَاءِ الاصْطِنَاعِيِّ بِالمَشَاعِرِ والتَّجَارِبِ. | | |
| ٥. التَّشْكِيكُ فِي قُدْرَةِ الإِنْسَانِ عَلَى مُنَافَسَةِ الذَّكَاءِ الاصْطِنَاعِيُّ. | | |

ج أُكْمِلُ الجَدْوَلَ عَلَى ضَوْءِ مَا اسْتَمَعْتَ إِلَيْهِ فِي النَّصِّ:

| مِحْوَرُ المُقَارَنَةِ | العَقْلُ البَشَرِيُّ | الذَّكَاءُ الاصْطِنَاعِيُّ |
