**التَّطْبِيقُ عَلَى نَصِّ (أَغْلَى مِنَ الذَّهَبِ)**

أَقْرَأُ النَّصَّ الإِقْنَاعِيَّ الآتِيَ:

**أَغْلَى مِنَ الذَّهَبِ**
«إِنَّ الأَخْلَاقَ هِيَ الصِّمَامُ الَّذِي يَحْمِي شَبَابَنَا مِنَ الانْزِلَاقِ نَحْوَ المَكَاسِبِ المَادِّيَّةِ الزَّائِفَةِ، وَتُعَلِّمُهُمْ أَنَّ البُطُولَةَ الحَقِيقِيَّةَ لَا تُقَاسُ بِالمِيدَالِيَاتِ، بَلْ بِنُبْلِ المَوَاقِفِ، وَقِيَمِ المُرُوءَةِ وَالشَّرَفِ.
وَمِنْ أَبْرَزِ الأَدِلَّةِ عَلَى ذَلِكَ مَوْقِفُ البَطَلِ مُحَمَّد رَشْوَان فِي مُبَارَاتِهِ التَّارِيخِيَّةِ عَامَ ١٩٨٤م أَمَامَ خَصْمِهِ اليَابَانِيِّ (يَامَاشِيتَا)؛ إِذْ رَفَضَ اسْتِغْلَالَ إِصَابَةِ خَصْمِهِ، مُتَّخِذًا قَرَارًا نَبِيلًا بِتَجَنُّبِ الهُجُومِ عَلَى قَدَمِهِ المُصَابَةِ تَمَامًا. وَمِنْ ثَمَّ، نَالَ المِيدَالِيَّةَ الفِضِّيَّةَ، وَنَالَ مَعَهَا احْتِرَامَ العَالَمِ، كَمَا مَنَحَتْهُ لَجْنَةُ اللَّعِبِ النَّظِيفِ التَّابِعَةُ لِلْيُونِسْكُو جَائِزَةَ الرُّوحِ الرِّيَاضِيَّةِ عَامَ ١٩٨٥م؛ تَقْدِيرًا لِمَوْقِفِهِ النَّبِيلِ.
لِذَلِكَ يَجِبُ عَلَى شَبَابِ اليَوْمِ أَنْ يَتَعَلَّمُوا مِنْ هَذِهِ القِصَّةِ أَنَّ المَبَادِئَ لَا تُبَاعُ مِنْ أَجْلِ انْتِصَارٍ عَابِرٍ، وَأَنَّ الأَخْلَاقَ سِيَاجٌ وَاقٍ يَحْفَظُ صَاحِبَهُ. فَقَدْ تَخْفُتُ أَضْوَاءُ البُطُولَاتِ، وَلَكِنَّ سِيرَةَ هَؤُلَاءِ العُظَمَاءِ تَظَلُّ حَيَّةً فِي وِجْدَانِنَا، وَيَبْقَى بَرِيقُ أَخْلَاقِهِمْ يَزْدَادُ لَمَعَانًا بِمُرُورِ الزَّمَنِ».

أُحَلِّلُ هَذَا النَّمُوذَجَ مُسْتَعِينًا بِالجَدْوَلِ الآتِي:

| العُنْصُرُ | التَّطْبِيقُ فِي النَّصِّ |
| :--- | :--- |
| **عَنَاصِرُ النَّصِّ الإِقْنَاعِيِّ** | |
| القَضِيَّةُ أَوِ الرَّأْيُ | الأَخْلَاقُ أَسَاسُ البُطُولَةِ الحَقِيقِيَّةِ، وَهِيَ أَعْلَى أَثَرًا مِنَ المَكَاسِبِ السَّرِيعَةِ. |
| الحُجَجُ وَالأَدِلَّةُ | مَوْقِفُ مُحَمَّد رَشْوَان حِينَ رَفَضَ اسْتِغْلَالَ إِصَابَةِ خَصْمِهِ، وَنَيْلُهُ احْتِرَامَ العَالَمِ وَجَائِزَةَ الرُّوحِ الرِّيَاضِيَّةِ. |
| التَّرَابُطُ | تَرْتِيبُ الفِكَرِ مَنْطِقِيًّا؛ إِذْ يَبْدَأُ بِتَعْرِيفٍ عَامٍّ عَنْ دَوْرِ الأَخْلَاقِ فِي حِمَايَةِ الشَّبَابِ، ثُمَّ يُقَدِّمُ مُحَمَّد رَشْوَان نَمُوذَجًا حَيًّا، وَيَرْبِطُ قِصَّتَهُ بِمَا يَجِبُ أَنْ يَتَعَلَّمَهُ شَبَابُ اليَوْمِ، مَعَ اسْتِخْدَامِ أَدَوَاتِ رَبْطٍ مُنَاسِبَةٍ، مِثْلَ: (وَمِنْ أَبْرَزِ الأَدِلَّةِ، إِذْ، وَمِنْ ثَمَّ، كَمَا، لِذَلِكَ، فَقَدْ). |
| الخَاتِمَةُ | الدَّعْوَةُ إِلَى التَّمَسُّكِ بِالمَبَادِئِ؛ لِأَنَّ بَرِيقَ الأَخْلَاقِ يَبْقَى حَيًّا فِي وِجْدَانِ النَّاسِ. |
| **أَسَالِيبُ الإِقْنَاعِ** | |
| الإِقْنَاعُ العَقْلِيُّ | عَرْضُ وَاقِعَةٍ تَارِيخِيَّةٍ وَنَتِيجَتِهَا: رَفْضُ اسْتِغْلَالَ الإِصَابَةِ، فَنَالَ التَّقْدِيرَ العَالَمِيَّ. |
| الإِقْنَاعُ الوِجْدَانِيُّ | اسْتِخْدَامُ عِبَارَاتٍ مُؤَثِّرَةٍ، مِثْلَ: (نُبْلِ المَوَاقِفِ، المُرُوءَةِ وَالشَّرَفِ، بَرِيقُ الأَخْلَاقِ). |
| الاسْتِشْهَادُ | الاسْتِشْهَادُ بِمَوْقِفِ مُحَمَّد رَشْوَان فِي أُولِمْبِيَادِ عَامَ ١٩٨٤م، وَجَائِزَةِ الرُّوحِ الرِّيَاضِيَّةِ عَامَ ١٩٨٥م. |

**نَشَاط**
أَكْتُبُ نَصًّا إِقْنَاعِيًّا لِلتَّحْذِيرِ مِنْ مَخَاطِرِ الفَوْزِ الَّذِي يَتَطَلَّبُ التَّخَلِّيَ عَنِ المَبَادِئِ وَالقِيَمِ، مَعَ الِالْتِزَامِ بِعَنَاصِرِ النَّصِّ الإِقْنَاعِيِّ، وَتَنْوِيعِ أَسَالِيبِ الإِقْنَاعِ.
