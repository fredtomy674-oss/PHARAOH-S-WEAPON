أَفْهَمُ المَسْمُوعَ، وَأُحَلِّلُهُ

أ أُرَتِّبُ الْفِكَرَ حَسَبَ وُرُودِهَا فِي النَّصِّ المَسْمُوعِ كَالْمِثَالِ:

| الفِكْرَةُ | تَرْتِيبُهَا (١ - ٢ - ٣ - ٤ - ٥ - ٦) |
| :--- | :---: |
| ١. تَقْدِيرُ خِبْرَةِ الوالِدَيْنِ وَدَوْرِهَا في تَعْزِيزِ التَّفَاهُمِ. | |
| ٢. أَهَمِّيَّةُ احْتِرَامِ الوَالِدَيْنِ فِي القَوْلِ وَالفِعْلِ سواءً عِنْدَ الاتفاقِ أو الاختلافِ. | ✓ (٢) |
| ٣. أَثَرُ التَّفَاهُمِ وَالتَّحَلِّي بِالآدَابِ فِي تَقْوِيَةِ العَلَاقَةِ الأُسَرِيَّةِ وَبِنَاءِ شَخْصِيَّةِ الأَبْنَاءِ. | |
| ٤. التَّعْبِيرُ عَنِ الرَّأْيِ بِأُسْلُوبٍ مُهَذَّبٍ يُرَاعِي مَشَاعِرَ الوالِدَيْنِ. | |
| ٥. اخْتِلَافُ أَسَالِيبِ الوالِدَيْنِ فِي التَّعْبِيرِ عَنِ الحُبِّ مَعَ وَحْدَةِ الهَدَفِ وَالنِّيَّةِ. | |
| ٦. حُسْنُ الاستماعِ إلى الوالدينِ، واختيارُ الوقتِ المناسِبِ للنقاشِ. | |


ب أُجِيبُ عَمَّا يَلِي:

١. بَعْدَ الِاسْتِمَاعِ إِلَى الفِقْرَةِ الأُولَى، بِمَ يُطَالِبُ المُتَحَدِّثُ المُسْتَمِعِينَ؟

٢. «وَمِنْ أَهَمِّ آدَابِ التَّعَامُلِ مَعَ الوَالِدَيْنِ أَيْضًا حُسْنُ الاِسْتِمَاعِ إِلَيْهِمَا». مَا الآدَابُ الأُخْرَى الَّتِي وَرَدَتْ فِي النَّصِّ المَسْمُوعِ؟

٣. بَعْدَ الِاسْتِمَاعِ إِلَى الفِقْرَةِ الرَّابِعَةِ، فِيمَ يَخْتَلِفُ الآبَاءُ؟ وَفِيمَ يَتَّفِقُونَ بِخُصُوصِ تَنْشِئَتِهِم أَبْنَاءَهُم؟

٤. بَعْدَ الِاسْتِمَاعِ إِلَى الفِقْرَةِ الأَخِيرَةِ، مَتَى يَتَحَوَّلُ المَنْزِلُ إِلَى بِيئَةٍ آمِنَةٍ تَسُودُهَا السَّكِينَةُ؟

٥. أُعَلِّلُ: يُفَضَّلُ اخْتِيَارُ وَقْتٍ مُنَاسِبٍ لِطَرْحِ النِّقَاشَاتِ بَيْنَ الآبَاءِ وَالأَبْنَاءِ.


١٦  الوَحْدَةُ الأُولَى : قِيَمٌ تَحْمِي شَبَابَنَا
