تمثيل مكونات الدائرة الكهربية
الكثير من الأجهزة الكهربية من حولك تحتوي على العديد من المكونات المختلفة. يتطلب تصميم وصيانة هذه الأجهزة شكلاً
مبسطًا يبين تركيبها، لذا يلجأ المهندسون إلى التعبير عن هذه المكونات برموز متفق عليها كما هو مبين بالجدول التالي :

| :---: | :---: | :---: | :---: |
| | مفتاح (مفتوح) | + | عمود كهربي |
| | مصباح كهربي | + | بطارية كهربية |
| | أميتر | | مقاومة ثابتة |
| | فولتميتر | | مقاومة متغيرّة<br>( ريوستات ) |
