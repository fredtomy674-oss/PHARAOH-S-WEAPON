نشاط (٣): بناء الفلك
ضع دائرة حول الأشياء التي يحتاجها نوح لبناء الفلك:

نشاط تقييمي:
ضع علامة (✓) أمام الأعمال الجيدة وعلامة (X) أمام الأعمال غير الجيدة:
١- نوح أطاع الله وبنى الفلك. ( )
٢- نوح تكاسل ولم يكمل بناء السفينة. ( )
٣- نوح عمل بجد وإتقان. ( )

شارك أسرتك:
هيا نُصَلِّ معًا:
أشكرك يارب لأنك تحبني وتحفظني.
علمني أن أكون مثل نوح، أطيعك وأعمل بكل اجتهاد وإتقان.
ساعدني أن أكون أمينًا.
