الكمبيوتر وتكنولوجيا المعلومات والاتصالات

مثال ١: تحديد هل الرقم زوجي أم فردي
عزيزي الطالب، نبدأ بمثال بسيط لتوضيح الفكرة.
خطوات التفكير الحاسوبي
١- تفكيك المشكلة
• نحتاج رقم من المستخدم
• نحدد هل يقبل القسمة على ٢ أم لا
٢- التعرف على الأنماط
أي رقم زوجي عندما يكون ← باقي قسمته على ٢ = 0
أي رقم فردي عندما يكون ← باقي قسمته على ٢ ≠ 0
٣- التجريد
• نهتم فقط بـ:
• الرقم
• نتيجة باقي القسمة
٤- الخوارزمية
١. إدخال الرقم
٢. حساب باقي القسمة على ٢
٣. إذا كان = ٠ ← زوجي
٤. غير ذلك ← فردي

الكود
num = int(input('Enter a number: '))
if num % 2 == 0:
    print("Even number")
else:
    print("Odd number")

الشرح
عزيزي الطالب، نلاحظ هنا أننا بدأنا بالتفكير ثم كتبنا الكود، وهذا هو الهدف من التفكير الحاسوبي.
• input() ← إدخال من المستخدم
• int() ← تحويل إلى عدد صحيح
• num % 2 ← باقي القسمة
• == 0 ← هل يساوي صفر؟
• if ← تنفيذ شرط
• else ← في الحالة الأخرى
