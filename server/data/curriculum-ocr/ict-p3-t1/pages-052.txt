١٧ -ما النتيجة المتوقعة للكود التالي؟
def max_number(a, b):
    if a > b:
        return a
    else:
        return b
print(max_number(7, 3))

أ) 3
ب) 7
ج) 10
د) False

١٨ -في برنامج حساب مساحة الدائرة، لماذا نستخدم radius كمعامل؟
أ) لجعل البرنامج أطول
ب) لإنشاء متغير دائم في البرنامج
ج) لجعل الدالة تعمل مع أي قيمة لنصف القطر
د) لطباعة القيمة على الشاشة

١٩ -ما النتيجة المتوقعة للكود التالي؟
def multiply(a, b):
    return a * b
x = multiply(4, 5)
y = multiply(2, 3)
print(x + y)

أ) 15
ب) 23
ج) 26 (20 + 6)
د) 46

أ) جعل البرنامج يحتوي على أسطر أكثر
ب) إنشاء متغيرات عالمية فقط
ج) تجنب تكرار الكود وتنظيم البرنامج وجعله قابلاً لإعادة الاستخدام
د) إزالة الحاجة لاستخدام المتغيرات
