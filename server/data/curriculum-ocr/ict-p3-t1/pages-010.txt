الكمبيوتر وتكنولوجيا المعلومات والاتصالات

المثال ٣: حساب مساحة مستطيل
عزيزي الطالب، نلاحظ هنا الربط بين البرمجة والرياضيات، حيث نستخدم قانونًا معروفًا ونحوله إلى كود.
التفكير الحاسوبي
١- تفكيك المشكلة
• إدخال الطول والعرض
• حساب المساحة
٢- التعرف على الأنماط
• المساحة = الطول × العرض
٣- التجريد
• نهتم فقط بـ: الطول - العرض
٤- الخوارزمية
١. إدخال الطول
٢. إدخال العرض
٣. ضربهما
٤. عرض الناتج
الكود
length = int(input('Enter length: '))
width = int(input('Enter width: '))
area = length * width
print('Area =', area)

الشرح
• length * width ← حساب المساحة
• area ← تخزين النتيجة
• print ← عرض المساحة
