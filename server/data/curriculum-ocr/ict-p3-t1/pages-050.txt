١٠ - أي من الكود التالي يُعرّف دالة بمعامل واحد فقط؟

ب) def multiply()
ج) def square(x)
د) def calc(a, b, c)

١١ - ما النتيجة المتوقعة للكود التالي؟
def greet(name):
    print(“Hello”, name)
greet(“Ahmed”)

أ) Hello
ب) Ahmed
ج) Hello Ahmed
د) name Ahmed

١٢ - ما الخطأ في الكود التالي؟
def add(a, b):
    return a + b
result = add(5)

أ) خطأ في كتابة def
ب) نقص معامل (قيمة واحدة بدلاً من قيمتين)
