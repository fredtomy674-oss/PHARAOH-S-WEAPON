الوحدة الأولى: الذكاء الاصطناعي ولغات البرمجة

المثال ٢: حساب متوسط ٣ أرقام
والآن، بعد أن فهمنا المثال الأول، ننتقل إلى مثال آخر يعتمد على نفس الفكرة.
وهنا نستخدم التعرف على الأنماط لأن طريقة الحل تشبه مسائل أخرى في الرياضيات.
التفكير الحاسوبي:
١- تفكيك المشكلة
• إدخال ٣ أرقام
• جمعهم
• قسمة الناتج على ٣
٢- التعرف على الأنماط
• المتوسط = مجموع القيم ÷ عددها
٣- التجريد
• نهتم فقط بـ: الأرقام الثلاثة - الناتج النهائي
٤- الخوارزمية
١. إدخال ٣ أرقام
٢. جمعهم
٣. القسمة على ٣
٤. عرض الناتج

الكود
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
c = int(input("Enter third number: "))
avg = (a + b + c) / 3
print("Average =", avg)

ملاحظة : لماذا استخدمنا نوع البيان float بدل int عند حساب المتوسط لانه قد يكون عددا عشرياً مثل (85.5) فإذا استخدمنا رمز / في القسمة فإن الناتج يكون نوعه float ، وإذا استخدمنا الرمز // في القسمة فإن الناتج يكون من نوع int.

الشرح
جمع الأرقام ← a + b + c
حساب المتوسط ← / 3
متغير لتخزين النتيجة ← avg
عرض الناتج ← print()
