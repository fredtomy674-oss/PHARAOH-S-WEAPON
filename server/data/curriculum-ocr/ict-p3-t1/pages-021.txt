الوحدة الأولى: الذكاء الاصطناعي ولغات البرمجة

خريطة التدفق
البداية : نقطة انطلاق البرنامج.
إدخال الرقم (num): استقبال القيمة من المستخدم.
اتخاذ القرار (هل 0 < num ؟)
• إذا كانت الإجابة نعم، يتم الانتقال لطباعة رقم موجب (Positive number).
• إذا كانت الإجابة لا، يتم الانتقال لطباعة رقم سالب (Negative number).

رسم خريطة التدفق: الخوارزمية الشرطية - تحديد نوع الرقم
البداية
إدخال الرقم num
هل num > 0 ؟
نعم
طباعة [Positive number]
لا
طباعة [Negative number]
النهاية

num = int(input('Enter a number: '))
if num > 0:
    print("Positive number")
else:
    print("Negative number")

الشرح: إذا تحقق الشرط ← ينفذ - إذا لم يتحقق ← ينفذ البديل
عزيزي الطالب: هذا يشبه اتخاذ قرار في حياتك اليومية، مثل: إذا ذاكرت ← تنجح، وإلا ← تحتاج للمذاكرة أكثر.
