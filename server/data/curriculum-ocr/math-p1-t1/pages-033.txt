استخدام خواص جمع الأعداد النسبية
مثال 2
أوجد ناتج كل مما يلى:
1) -3/5 + 2/15 + 8/5
2) -7/4 + 2/5 + 7/4

1) -3/5 + 2/15 + 8/5 = -3/5 + 8/5 + 2/15 (الإبدال)
= (-3/5 + 8/5) + 2/15 (الدمج)
= 1 + 2/15 = 1 2/15

2) -7/4 + 2/5 + 7/4 = -7/4 + 7/4 + 2/5 (الإبدال)
= (-7/4 + 7/4) + 2/5 (الدمج)
= 0 + 2/5 = 2/5 (المحايد الجمعي)

ثانياً طرح الأعداد النسبية
عملية طرح c/d من a/b هي نفسها عملية جمع العدد a/b مع المعكوس الجمعي للعدد c/d
إذا كان a/b ، c/d عددين نسبيين فإن: a/b - c/d = a/b + (-c/d)

مثال 3
أوجد ناتج كل مما يلى:
1) 2 1/2 - 3 1/4
2) -3 2/3 - 2 5/6
3) 35% - |-3/5|
4) 0.36 - 2/25

1) 2 1/2 - 3 1/4 = 5/2 - 13/4 = 10/4 - 13/4 = -3/4
2) -3 2/3 - 2 5/6 = -3 4/6 - 2 5/6 = -5 9/6 = -5 3/2 = -6 1/2
3) 35% - |-3/5| = 35/100 - 3/5 = 7/20 - 3/5 = 7/20 - 12/20 = -5/20 = -1/4
4) 0.36 - 2/25 = 36/100 - 2/25 = 9/25 - 2/25 = 7/25
