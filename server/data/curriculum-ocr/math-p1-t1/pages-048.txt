إذا كانت A ، B ، C ثلاثة أعداد فإن لهذه الأعداد الخواص الآتية :

1 خاصية الجمع أو الإضافة :
إذا كان : A = B فإن : A + C = B + C
فمثلاً : إذا كان : 3 = 1 + X فإن : 1 + 3 = 1 - X ومنها 4 = X

2 خاصية الطرح أو الحذف :
إذا كان : A = B فإن : A - C = B - C
فمثلاً : إذا كان : 2 + X = 3 فإن : 2 - 3 = 2 - X ومنها 1 = X

3 خاصية الضرب :
إذا كان : A = B فإن : A × C = B × C
فمثلاً : إذا كان : 3 = 1/3 X فإن : 3 × 3 = 3 × 1/3 X ومنها 9 = X

4 خاصية القسمة :
إذا كان : A = B فإن : A/C = B/C (حيث 0 ≠ C)
فمثلاً : إذا كان : 20 = 4X فإن : 20/4 = 4X/4 ومنها 5 = X

خاصية 1
يمكن جمع (أو إضافة) نفس العدد إلى طرفي المعادلة ويبقى الطرفان متساويين.

خاصية 2
يمكن طرح (أو حذف) نفس العدد من طرفي المعادلة ويبقى الطرفان متساويين.

خاصية 3
يمكن ضرب طرفي المعادلة في نفس العدد ويبقى الطرفان متساويين.

خاصية 4
يمكن قسمة طرفي المعادلة على نفس العدد (ما عدا الصفر) ويبقى الطرفان متساويين.

تقييم ذاتي 3

حل المعادلات باستخدام خواص التساوي
مثال 3

إذا كانت مجموعة التعويض : 1 Z 2 N
