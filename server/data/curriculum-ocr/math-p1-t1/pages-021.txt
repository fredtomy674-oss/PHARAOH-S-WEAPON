مفهوم المجموعة
مفهوم المجموعة
المجموعة هي تجمع من الأشياء المعروفة والمحددة تحديدًا تامًا.
هذه الأشياء تسمى عناصر المجموعة، وتكتب داخل القوسين { } دون تكرار ولا يشترط الترتيب.

التعبير عن المجموعة
يمكن التعبير عن المجموعة إما بطريقة السرد أو الصفة المميزة أو شكل فن.
مثال: إذا كانت A مجموعة الأعداد الطبيعية الأقل من 4 فإنه يمكن التعبير عن المجموعة A بإحدى الطرق التالية :

طريقة السرد (القائمة)
A = { 0، 1، 2، 3 }

طريقة الصفة المميزة
A = { X : X ∈ N , X < 4 }
حيث N مجموعة الأعداد الطبيعية
