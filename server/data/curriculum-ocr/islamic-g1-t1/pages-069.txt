نشاط (٥) ضَعْ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ الْعِبَارَةِ غَيْرِ الصَّحِيحَةِ:

١ مَصْدَرُ الرِّزْقِ الْمَذْكُورُ فِي سُورَةِ قُرَيْشٍ هُوَ التِّجَارَةُ. ( )
٢ الرِّزْقُ وَالْأَمْنُ مِنْ أَعْظَمِ نِعَمِ اللَّهِ (تَعَالَى) عَلَى الْإِنْسَانِ. ( )
٣ كَانَتْ رِحْلَةُ قُرَيْشٍ إِلَى الْيَمَنِ فِي الصَّيْفِ. ( )
٤ الْمُرَادُ بِكَلِمَةِ ﴿الْبَيْتِ﴾ فِي سُورَةِ قُرَيْشٍ الْبُرْجُ الْمُرْتَفِعُ. ( )
٥ أَمَرَ اللَّهُ (تَعَالَى) قُرَيْشًا فِي السُّورَةِ الْكَرِيمَةِ أَنْ يَعْبُدُوا اللَّهَ (تَعَالَى) وَحْدَهُ. ( )

شَارِكْ أُسْرَتَكَ
اقْرَأْ سُورَةَ قُرَيْشٍ مَعَ أُسْرَتِكَ.
