الْأَنْشِطَةُ وَالتَّدْرِيبَاتُ

نَشاط (١) ارْسُمْ صُورَةً تُعَبِّرُ عَنْ حُبِّكَ لِأُمِّكَ:

نَشاط (٢) رَتِّبِ الْأَحْدَاثَ التَّالِيَةَ حَسَبَ حُدُوثِهَا:
( ) زِيَارَةُ الرَّسُولِ ﷺ قَبْرَ أُمِّهِ، وَتَأَثُّرُهُ بِتِلْكَ الزِّيَارَةِ.
( ) زِيَارَةُ السَّيِّدَةِ آمَنَةَ قَبْرَ زَوْجِهَا.
( ) عَوْدَةُ النَّبِيِّ ﷺ إِلَى مَكَّةَ مَعَ أُمِّ أَيْمَنَ.
( ) مَرَضُ السَّيِّدَةِ آمَنَةَ وَوَفَاتُهَا.
