(ب) ضَعْ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ الْعِبَارَةِ غَيْرِ الصَّحِيحَةِ:
١ تُعْطَى الزَّكَاةُ لِلْفُقَرَاءِ. ( )
٢ لَا تُقْبَلُ الصَّلَاةُ بِغَيْرِ وُضُوءٍ. ( )
٣ الْمَضْمَضَةُ وَالِاسْتِنْشَاقُ مِنْ أَعْمَالِ الصَّلَاةِ. ( )
٤ صَلَاةُ الْعِشَاءِ رَكْعَتَانِ. ( )
٥ غَسْلُ الرِّجْلَيْنِ آخِرُ أَعْمَالِ الْوُضُوءِ. ( )
