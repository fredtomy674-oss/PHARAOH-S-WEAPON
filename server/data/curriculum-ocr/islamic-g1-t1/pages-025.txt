نشاط (٥) اخْتَرِ الإِجَابَةَ الصَّحِيحَةَ:
١ سُمِّيَ العَامُ الَّذِي وُلِدَ فِيهِ النَّبِيُّ ﷺ بِعَامِ ................................. (الطَّيْرِ - الكَعْبَةِ - الفِيلِ)
٢ أَرَادَ ................................. هَدَمَ الكَعْبَةِ. (أَبْرَهَةَ - عَبْدِ المُطَّلِبِ - عَبْدِ اللهِ)
٣ وُلِدَ النَّبِيُّ ﷺ فِي شَهْرِ ................................. (رَمَضَانَ - رَجَبٍ - رَبِيعٍ الأَوَّلِ)
٤ تُوُفِّيَ ................................. النَّبِيُّ ﷺ قَبْلَ رُؤْيَتِهِ. (عَمُّ - جَدُّ - أَبُو)

نشاط (٦) ضَعْ عَلَامَةَ (✓) أَمَامَ العِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (x) أَمَامَ العِبَارَةِ غَيْرِ الصَّحِيحَةِ:
١ وُلِدَ النَّبِيُّ مُحَمَّدٌ ﷺ فِي المَدِينَةِ المُنَوَّرَةِ. ( )
٢ وُلِدَ النَّبِيُّ مُحَمَّدٌ ﷺ فِي عَامِ الفِيلِ. ( )
٣ عَبْدُ المُطَّلِبِ هُوَ جَدُّ النَّبِيِّ مُحَمَّدٌ ﷺ. ( )
٤ أُمُّ النَّبِيِّ مُحَمَّدٌ ﷺ هِيَ السَّيِّدَةُ آمِنَةُ بِنْتُ وَهْبٍ. ( )

شَارِكْ أُسْرَتَكَ
• تَنَاقَشْ أَنْتَ وَأُسْرَتُكَ، ثُمَّ أَجِبْ عَمَّا يَأْتِي:
١ لِمَاذَا نَفْرَحُ بِيَوْمِ مَوْلِدِ النَّبِيِّ مُحَمَّدٌ ﷺ؟
٢ كَيْفَ يُمْكِنُنَا أَنْ نُظْهِرَ حُبَّنَا لِلنَّبِيِّ مُحَمَّدٌ ﷺ فِي حَيَاتِنَا؟

٢٥
