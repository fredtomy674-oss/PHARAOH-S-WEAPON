نشاط (٢) أَجِبْ عَنِ الْأَسْئِلَةِ الْآتِيَةِ:
١. كَيْفَ يَصِفُ اللَّهُ ﷺ الْمُنافِقِينَ فِي الْآياتِ (١١ : ٢٤) مِنْ سُورَةِ الْحَشْرِ؟
٢. اشْرَحْ مَعْنَى قَوْلِهِ (تعالى): ﴿تَحْسَبُهُمْ جَمِيعًا وَقُلُوبُهُمْ شَتَّىٰ﴾.
٣. مَا مَعْنَى اسْمِ اللَّهِ (الْمَلِكُ الْقُدُّوسُ)؟
٤. وَضْحُ وَجْهَ الشَّبَهِ بَيْنَ الْمُنافِقِينَ وَالشَّيْطانِ كَمَا وَرَدَ فِي الْآياتِ الْكَرِيمَةِ.
٥. مَا النَّصِيحَةُ الَّتِي وَجَّهَهَا اللَّهُ (تعالى) لِلْمُؤْمِنِينَ فِي الْآياتِ الْكَرِيمَةِ؟

نشاط (٣) ضَعْ عَلامَةَ (✓) أَمَامَ الْعِبارَةِ الصَّحِيحَةِ، وَعَلامَةَ (✗) أَمَامَ الْعِبارَةِ غَيْرِ الصَّحِيحَةِ:
١. وَعَدَ الْمُنافِقُونَ يَهُودَ بَنِي النَّضِيرِ بِأَنَّهُمْ سَيَخْرُجُونَ مَعَهُمْ إِذَا طُرِدُوا، وَقَدْ وَفَّوْا بِهَذَا الْوَعْدِ. ( )
٢. عَدَاوَةُ الْيَهُودِ وَالْمُنافِقِينَ فِيمَا بَيْنَهُمْ شَدِيدَةٌ، رَغْمَ أَنَّ الرَّائِيَ قَدْ يَظُنُّهُمْ مُجْتَمِعِينَ. ( )
٣. ضَرَبَ اللَّهُ مَثَلًا بِالْجَبَلِ لِبَيَانِ مَدَى عَظَمَةِ الْقُرْآنِ وَهَيْبَتِهِ وَتَأْثِيرِهِ. ( )
٤. الِاسْتِوَاءُ فِي الْمَنْزِلَةِ حَاصِلٌ بَيْنَ أَصْحَابِ الْجَنَّةِ وَأَصْحَابِ النَّارِ يَوْمَ الْقِيَامَةِ. ( )
٥. مِنْ أَسْمَاءِ اللَّهِ الْحُسْنَى الْوَارِدَةِ فِي الْآياتِ الْكَرِيمَةِ: (الْعَزِيزُ، الْجَبَّارُ، الْمُتَكَبِّرُ) ( )

شَارِكْ بِالِاشْتِرَاكِ مَعَ أَفْرَادِ أُسْرَتِكَ حَدِّدْ مَعْنَى (النِّفَاقِ)، وَكَيْفَ يُمْكِنُ لِلْمُؤْمِنِ أَنْ
أُسْرَتَكَ يَتَجَنَّبَ هَذَا السُّلُوكَ.
