| | إحدَى أخواتها. | خضراءُ. | * الشجرُ : اسمُ إنَّ منصوبُ وعلامة نصبه الفتحة الظاهرة. |
| | | | * أوراقُه : مبتدأ مرفوعٌ وعلامة رفعه الضمة الظاهرة والهاءُ ضمير مضافُ إليه مبنى في محل جر . |
