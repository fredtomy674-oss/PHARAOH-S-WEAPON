الوحدة الخامسة (مرفوعات الأسماء)

(٣) إذا كان الفعل متعديًا لواحد رفع مفعوله على أنه نائب فاعل، وإن كان متعديًا لمفعولين أو أكثر
مثل : ( أُعْطِيَ - مَنَحَ - ظُنَّ ) رفع المفعول الأول على أنه نائب فاعل، وبقى غيره منصوبًا . مثل :
( مُنِحَ الجندىُّ وسامًا ) .
(٤) يجوزُ بناءُ الفعلِ اللازمِ للمجهولِ إذا كانَ نائبُ الفاعلِ جارًا ومجرورًا مثلُ : ( فُرِحَ بنجاحى ) أو
ظرفًا متصرفًا : ( لا يلزمُ النصبَ على الظرفيةِ أو الجرَّ بحرفِ الجرِّ ) مختصًا : ( يفيدُ فائدةً
خاصةً بوصفه أو إضافته ) سُهِرَتْ ليلةٌ ممتعة - جُلِسَ أمامَ الرئيسِ .
(٥) قد يكونُ نائبُ الفاعلِ اسمًا ظاهرًا : مفردًا أو مثنى أو جمعًا ، وقد يكونُ ضميرًا بارزًا متصلًا
مثل : ( نُشِّئْتُ ) على الصدقِ ( الشبابُ نُشِّئُوا على الفضيلةِ ) وقد يكونُ ضميرًا مستترًا مثل :
( الدُّنيا تُؤخَذُ غلابًا ) أى تُؤخَذُ ( هى ) ، ومثلُ : ( الوطنُ يُفدَى بالدماءِ ) أى يُفدَى ( هو ) .
