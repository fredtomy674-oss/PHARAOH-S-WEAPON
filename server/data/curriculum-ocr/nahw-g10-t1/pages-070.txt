الاستنتاج :
(١) تدخلُ كانَ أو إحدى أخواتها على المبتدأ والخبر فترفعُ الأول ويسمى ( اسمها ) وتنصبُ الثاني ويسمى ( خبرها ) ، وتسمى أفعالاً ناسخة ، لأنها تغيرُ حكمَ المبتدأ والخبر أو أفعالاً ناقصة ؛ لأنها لا تكتفي بمرفوعها .
(٢) أخواتُ كانَ ومعانيها :
( كان ) للتوقيتِ في الماضي - وفي مِثْلِ ( كانَ اللهُ غفورًا ) تفيدُ الاستمرارِ ، ( أصبحَ ) للتوقيتِ في الصباح ، ( أضحى ) للتوقيتِ بالضُّحى ، ( ظلَّ ) للتوقيتِ بالنهار ، ( أمسى ) للتوقيتِ
