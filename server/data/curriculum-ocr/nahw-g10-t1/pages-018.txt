تقسيمُ الضميرِ البارزِ إلى : منفصلٍ ومتصلٍ

أولا : الضمائرُ البارزةُ المنفصلةُ
أ للرفع

| الأمثلة | الضمير |
| :--- | :--- |
| (١) أنا مجتهدٌ - أنا مجتهدةٌ. | أنا: للمتكلمِ والمتكلمةِ. |
| (٢) نحنُ مجتهدون أو مجتهداتٌ. أو مجتهدان أو مجتهدتانِ. | نحنُ: للمتكلمِ المثنى والجمعِ بنوعيهما. |
| (٣) أنتَ مجتهدٌ. | أنتَ: للمخاطَبِ المفردِ المذكرِ. |
| (٤) أنتِ مجتهدةٌ. | أنتِ: للمخاطبةِ المفردةِ المؤنثةِ. |
| (٥) أنتما مجتهدان أو مجتهدتانِ. | أنتما: للمثنى المخاطَبِ: مذكرًا ومؤنثًا. |
| (٦) أنتم مجتهدون. | أنتمْ: لخطابِ جمعِ المذكرِ. |
| (٧) أنتنَّ مجتهداتٌ. | أنتنَّ: لخطابِ جمعِ المؤنثِ. |
| (٨) هو مجتهدٌ. | هو: للمفردِ الغائبِ. |
| (٩) هي مجتهدةٌ. | هي: للمفردةِ الغائبةِ. |
| (١٠) هما مجتهدان هما مجتهدتان. | هما: للمثنى الغائبِ: مذكرًا ومؤنثًا. |
| (١١) هم مجتهدون. | هم: لجمعِ المذكرِ الغائبِ. |
| (١٢) هن مجتهداتٌ. | هن: لجمعِ المؤنثِ الغائبِ. |

١٢ القواعد الأساسية للنحو والصرف أم القرى للطباعة
