| الأمثلة | حالةُ الهمزةِ | السببُ |
| :--- | :--- | :--- |
| ١ - إِنَّ اللهَ مع المتقينَ | مكسورةٌ | وقعتْ أولَ الكلامِ |
| ٢ - قالَ : إني عبدُ اللهِ | مكسورةٌ | وقعتْ بعدَ القولِ |
| ٣ - واللهِ إِنَّ الحقَّ منصورٌ | مكسورةٌ | وقعتْ أولَ جملةِ القَسَمِ |
| ٤ - أسكُتُ حيثُ إِنَّ السكوتَ مستحبٌّ | مكسورةٌ | وقعتْ بعدَ حيثُ |
| ٥ - أكرمتُ الذي إِنَّ خلقَه كريمٌ | مكسورةٌ | وقعتْ أولَ جملةِ الصلةِ |
| ٦ - يؤدّي العاملُ واجبَه وإنه مخلصٌ | مكسورةٌ | وقعتْ أولَ جملةِ الحالِ |

الاستنتاجُ :
(١) تُفتح همزةُ ( أَنَّ ) إذا صحَّ أن تؤوَّلَ مع معموليها بمصدرٍ : ( وقعتْ موقعَ المفردِ ) .
(٢) تكسرُ همزةُ (إِنَّ) إذا وقعتْ :
(أ) أولَ الكلامِ . (ب) بعدَ القولِ . (ج) أولَ جملةِ القَسَمِ .
(د) بعدَ حيثُ . (هـ) أولَ جملةِ الصلةِ ( و ) أولَ جملةِ الحالِ

٧٢ القواعد الأساسية للنحو والصرف أم القرى للطباعة
