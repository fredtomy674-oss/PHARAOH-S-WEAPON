٢. أحد الحلول المقترحة لحل مشكلة بطء الحاسب الآلي هو التحقق من الاتصال بالـ Wi-Fi. ( )
٣. دراسة الحلول المقترحة هي الخطوة الثانية من خطوات اكتشاف المشكلات وحلها. ( )
٤. التحقق من الاتصال بالـ Wi-Fi هي أحد الحلول المقترحة في حالة بطء محرك البحث. ( )
٥. أحد الحلول المحتملة لانقطاع الإنترنت هو تغير سلك Ethernet. ( )
٦. يمكنك الاستعانة بمعلمك أو حد أفراد أسرتك إذا لم تتوصل إلى حل للمشكلة. ( )

د. دراسة الحلول المحتملة للمشكلة .

ج. شراء طابعة
د. شراء شاشة
