13-6 عرض تقديمي لموقع الويب
النقاط الرئيسية
في هذا الدرس، سنقوم بتقديم عرض تقديمي حول موقع الويب الذي أنشأته في الحصة السابقة أمام زملائك.
تحدي معلوماتك
لخص محتوى العرض التقديمي لموقع الويب الذي أنشأته في الدرس السابق بناء على النقاط التالية:
1) ما هو موضوع موقع الويب؟
أمثلة:
موقع ويب حول هواياتي الخاصة.
موقع ويب حول كرة القدم.
2) ما تعلمته حول HTML
أمثلة:
يمكن تضمين CSS و JavaScript داخل HTML باستخدام الوسمين <link> و <script>.
يمكن التحكم في الوسم <button> باستخدام JavaScript عن طريق تعيين id له.
3) ما تعلمته حول CSS
أمثلة:
يمكن تعيين لون الخلفية باستخدام body.
يمكن إعداد لون الزر والرسوم المتحركة (Animation) باستخدام button.
4) ما تعلمته حول JavaScript
أمثلة:
يمكن تحديد العناصر مثل الأزرار أو النصوص داخل HTML باستخدام document.getElementById.
يمكن كتابة الإجراءات التي تحدث عند الضغط على الزر باستخدام addEventListener.
جرب بنفسك
اعرض المحتوى الذي قمت بتلخيصه على أفراد مجموعتك.
