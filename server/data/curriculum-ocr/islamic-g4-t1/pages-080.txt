نشاط ٤ اِذْكُرْ حُكْمَ الزَّكَاةِ فِي الْأَمْوَالِ الْآتِيَةِ:

| الْمَالُ | يَجِبُ فِيهِ الزَّكَاةُ | لَا يَجِبُ فِيهِ الزَّكَاةُ |
| :--- | :--- | :--- |
| حُلِيٌّ تَتَزَيَّنُ بِهِ الْمَرْأَةُ | | |
| عُمْلَاتٌ نَقْدِيَّةٌ مُدَّخَرَةٌ فِي الْبَنْكِ | | |
| قَمْحٌ مَحْصُودٌ لِلْبَيْعِ | | |
| بَيْتٌ لِلسَّكَنِ | | |
| بَيْتٌ لِلِاسْتِثْمَارِ | | |

نشاط ٥ صَمِّمْ بِطَاقَةً تَذْكُرُ فِيهَا الْمُسْلِمِينَ بِالْحِكْمَةِ مِنَ الزَّكَاةِ:

شَارِكْ أُسْرَتَكَ
• بِالتَّعَاوُنِ مَعَ أُسْرَتِكَ ابْحَثْ عَنِ الْآيَاتِ الَّتِي تَحَدَّثَتْ عَنِ الزَّكَاةِ فِي الْقُرْآنِ الْكَرِيمِ، ثُمَّ تَنَاقَشُوا حَوْلَهَا.
