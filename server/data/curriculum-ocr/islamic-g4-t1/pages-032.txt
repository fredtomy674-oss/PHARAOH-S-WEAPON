الْأَنْشِطَةُ وَالتَّدْرِيبَاتُ

نَشاط 1 ضَعْ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ الْعِبَارَةِ الْخَطَأِ:
1 إِكْرَامُ الضَّيْفِ يَقْتَصِرُ عَلَى تَقْدِيمِ الطَّعَامِ فَقَطْ. ( )
2 جَعَلَ الْإِسْلَامُ الْكَرَمَ عِبَادَةً يَتَقَرَّبُ بِهَا الْعَبْدُ إِلَى اللهِ (تَعَالَى). ( )
3 كَانَ الْعَرَبُ قَبْلَ الْإِسْلَامِ لَا يَعْرِفُونَ قِيمَةَ إِكْرَامِ الضَّيْفِ. ( )
4 إِكْرَامُ الضَّيْفِ سُلُوكٌ غَيْرُ ضَرُورِيٍّ فِي الْإِسْلَامِ. ( )
5 لَيْسَ مِنَ الضَّرُورِيِّ إِظْهَارُ فَرَحِنَا بِزِيَارَةِ ضُيُوفِنَا. ( )
