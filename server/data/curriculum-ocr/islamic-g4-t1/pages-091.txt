مُرَاجَعَةٌ عَلَى الْوَحْدَةِ الثَّالِثَةِ

ضَعْ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ الْعِبَارَةِ غَيْرِ الصَّحِيحَةِ:
١ الرَّسُولُ هُوَ مَنْ أَرْسَلَهُ اللَّهُ (تَعَالَى) بِشَرْعٍ جَدِيدٍ وَأَمَرَهُ بِتَبْلِيغِهِ لِلنَّاسِ. ( )
٢ تَشْمَلُ أَنْوَاعُ الزَّكَاةِ الْمَالَ وَالزُّرُوعَ وَالثِّمَارَ فَقَطْ. ( )
٣ وَثِيقَةُ الْمَدِينَةِ نَظَّمَتِ الْعَلَاقَاتِ بَيْنَ الْمُسْلِمِينَ وَغَيْرِهِمْ فِي الْمَدِينَةِ. ( )
٤ جَعَلَتِ الْوَثِيقَةُ الْمُهَاجِرِينَ وَالْأَنْصَارَ فِي صِرَاعٍ دَائِمٍ. ( )
٥ اسْتَمَرَّتْ خِلَافَةُ عُثْمَانَ بْنِ عَفَّانَ ﷺ عِشْرِينَ عَامًا. ( )
٦ كَانَ عُثْمَانُ بْنُ عَفَّانَ ﷺ مَعْرُوفًا بِالْحَيَاءِ وَالْكَرَمِ. ( )
٧ السَّخَاءُ مِنَ الْقِيَمِ الَّتِي حَثَّ عَلَيْهَا الْإِسْلَامُ. ( )
٨ النَّبِيُّ ﷺ كَانَ مِثَالًا فِي السَّخَاءِ وَالْكَرَمِ. ( )
٩ مِنْ صُوَرِ السَّخَاءِ التَّصَدُّقُ وَمُسَاعَدَةُ الْمُحْتَاجِينَ. ( )

اخْتَرِ الْإِجَابَةَ الصَّحِيحَةَ:
١ الْمَالُ الَّذِي تَجِبُ فِيهِ الزَّكَاةُ يَجِبُ أَنْ يَكُونَ ....................
(أ) مَمْلُوكًا لِلْمُسْلِمِ وَبَلَغَ النِّصَابَ.
(ب) أَيَّ مَبْلَغٍ مِنَ الْمَالِ مَهْمَا كَانَ صَغِيرًا.
(ج) كَافِيًا لِلاحْتِيَاجَاتِ الضَّرُورِيَّةِ.
٢ وَثِيقَةُ الْمَدِينَةِ هِيَ أَوَّلُ دُسْتُورٍ إِسْلَامِيٍّ، وَكَانَ الْهَدَفُ مِنْهَا ....................
(أ) إِعْطَاءَ الْحُكْمِ لِقُرَيْشٍ.
(ب) تَقْسِيمَ الْمَدِينَةِ بَيْنَ الْقَبَائِلِ.
(ج) تَنْظِيمَ الْعَلَاقَةِ بَيْنَ الْمُسْلِمِينَ وَغَيْرِهِمْ فِي الْمَدِينَةِ.
