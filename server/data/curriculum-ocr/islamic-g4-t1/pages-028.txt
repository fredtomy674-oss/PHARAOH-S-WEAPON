الْأَنْشِطَةُ وَالتَّدْرِيبَاتُ

نَشَاط ١ اخْتَرِ الْإِجَابَةَ الصَّحِيحَةَ:
١ كَانَتْ بَيْعَةُ الْعَقَبَةِ الثَّانِيَةُ فِي السَّنَةِ .................... مِنَ الْبَعْثَةِ.
(أ) الْعَاشِرَةِ (ب) الثَّالِثَةَ عَشْرَةَ (ج) الْخَامِسَةَ عَشْرَةَ
٢ كَانَ بَيْتُ أَبِي أَيُّوبَ ﷺ يَتَكَوَّنُ مِنْ ....................
(أ) طَابِقٍ وَاحِدٍ. (ب) طَابِقَيْنِ. (ج) ثَلَاثَةِ طَوَابِقَ.
٣ اسْتُشْهِدَ أَبُو أَيُّوبَ الْأَنْصَارِيُّ ﷺ وَهُوَ فِي طَرِيقِهِ إِلَى ....................
(أ) الْمَدِينَةِ (ب) مَكَّةَ (ج) الْقُسْطَنْطِينِيَّةِ

نَشَاط ٢ ضَعْ عَلَامَةَ (/) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ الْعِبَارَةِ الْخَطَأِ:
١ كَانَ أَبُو أَيُّوبَ الْأَنْصَارِيُّ ﷺ مِنْ أَهْلِ مَكَّةَ. ( )
٢ أَحَبَّ أَبُو أَيُّوبَ الْأَنْصَارِيُّ ﷺ النَّبِيَّ ﷺ حُبًّا شَدِيدًا. ( )
٣ اسْتَضَافَ أَبُو أَيُّوبَ الْأَنْصَارِيُّ ﷺ النَّبِيَّ ﷺ فِي بَيْتِهِ. ( )
٤ مِنْ صِفَاتِ أَبِي أَيُّوبَ الْأَنْصَارِيُّ ﷺ الْكَرَمُ وَالتَّضْحِيَةُ فِي سَبِيلِ اللَّهِ. ( )
٥ تُوُفِّيَ أَبُو أَيُّوبَ الْأَنْصَارِيُّ ﷺ بِالْمَدِينَةِ الْمُنَوَّرَةِ. ( )

نَشَاط ٣ رَتِّبِ الْأَحْدَاثَ التَّالِيَةَ مِنَ الْأَقْدَمِ إِلَى الْأَحْدَثِ:
( ) إِقَامَةُ النَّبِيِّ ﷺ فِي دَارِ أَبِي أَيُّوبَ.
( ) بَيْعَةُ الْعَقَبَةِ الثَّانِيَةِ.
( ) هِجْرَةُ النَّبِيِّ ﷺ إِلَى الْمَدِينَةِ.
( ) اسْتِشْهَادُ أَبِي أَيُّوبَ الْأَنْصَارِيِّ.
