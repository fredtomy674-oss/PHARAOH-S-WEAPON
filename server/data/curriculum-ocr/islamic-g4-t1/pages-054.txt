الْأَنْشِطَةُ وَالتَّدْرِيبَاتُ

نَشَاط (١) ضَعْ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (✗) أَمَامَ الْعِبَارَةِ الْخَطَأِ:
١ هَاجَرَ النَّبِيُّ ﷺ وَصَحَابَتُهُ إِلَى الْمَدِينَةِ وَمَعَهُمْ كُلُّ أَمْوَالِهِمْ وَأَمْلَاكِهِمْ. ( )
٢ اعْتَمَدَ الْمُهَاجِرُونَ كُلِّيًّا عَلَى الْأَنْصَارِ، وَلَمْ يَعْمَلُوا. ( )
٣ الْمُؤَاخَاةُ كَانَتْ تَقُومُ عَلَى الْمَحَبَّةِ وَالْإِيثَارِ وَالتَّعَاوُنِ. ( )
٤ كَانَ الْمُهَاجِرُونَ أَغْنِيَاءَ، وَلَمْ يَحْتَاجُوا إِلَى مُسَاعَدَةِ الْأَنْصَارِ. ( )
٥ مِنْ قِيَمِ الْمُؤَاخَاةِ التَّعَاوُنُ وَالْإِيثَارُ. ( )
٦ عَرَضَ عَبْدُ الرَّحْمَنِ بْنُ عَوْفٍ ﷺ مَالَهُ عَلَى سَعْدِ بْنِ الرَّبِيعِ ﷺ. ( )

نَشَاط (٢) أَجِبْ عَنِ الْأَسْئِلَةِ التَّالِيَةِ:
١ لِمَاذَا آخَى النَّبِيُّ ﷺ بَيْنَ الْمُهَاجِرِينَ وَالْأَنْصَارِ؟
٢ وَضِّحْ مَعْنَى الْمُؤَاخَاةِ بَيْنَ الْمُهَاجِرِينَ وَالْأَنْصَارِ.
٣ مَاذَا عَرَضَ سَعْدُ بْنُ الرَّبِيعِ ﷺ عَلَى عَبْدِ الرَّحْمَنِ بْنِ عَوْفٍ ﷺ؟
٤ كَيْفَ سَاعَدَ الْأَنْصَارُ إِخْوَانَهُمُ الْمُهَاجِرِينَ؟
٥ مَاذَا نَسْتَفِيدُ مِنْ مَوْقِفِ عَبْدِ الرَّحْمَنِ بْنِ عَوْفٍ ﷺ عِنْدَمَا رَفَضَ الْمَالَ وَطَلَبَ الْعَمَلَ؟

نَشَاط (٣) اكْتُبْ رِسَالَةً لِصَدِيقٍ لَكَ تُعَبِّرُ فِيهَا عَنِ اسْتِعْدَادِكَ لِمُسَاعَدَتِهِ:

شَارِكْ أُسْرَتَكَ
تَعَاوَنْ مَعَ أَفْرَادِ أُسْرَتِكَ فِي مُنَاقَشَةِ مَوْقِفِ عَبْدِ الرَّحْمَنِ بْنِ عَوْفٍ ﷺ.
هَلْ كُنْتَ سَتَتَصَرَّفُ مِثْلَهُ؟ أَمْ هَلْ كُنْتَ سَتَقْبَلُ عَرْضَ سَعْدِ بْنِ الرَّبِيعِ ﷺ؟
وَلِمَاذَا؟

٥٣
