مُرَاجَعَةٌ عَلَى الْوَحْدَةِ الْأُولَى

ضَعْ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ الْعِبَارَةِ غَيْرِ الصَّحِيحَةِ:
١ الرُّسُلُ جَمِيعُهُمْ بَشَرٌ اصْطَفَاهُمُ اللَّهُ (تَعَالَى) لِحَمْلِ الرِّسَالَةِ. ( )
٢ يَوْمُ الْقِيَامَةِ تُنْشَرُ الصُّحُفُ الْمَكْتُوبُ فِيهَا أَعْمَالُ النَّاسِ. ( )
٣ الزَّكَاةُ هِيَ الرُّكْنُ الْخَامِسُ مِنْ أَرْكَانِ الْإِسْلَامِ. ( )
٤ الْمُسْتَحِقُّونَ لِلزَّكَاةِ ثَمَانِيَةُ أَصْنَافٍ وَرَدَ ذِكْرُهُمْ فِي الْقُرْآنِ الْكَرِيمِ. ( )
٥ كَانَ الْمَسْجِدُ النَّبَوِيُّ مَرْكَزًا لِلْعِبَادَةِ فَقَطْ دُونَ أَيِّ أَدْوَارٍ أُخْرَى. ( )
٦ شَارَكَ النَّبِيُّ ﷺ بِنَفْسِهِ فِي بِنَاءِ الْمَسْجِدِ النَّبَوِيِّ. ( )
٧ أَبُو أَيُّوبَ الْأَنْصَارِيُّ كَانَ مِنَ الْأَنْصَارِ الَّذِينَ اسْتَقْبَلُوا النَّبِيَّ ﷺ فِي الْمَدِينَةِ. ( )
٨ إِكْرَامُ الضَّيْفِ مِنَ الْعَادَاتِ الْجَاهِلِيَّةِ الَّتِي لَمْ يُؤْمَرْ بِهَا فِي الْإِسْلَامِ. ( )
٩ الْكَرَمُ وَحُسْنُ الضِّيَافَةِ مِنْ صِفَاتِ الْأَنْبِيَاءِ وَالصَّالِحِينَ. ( )
١٠ حَثَّ الْإِسْلَامُ عَلَى تَقْدِيمِ الطَّعَامِ لِلضَّيْفِ وَالتَّرْحِيبِ بِهِ. ( )

اخْتَرِ الْإِجَابَةَ الصَّحِيحَةَ:
١ تَرْتِيبُ الْإِيمَانِ بِالرُّسُلِ بَيْنَ أَرْكَانِ الْإِيمَانِ هُوَ ....................
(أ) الثَّانِي (ب) الثَّالِثُ (ج) الرَّابِعُ
٢ مَعْنَى ﴿انْفَطَرَتْ﴾ فِي قَوْلِهِ تَعَالَى: ﴿إِذَا السَّمَاءُ انْفَطَرَتْ﴾ هُوَ ....................
(أ) تَشَقَّقَتْ (ب) احْتَرَقَتْ (ج) لَمَعَتْ
٣ لِلزَّكَاةِ ثَمَرَاتٌ كَثِيرَةٌ، مِنْهَا تَطْهِيرُ ....................
(أ) مَالِ الْغَنِيِّ (ب) نَفْسِ الْغَنِيِّ مِنَ الشُّحِّ (ج) كِلَاهُمَا صَوَابٌ
٤ أَوَّلُ عَمَلٍ قَامَ بِهِ النَّبِيُّ ﷺ عِنْدَ وُصُولِهِ إِلَى الْمَدِينَةِ هُوَ ....................
(أ) بِنَاءُ الْمَسْجِدِ النَّبَوِيِّ (ب) إِنْشَاءُ الْأَسْوَاقِ (ج) إِقَامَةُ سُورٍ حَوْلَ الْمَدِينَةِ
