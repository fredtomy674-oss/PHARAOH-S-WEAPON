Tip
First conditional
If + present simple, will + infinitive
→ If it rains, we will stay home.
• We use the first conditional to express real or possible situations in the future.
Second conditional
If + past simple, would + infinitive
→ If I had wings, I would fly.
• We use the second conditional to express unreal or imaginary situations in present or future.
