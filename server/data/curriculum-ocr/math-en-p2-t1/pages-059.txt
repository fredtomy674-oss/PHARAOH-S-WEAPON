Example 1
Factorize each of the following completely:
1 a x + b y + a y + b x
3 3 x³ + 2 x² - 3 x - 2
5 2 x³ y - 6 x² y - 1 8 x y + 5 4 y
2 3 x² - 3 y + x y - 9 x
4 x² - 5 x - y² + 5 y

1 a x + b y + a y + b x
= (a x + a y) + (b y + b x)
= a (X + y) + b (Y + X)
= (X + y) (a + b)

2 3 x² - 3 y + x y - 9 x
= (3 x² - 9 x) + (X y - 3 y)
= 3 x (X - 3) + y (X - 3)
= (X - 3) (3 x + y)

3 3 x³ + 2 x² - 3 x - 2
= (3 x³ + 2 x²) + (- 3 x - 2)
= x² (3 x + 2) - (3 x + 2)
= (3 x + 2) (x² - 1)
= (3 x + 2) (x - 1) (x + 1)

4 x² - 5 x - y² + 5 y = (x² - y²) + (5 y - 5 x)
= (x - y) (x + y) + 5 (y - x)
= (x - y) (x + y) - 5 (x - y)
= (x - y) (x + y - 5)

5 2 x³ y - 6 x² y - 1 8 x y + 5 4 y = 2 y (x³ - 3 x² - 9 x + 2 7)
= 2 y [(x³ - 3 x²) + (- 9 x + 2 7)]
= 2 y [x² (x - 3) - 9 (x - 3)]
= 2 y (x - 3) (x² - 9)
= 2 y (x - 3) (x - 3) (x + 3)
= 2 y (x - 3)² (x + 3)

■ Another Solution
a x + b y + a y + b x
= (a x + b x) + (b y + a y)
= x (a + b) + y (b + a)
= (a + b) (x + y)

■ Note that
In number 2 if the grouping has
been done this way:
3 x² - 3 y + x y - 9 x
= (3 x² - 3 y) + (x y - 9 x)
= 3 (x² - y) + x (y - 9)
There is no common factor
so this grouping fails and you
should try to regroup in
a different way.
