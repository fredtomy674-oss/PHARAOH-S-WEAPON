Example 1
If X = -4√3 , y = √3 , z = ³√5 ,
find the value of each of the following:
1 x + y
2 x x y
3 x / 2y
4 2x - z³

1 x + y = -4√3 + √3
= (-4 + 1)√3
= -3√3

2 x x y = -4√3 x √3
= (-4 x 1) x (√3)²
= -4 x 3 = -12

3 x / 2y = -4√3 / 2√3
= -4√3 / 2√3 = -4/2 x √3/√3
= -2 x 1 = -2

4 2x - z³ = 2 x (-4√3) - (³√5)³
= -8√3 - 5

■ Note that
When adding and subtracting
like radical terms, we use the
same method as for adding and
subtracting like algebraic terms:
-4 X + X = (-4 + 1) X = -3 X

■ Note that
When multiplying radical terms,
we use the same method as for
multiplying algebraic terms:
-4 X x X = (-4 x 1) X² = -4 X²

■ Note that
The radical term - 8√3 is not
like to the term 5, so they can
not be subtracted.
