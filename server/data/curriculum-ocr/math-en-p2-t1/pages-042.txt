▶ Spot the mistake:
(7) Sameh and Islam solved the equation 4 x^2 = 8 x as shown:
Which solution is correct?
Discuss.

Sameh's solution:
4 x^2 = 8 x
4 x^2 / 4 x = 8 x / 4 x
x = 2

Islam's solution:
4 x^2 = 8 x
4 x^2 - 8 x = 0
4 x (x - 2) = 0
Either 4 x = 0, hence x = 0
Or x - 2 = 0, hence x = 2
