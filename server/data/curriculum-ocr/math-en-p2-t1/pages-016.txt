Operations on intervals
Intervals are subsets of the set of real numbers, therefore, union,
intersection, difference, and complement operations can be performed
on them in the same way as on sets, as follows :

■ Note that
The universal set is a set
that contains all of its
subsets, and it is denoted
by the symbol U.

Sets
Assuming that:
U = {1, 2, 3, 4, 5, 6}
where U is the
universal set
X = {2, 3, 4, 5}
Y = {1, 2, 3}

Intervals
Assuming that:
U = R

The set of
elements that
belong to
X or Y.
X ∪ Y = {1, 2, 3, 4, 5}

X ∩ Y = [1, 3]
