b ∈ [a, b]
▶ ]a, b[ is called an open

The set of real numbers greater

The set of real numbers greater

{X : X ∈ R, a ≤ X < b} = [a, b[

The set of real numbers greater
than a and less than b
{X : X ∈ R, a < X < b} = ]a, b[

The set of real numbers greater

to b
{X : X ∈ R, a < X ≤ b} = ]a, b]

Example 1
1 Write in the form of an interval
and represent on the number
line set A:
A = {X : X ∈ R, 1 < X ≤ 3}
Is √2 ∈ A?

2 Write in the form of an interval
and represent on the number
line set B:
B = {X : X ∈ R, -2 < X < 2}
Is ∛-9 ∈ B?

1 A = ]1, 3]
(1) (3)
By using a calculator :
√2 ≈ 1.4
∴ 1 < √2 ≤ 3
∴ √2 ∈ ]1, 3]

2 B = ]-2, 2[
(-2) (2)
By using a calculator :
∛-9 ≈ -2.08
∴ ∛-9 < -2
∴ ∛-9 ∉ ]-2, 2[
