Example 3
Simplify each of the following to its simplest form:
1 (√6)^n × (√3)^n-1 × (√2)^-n, then find the numerical value of the result when n = 1
2 10^2n × 0.001 / 10^-n+1 × 100, then find the numerical value of the result when n = 2

1 (√6)^n × (√3)^n-1 × (√2)^-n = (√3 × √2)^n × (√3)^n-1 × (√2)^-n
= (√3)^n × (√2)^n × (√3)^n-1 × (√2)^-n
= (√3)^n+n-1 × (√2)^n-n
= (√3)^2n-1 × (√2)^0
= (√3)^2n-1 × 1
= (√3)^2n-1
When n = 1:
∴ (√3)^2n-1 = (√3)^2×1-1 = √3

2 10^2n × 0.001 / 10^-n+1 × 100 = 10^2n × 10^-3 / 10^-n+1 × 10^2
= 10^2n-3 / 10^-n+1+2 = 10^2n-3 / 10^-n+3
= 10^(2n-3)-(-n+3) = 10^2n-3+n-3 = 10^3n-6
When n = 2:
∴ 10^3n-6 = 10^3×2-6 = 10^6-6 = 10^0 = 1
