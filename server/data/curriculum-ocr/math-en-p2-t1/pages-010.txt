Solving equations

Example 5
Find the solution set for each of the following equations:
1 x^2 - 3 = 2 where x ∈ Q'
2 4x^3 = -32 where x ∈ Q'
3 1/2 x^2 + 1 = -4 where x ∈ R
4 5x^3 - 1 = 4x^3 + 8 where x ∈ R

1 ∴ x^2 - 3 = 2
∴ x^2 = 2 + 3 = 5
∴ x = ±√5 ∈ Q'
∴ The solution set = {√5, -√5}

2 ∴ 4x^3 = -32
∴ x^3 = -32/4 = -8
∴ x = 3√-8 = -2 ∉ Q'
∴ The solution set = ∅

3 ∴ 1/2 x^2 + 1 = -4
∴ 1/2 x^2 = -4 - 1 = -5
∴ x^2 = -5 × 2 = -10
∴ x = ±√-10 ∉ R
∴ The solution set = ∅

4 ∴ 5x^3 - 1 = 4x^3 + 8
∴ 5x^3 - 4x^3 = 8 + 1
∴ x^3 = 9
∴ x = 3√9 ∈ R
∴ The solution set = {3√9}
