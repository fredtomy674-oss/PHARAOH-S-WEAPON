Example 5
Find the solution set of the equation : x² - 8x + 3 = 0 in R
∴ x² - 8x + 3 = 0
∴ x² - 8x = -3
By adding (-8x)² / 4x² = 16 to both sides of the equation
∴ x² - 8x + 16 = -3 + 16
∴ (x - 4)² = 13 ∴ x - 4 = ±√13
∴ x = 4 ± √13
∴ The solution set = {4 - √13, 4 + √13}
■ Note that
We cannot solve this
example using trinomial
factorization, but it can
be solved by using
completing the square.

Example 6
If x² + 3y = 31, 2x - y = 8,
what is the numerical value of the expression
2x³ - x²y + 6xy - 3y²?
2x³ - x²y + 6xy - 3y² = (2x³ - x²y) + (6xy - 3y²)
= x² (2x - y) + 3y (2x - y)
= (2x - y) (x² + 3y) = 8 × 31 = 248

A cuboid glass box used for
