السؤال الأول: اكتب كلمة (صواب) أمام العبارة الصحيحة، وكلمة (خطأ) أمام العبارة غير الصحيحة، مع تصويب الخطأ:
١ - أرسلت بريطانيا وفرنسا كلاً من المذكرة المشتركة الأولى والثانية إلى مصر لتأييد الحركة الوطنية. ( ) ( )
٢ - رفضت الحكومة المصرية تسليم بعض حصون الاسكندرية للأسطول البريطاني عام ١٨٨٢م. ( ) ( )
٣ - كان وزير الحربية عثمان رفقي يُفضّل الضباط المصريين على الأتراك. ( ) ( )
٤ - ركّز الاحتلال البريطاني على تطوير الصناعة الوطنية في مصر. ( ) ( )

٢ - عُقد الاتفاق الودي ١٩٠٤م بين ........................ و........................
٣ - دعا مصطفى كامل لتأسيس أول ........................ بتبرعات المصريين.

السؤال الثالث: اختر الإجابة الصحيحة مما بين القوسين:
١ - كان من نتائج مظاهرة عابدين عام ١٨٨١م ........................
(هزيمة الجيش المصري - عزل وزارة رياض باشا - قصف الإسكندرية - نفي عرابي)
٢ - أسّس مصطفى كامل ........................ للمطالبة بالجلاء.
(الحزب الوطني - حزب الإصلاح - حزب المستقبل - الحزب الشعبي)
٣ - بعد رفض الحكومة المصرية تسليم الحصون لبريطانيا ........................
(انسحبت بريطانيا - قُصفت الإسكندرية - أسّس الحزب الوطني - زاد عدد الجيش)
٤ - نشر مصطفى كامل خُطبه ومقالاته في جريدة ........................
(الأهرام - الأخبار - اللواء - الوفد)
٥ - نُفي أحمد عرابي بعد الثورة إلى ........................
(جزيرة رودس - جزيرة سيلان - السودان - قبرص)
٦ - ساعد محمد فريد على إنشاء ........................ لحماية حقوق العمال.
(مدارس ليلية - وزارات عمالية - نقابات عمالية - صحفًا وطنية)
