أولاً: ضع علامة (✓) أمام العبارة الصحيحة وعلامة (X) أمام العبارة غير الصحيحة:
١) الوسوم <body> و<head> هما وسمان رئيسيان فى اى صفحة HTML. ( )
٢) وسم <h1> يستخدم لانشاء اكبر عنوان فى صفحة الويب. ( )
٣) يجب ان يتم حفظ ملف HTML بامتداد (txt). ( )
٤) يستخدم الوسم <P> لإضافة صورة الى صفحة الويب. ( )
٥) لغة HTML هى احد اللغات المستخدمة فى انشاء صفحات الويب. ( )
٦) نستخدم الوسم <h6/> .... <h6> لكتابة اكبر عنوان فى الصفحة. ( )
٧) Microsoft Windows هي لغة البرمجة المستخدمة في انشاء صفحات الويب. ( )
٨) لجعل الخط عريض فى صفحة الويب نستخدم الوسم <strong/><strong>. ( )
٩) فى صفحة الويب لانشاء فقرة نستخدم وسم <font size="1">. ( )

ثانياً: اختر الإجابة الصحيحة من بين الاختيارات التالية:
١) اى من الوسوم التالية يستخدم لاضافة فقرة نصية فى صفحة HTML؟
أ) <p> ب) <html>
ج) <body> د) <h1>

٢) ما الوسم الذي يحتوى على كل المحتوى المرئى فى صفحة الويب؟
أ) <html> ب) <head>
ج) <title> د) <body>

٣) لغة HTML تستخدم بشكل اساسي لـ ..........
أ) انشاء انظمة التشغيل. ب) تشغيل الالعاب.
ج) تنظيم وتحديد هيكل صفحات الويب. د) تلوين صفحات الويب.

٤) ما الامتداد الصحيح الذي يجب استخدامه عند حفظ ملف HTML؟
أ) html ب) txt
ج) doc د) pdf
