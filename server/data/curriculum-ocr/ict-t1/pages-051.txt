الأسئلة وتدريبات

أولاً: ضع علامة (✓) أمام العبارة الصحيحة وعلامة (X) أمام العبارة غير الصحيحة:
١) تخزين الملفات في السحابة يجعلها اكثر عرضة للضياع في حال تعطل جهازك. ( )
٢) يمكنك الوصول الى ملفاتك المخزنة في السحابة حتى اذا لم يكن لديك اتصال بالانترنت. ( )
٣) تساعدك الحوسبة السحابية على توفير تخزين كبيرة على جهازك. ( )
٤) الذكاء الاصطناعي هو احد مزودى خدمة الحوسبة السحابية. ( )
٥) تتيح الحوسبة السحابية للمستخدم الوصول الى الملفات والبيانات في اى وقت بسهولة ويسر. ( )
٦) من سلبيات استخدام الحوسبة السحابية توفير نسخ احتياطية لملفاتك. ( )
٧) تمكن الخوادم البعيدة المستخدمين من الوصول الى ملفاتهم عبر الانترنت. ( )
٨) تعتبر شركة جوجل من مزودى خدمة الحوسبة السحابية. ( )
٩) يعتبر مايكروسوفت ٣٦٥ من مزودى خدمة الحوسبة السحابية من خلال تطبيق One drive. ( )
١٠) من ايجابيات استخدام الحوسبة السحابية الحاجة الى اتصال ثابت بالانترنت. ( )

ثانياً: اختر الإجابة الصحيحة من بين الاختيارات التالية:
١) ماهو التعريف الافضل للحوسبة السحابية؟
أ) برنامج لتعديل الصور.
ب) طريقة لتخزين الملفات على الإنترنت.
ج) طريقة لتصوير الافلام.
د) نظام لتشغيل الألعاب.
