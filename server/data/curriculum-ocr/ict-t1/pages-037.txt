الدرس الثاني: (الأسئلة والتدريبات)

الأسئلة وتدريبات

أولاً: ضع علامة (✓) أمام العبارة الصحيحة وعلامة (X) أمام العبارة غير الصحيحة:
١) كلمة المرور القوية يجب ان تكون سهلة التخمين مثل تاريخ ميلادك. ( )
٢) لا يهم ان قمت بتحديث برامج جهازك لانها تؤثر على الامان. ( )
٣) يجب ان تشارك كلمة المرور الخاصة بك مع اصدقائك المقربين. ( )
٤) يمكن لخاصية التعرف على الوجه ان تكون اكثر امانا من كلمة المرور العادية. ( )
٥) من مسؤوليتى الشخصية ان اتأكد من ان جهازى مقفل بكلمة مرور. ( )
٦) لاداعى للقلق عند الضغط على الروابط المشبوهة التى تصلك من الغرباء. ( )
٧) كلمات المرور التى تتكون من ثمانية حروف على الاقل وارقام ورموز عشوائية هى الاكثر امانا. ( )
٨) تتطلب المصادقة متعددة العوامل طريقة واحدة فقط لتحديد هويتك. ( )
٩) التشفير الكامل يعمل على حماية معلوماتك بحيث تستطيع انت فقط الوصول اليها. ( )
١٠) المصادقة ببصمة الاصبع يتم بها اجراء مسحا لوجهك باستخدام الكاميرا الخاصة بك. ( )
١١) اذا تعرضت بياناتك للخطر يجب اخبار احد والديك او شخص بالغ موثوق به. ( )

ثانياً: اختر الإجابة الصحيحة من بين الاختيارات التالية:
١) إحدى خصائص الحماية التي تجعل كلمة المرور أقوى أن تكون.
أ) خليطًا من الحروف والارقام والرموز
ب) تاريخ ميلادك
ج) اسمك فقط
د) قصيرة

٢) ماذا تفعل إذا وصلك رابط غريب من شخص لاتعرفه؟
أ) تضغط عليه لترى ماذا يحدث
ب) تتجاهله ولا تضغط عليه
ج) تضغط عليه فورا
د) ترسله لاصدقائك
