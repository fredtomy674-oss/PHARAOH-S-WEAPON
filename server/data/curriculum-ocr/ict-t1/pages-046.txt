الأسئلة والتدريبات

أولاً: ضع علامة (✔) أمام العبارة الصحيحة وعلامة (✘) أمام العبارة غير الصحيحة:
١) حقوق الملكية الفكرية تحمى الاعمال المبتكرة مثل القصص والرسومات. ( )
٢) المشاع الابداعى هى اعمال لا يمكن لاى شخص استخدامها او مشاركتها. ( )
٣) التداول المالى الالكترونى يعنى اننا نشترى ونبيع الاسهم عبر الانترنت. ( )
٤) للتداول المالى الالكترونى الآمن فى مصر يجب استخدام اى تطبيق متاح على الانترنت. ( )
٥) الحقوق الفكرية هى اختراع او ابتكار او فكرة شخص ما يحميها القانون من ان ينسخها شخص اخر. ( )
٦) تعرف البورصة على انها بنك معرفة يتبادل فيها الاعضاء افكارهم. ( )
٧) المشاع الابداعى هى الاعمال التى منح مبتكرها الاذن بمشاركتها. ( )
٨) يوفر التداول المالى الالكترونى للمستثمرين الاستقلالية وبدائل سهلة الاستخدام. ( )
٩) تعتبر مصر الاعمال ملكا عاما اذا كان المؤلف متوفيا منذ ٥٠ عاما على الاقل. ( )
١٠) تتيح البورصة المصرية للمواطنين فرصة الاستثمار فى مختلف القطاعات. ( )

ثانياً: اختر الإجابة الصحيحة من بين الاختيارات التالية:
١) ماهو التعريف الصحيح لحقوق الطبع والنشر؟
أ) اسم آخر للبورصة
ب) طريقة لشراء وبيع الاسهم
ج) حماية الاجهزة الالكترونية من الفيروسات
د) حماية الاعمال الفنية والادبية مثل الاغانى والكتب
