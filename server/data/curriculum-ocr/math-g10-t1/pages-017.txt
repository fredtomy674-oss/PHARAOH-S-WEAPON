العلاقة بين جذرى معادلة الدرجة الثانية ومعاملات حدودها

حاول أن تحل
١) دون حل المعادلة أوجد مجموع وحاصل ضرب جذرى كل من المعادلات الآتية :
أ) ٢ س٢ + س - ٦ = ٠
ب) ٣ س٢ = ٢٣ س - ٣٠
ج) (٢ س - ٣) (س + ٢) = ٠

مثال
٢) إذا كان حاصل ضرب جذرى المعادلة ٢ س٢ - ٣ س + ك = ٠ يساوى ١ فأوجد قيمة ك، ثم حل المعادلة.
الحل
حاصل ضرب الجذرين = ج/أ
١ = ك/٢ ..
.. ك = ٢
أ = ٢ ، ب = - ٣ ، ج = ٢
القانون العام:
س = - ب ± جذر(ب٢ - ٤ أ ج) / ٢ أ
س = ٣ ± جذر(٩ - ١٦) / ٤ = ٣ ± جذر(- ٧) / ٤ = ٣ ± جذر(٧) ت / ٤
مجموعة حل المعادلة هى { ٣/٤ + جذر(٧)/٤ ت ، ٣/٤ - جذر(٧)/٤ ت }

حاول أن تحل
٢) إذا كان حاصل ضرب جذرى المعادلة ٣ س٢ + ١٠ س - ج = ٠ هو ٤/٣ فأوجد قيمة ج، ثم حل المعادلة.
٣) إذا كان مجموع جذرى المعادلة ٢ س٢ + ب س - ٥ = ٠ هو - ٣/٢ فأوجد قيمة ب، ثم حل المعادلة.

مثال
٢) إذا كان (١ + ت) هو أحد جذور المعادلة س٢ - ٢ س + أ = ٠ حيث أ ع فأوجد:
أ) الجذر الآخر
ب) قيمة أ
الحل
أ = ١ ، ب = - ٢ ، ج = أ
أ) .. ١ + ت هو أحد جذرى المعادلة
.. الجذر الآخر = ١ - ت
لأن الجذرين مترافقان ومجموعهما = ٢

ب) .. حاصل ضرب الجذرين = أ
.. (١ + ت) (١ - ت) = أ
.. ١ + ١ = ٢ .. أ = ٢

حاول أن تحل
٤) إذا كان (٢ + ت) هو أحد جذور المعادلة س٢ - ٤ س + ب = ٠ حيث ب ع فأوجد
أ) الجذر الآخر
ب) قيمة ب
