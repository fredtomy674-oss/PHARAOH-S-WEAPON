المستقيمات المتوازية والأجزاء المتناسبة

أ + ١ = هـ ج + ١
أ ي أ هـ
.. ي ب = هـ ج
أ هـ
ومن خواص التناسب نجد أن: أ ي = أ هـ (وهو المطلوب)
ي ب هـ ج
لاحظ أن: .. أ ي = أ هـ .. أ ي + ي ب = أ هـ + هـ ج
ي ب هـ ج هـ ج
أي أن: أ ب = أ ج
ي ب هـ ج

مثال
١ في الشكل المقابل: س ص // ب ج، اس = ١٦سم، ب س = ١٢سم.
أ إذا كان اص = ٢٤سم، أوجد ص ج.
ب إذا كان ج ص = ٢١سم، أوجد أ ج.

الحل
أ .. س ص // ب ج .. اس = اص
س ب ص ج
ويكون: ١٦ = ٢٤ .. ص ج = ٢٤ × ١٢ = ١٨سم.
١٢ ص ج ١٦

ب .. س ص // ب ج .. اب = اج
ب س ج ص
ويكون: ١٦ + ١٢ = اج .. اج = ٢١ × ٢٨ = ٤٩سم.
١٢ ٢١ ١٢

حاول أن تحل
١ في كل من الأشكال التالية: ى هـ // ب ج. أوجد قيمة س العددية (الأطوال مقدرة بالسنتيمترات)
أ ب ج
