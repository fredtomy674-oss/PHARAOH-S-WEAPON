نظرية تاليس العامة
Talis' Theorem

نظرية: إذا قطع مستقيمان عدة مستقيمات متوازية، فإن أطوال القطع الناتجة على أحد القاطعين تكون متناسبة مع أطوال القطع الناتجة على القاطع الآخر. (برهان النظرية لا يمتحن فيه الطالب)

المعطيات: ل1 // ل2 // ل3 // ل4 ، م ، م' قاطعان لها
المطلوب: أ ب : ب ج : ج د = أ' ب' : ب' ج' : ج' د'
البرهان: ارسم أ و' // م' ، ويقطع ل2 في هـ ، ل3 في و.
ب ص // م' ، ويقطع ل3 في س ، ل4 في ص.
:. أ هـ // هـ ب' ، أهـ // أ ب'
:. أ هـ ب' أ متوازى أضلاع ويكون: أهـ = أ' ب'
بالمثل: هـ و = ب' ج' ، و س = ج' د'
في Δ أ ج و':
:. ب هـ // ج و'  :. أ ب / ب ج = أ هـ / هـ و
ويكون: أ ب / ب ج = أ' ب' / ب' ج' (إبدال الوسطين) (1)
بالمثل Δ ب د ص:
:. ب ج / ج د = ب س / س ص = ب' ج' / ج' د' (إبدال الوسطين) (2)
من (1)، (2) ينتج أن:
أ ب / ب ج = ب ج / ج د = أ' ب' / ب' ج' = ب' ج' / ج' د'
:. أ ب : ب ج : ج د = أ' ب' : ب' ج' : ج' د' وهو المطلوب.

مثال
6 في الشكل المقابل: أ ب // ج و // هـ و // س ص ،
أ ج = 28 سم، ج هـ = 20 سم، و و = 15 سم، و ص = 33 سم.
أوجد طول كل من: ب ى ، هـ س

الحل
:. أ ب // ج و // هـ و // س ص
:. أ ج / ب ى = ج هـ / ه و = هـ و / و ص
:. 28 / ب ى = 20 / 15 = هـ س / 33
:. ب ى = 21 سم، هـ س = 44 سم.
