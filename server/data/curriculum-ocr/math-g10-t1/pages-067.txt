المستقيمات المتوازية والأجزاء المتناسبة

عكس
نظرية
إذا قطع مستقيم ضلعين من أضلاع مثلث، وقسمهما إلى قطع أطوالها متناسبة فإنه يوازي
الضلع الثالث.

في الأشكال الثلاثة السابقة: أ ب جـ مثلث، ى هـ يقطع أ ب في ى، أ جـ في هـ وكان أى / أ ب = أهـ / أ جـ
فإن ى هـ // ب جـ
تفكير منطقي: هل ∆ أ ى هـ ~ ∆ أ ب جـ؟ ولماذا؟ - هل ∠ أ ى هـ = ∠ ب؟ فسر إجابتك.

مثال
٣ في الشكل المقابل: أ ب جـ مثلث قائم الزاوية في أ
أ أثبت أن: ى هـ // ب جـ
ب أوجد طول ب جـ

الحل
أ ∴ المثلث أ ى هـ قائم الزاوية في أ
∴ أ ى = √٢٥ - ١٦ = ٣ سم (نظرية فيثاغورث)
∴ أ ى / أ ب = ٣ / ٦ = ١ / ٢ ، أهـ / أ جـ = ٤ / ٨ = ١ / ٢
∴ أ ى / أ ب = أهـ / أ جـ ويكون ى هـ // ب جـ
ب ∴ ∆ أ ى هـ ~ ∆ أ ب جـ (لماذا) ∴ أ ى / أ ب = ى هـ / ب جـ = ١ / ٢
ويكون ٥ / ب جـ = ١ / ٢
∴ ب جـ = ١٥ سم
