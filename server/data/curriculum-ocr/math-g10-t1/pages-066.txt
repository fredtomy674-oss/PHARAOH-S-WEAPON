نتيجة: إذا رسم مستقيم خارج مثلث أ ب ج يوازى ضلعًا من أضلاع المثلث، وليكن ب ج، ويقطع
أب، أج في ى، هـ على الترتيب فإن: أب / ب ى = أج / ج هـ (كما في الشكل).

بتطبيق خواص التناسب نستنتج أن:
أى / أب = أهـ / أج ، أى / ى ب = أهـ / هـ ج

مثال
٢ في الشكل المقابل: جـ هـ ∩ ب ى = {أ}، س ∋ أى
ص ∋ أهـ حيث س ص // ب جـ // هـ ى.
فإذا كان أ ب = ٦سم، أ جـ = ٥سم، أ ى = ١٢سم، هـ ص = ٤سم.
أوجد طول كل من أهـ، ى س.

الحل
∵ هـ ى // ب جـ ، جـ هـ ∩ ب ى = {أ}
∴ أ ى / أ ب = أهـ / أ جـ ويكون: ١٢ / ٦ = أهـ / ٥ ∴ أهـ = ١٠سم

في ∆ أهـ ى:
∵ س ص // هـ ى ∴ أهـ / هـ ص = أ ى / ى س
ويكون ١٠ / ٤ = ١٢ / ى س ∴ ى س = ٤,٨سم

حاول أن تحل
٢ في الشكل المقابل: ى هـ // أ جـ ، أهـ ∩ جـ ى = {ب}
أ إذا كان: أ ب = ٨سم، ب جـ = ٩سم، ب هـ = ١٢سم.
أوجد طول ب ى.
ب إذا كان: أ ب = ٦سم، ب هـ = ٩سم، جـ ى = ١٨سم.
أوجد طول ب جـ.
