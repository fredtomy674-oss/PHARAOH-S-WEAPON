Operations on complex numbers

العمليات على الأعداد المركبة
يمكن استخدام خواص الإبدال والتجميع والتوزيع عند جمع أو ضرب الأعداد المركبة، كما توضح ذلك الأمثلة التالية:
مثال
أوجد في أبسط صورة ناتج كل مما يأتي:
( أ ) ( ٧ - ٤ ت ) + ( ٢ + ت )
( ب ) ( ٢ + ٣ ت ) ( ٣ - ٤ ت )
الحل
( أ ) المقدار = ( ٧ - ٤ ت ) + ( ٢ + ت )
= ( ٧ + ٢ ) + ( - ٤ + ١ ) ت
= ٩ - ٣ ت
باستخدام خاصيتي الإبدال والتجميع
بالتبسيط
( ب ) المقدار = ( ٢ + ٣ ت ) ( ٣ - ٤ ت )
= ٢ ( ٣ - ٤ ت ) + ٣ ت ( ٣ - ٤ ت )
= ٦ - ٨ ت + ٩ ت - ١٢ ت٢
= ٦ - ٨ ت + ٩ ت + ١٢
باستخدام خاصية التوزيع
بفك الأقواس
حيث ت٢ = - ١
= ( ٦ + ١٢ ) + ( - ٨ + ٩ ) ت = ١٨ + ت بالتبسيط
حاول أن تحل
أوجد في أبسط صورة ناتج كل مما يأتي:
( أ ) ( ١٢ - ٥ ت ) - ( ٧ - ٩ ت )
( ب ) ( ٤ - ٣ ت ) ( ٤ + ٣ ت )
( ج ) ( ٥ - ٦ ت ) ( ٣ + ٢ ت )
العددان المترافقان
Conjugate Numbers
العددان المركبان أ + ب ت، أ - ب ت يسميان بالعددين المترافقين فمثلاً ٤ - ٣ ت، ٤ + ٣ ت عددان مترافقان، حيث:
(١) ( ٤ - ٣ ت ) ( ٤ + ٣ ت ) = ( ٤ )٢ - ( ٣ ت )٢
= ١٦ - ٩ ت٢ = ١٦ - ٩ ( - ١ ) = ٢٥ (الناتج عدد حقيقي)
(٢) ( ٤ - ٣ ت ) + ( ٤ + ٣ ت ) = ٨ (الناتج عدد حقيقي)
تفكير ناقد:
هل بالضرورة أن يكون مجموع العددين المترافقين هو دائما عددًا حقيقيًا؟ فسر ذلك.
هل بالضرورة أن يكون حاصل ضرب العددين المترافقين هو دائما عددًا حقيقيًا؟ فسر ذلك.
