٣ في كل من الأشكال التالية حدد ما إذا كان و هـ // ب جـ أم لا.

مثال
٤ أ ب جـ د شكل رباعي فيه س ∋ أ ب، ص ∋ أ جـ حيث س ص // ب جـ،
رسم ص ع // جـ د ويقطع أ د في ع. أثبت أن س ع // ب د.
الحل
في ∆ أ ب جـ:
∵ س ص // ب جـ ∴ اس / س ب = اص / ص جـ (١)
في ∆ أ جـ د:
∵ ص ع // جـ د ∴ اص / ص جـ = اع / ع د (٢)
من (١)، (٢) نستنتج أن: اس / س ب = اع / ع د
في ∆ أ ب د:
∴ اس / س ب = اع / ع د ∴ س ع // ب د

٤ في الشكل المقابل: أ ب جـ مثلث، و ∋ أ جـ،
و هـ // أ ب، و و // أ هـ
إثبت أن (جـ هـ)² = جـ و × جـ ب.
