المطلوب: م(∆ أ ب جـ) / م(∆ ى هـ و) = (أ ب / ى هـ)² = (ب جـ / هـ و)² = (أ جـ / ى و)²
البرهان: ارسم أ س ⊥ ب جـ حيث أ س ∩ ب جـ = {س}،
و ص ⊥ هـ و حيث و ص ∩ هـ و = {ص}
∴ ∆ أ ب جـ ~ ∆ ى هـ و
∴ ق(∠ب) = ق(∠هـ)، أ ب / ى هـ = ب جـ / هـ و = أ جـ / ى و (١)
في المثلثين أ ب س، ى هـ ص:
ق(∠س) = ق(∠ص) = ٩٠°، ق(∠ب) = ق(∠هـ)
∴ ∆ أ ب س ~ ∆ ى هـ ص (مسلمة التشابه)
ويكون: أ ب / ى هـ = أ س / ى ص (٢)
م(∆ أ ب جـ) / م(∆ ى هـ و) = (١/٢ × ب جـ × أ س) / (١/٢ × هـ و × ى ص) = ب جـ / هـ و × أ س / ى ص
بالتعويض من (١)، (٢) ينتج أن:
م(∆ أ ب جـ) / م(∆ ى هـ و) = أ ب / ى هـ × أ ب / ى هـ = (أ ب / ى هـ)² = (ب جـ / هـ و)² = (أ جـ / ى و)² وهو المطلوب.
لاحظ أن: م(∆ أ ب جـ) / م(∆ ى هـ و) = (أ ب / ى هـ)² = (أ س / ى ص)²
فيكون: م(∆ أ ب جـ) / م(∆ ى هـ و) = (أ س / ى ص)²
أى أن النسبة بين مساحتى سطحى مثلثين متشابهين تساوى مربع النسبة بين ارتفاعين متناظرين فيهما.

تفكير ناقد:
١ - إذا كان ∆ أ ب جـ ~ ∆ ى هـ و، ل منتصف ب جـ، م منتصف هـ و.
هل م(∆ أ ب جـ) / م(∆ ى هـ و) = (أ ل / ى م)² ؟
فسر إجابتك واكتب استنتاجك.

٢ - إذا كان ∆ أ ب جـ ~ ∆ ى هـ و،
أن ينصف ∠ أ ويقطع ب جـ فى ن،
ى ع ينصف ∠ ى ويقطع هـ و فى ع.
هل م(∆ أ ب جـ) / م(∆ ى هـ و) = (أ ن / ى ع)² ؟
فسر إجابتك واكتب استنتاجك.
