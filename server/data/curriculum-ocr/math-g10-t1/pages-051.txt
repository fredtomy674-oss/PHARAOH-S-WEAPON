العلاقة بين مساحتي سطحي مضلعين متشابهين

نظرية ٤: النسبة بين مساحتي سطحي مضلعين متشابهين تساوى مربع النسبة بين طولى أى ضلعين متناظرين فيهما.
(برهان النظرية لا يمتحن فيه الطالب)

المعطيات: المضلع أ ب ج د هـ ~ المضلع أ' ب' ج' د' هـ'
المطلوب: م (المضلع أ ب ج د هـ) / م (المضلع أ' ب' ج' د' هـ') = (أ ب / أ' ب')^٢

البرهان: من أ، أ' نرسم أ ج، أ د، أ' ج'، أ' د'
:. المضلع أ ب ج د هـ ~ المضلع أ' ب' ج' د' هـ'
:. فهما ينقسمان إلى نفس العدد من المثلثات، كل يشابه نظيره (حقيقة). ويكون:
م(∆ أ ب ج) / م(∆ أ' ب' ج') = (ب ج / ب' ج')^٢ = (أ ب / أ' ب')^٢ ، م(∆ أ ج د) / م(∆ أ' ج' د') = (ج د / ج' د')^٢ ، م(∆ أ د هـ) / م(∆ أ' د' هـ') = (د هـ / د' هـ')^٢
:. ب ج / ب' ج' = ج د / ج' د' = د هـ / د' هـ' = أ ب / أ' ب' (من تشابه المضلعين)
:. م(∆ أ ب ج) / م(∆ أ' ب' ج') = م(∆ أ ج د) / م(∆ أ' ج' د') = م(∆ أ د هـ) / م(∆ أ' د' هـ') = (أ ب / أ' ب')^٢

ومن خواص التناسب
م(∆ أ ب ج) + م(∆ أ ج د) + م(∆ أ د هـ) / م(∆ أ' ب' ج') + م(∆ أ' ج' د') + م(∆ أ' د' هـ') = (أ ب / أ' ب')^٢
ويكون: م (المضلع أ ب ج د هـ) / م (المضلع أ' ب' ج' د' هـ') = (أ ب / أ' ب')^٢ وهو المطلوب

ملاحظة: (أ ب / أ' ب')^٢ = (أ ب)^٢ / (أ' ب')^٢
