حالات خاصة
١- إذا تقاطع المستقيمان م، م/ في النقطة أ
وكان: ب ب/ // ج ج/، فإن: أ ب / أ ج = أ ب/ / أ ج/
وبالعكس: إذا كان: أ ب / أ ج = أ ب/ / أ ج/
فإن: ب ب/ // ج ج/

نظرية تاليس الخاصة
٢- إذا كانت أطوال القطع الناتجة على أحد القاطعين متساوية فإن
أطوال القطع الناتجة على القاطع الآخر تكون متساوية كذلك.
في الشكل المقابل ل١ // ل٢ // ل٣ // ل٤، قطعها المستقيمان م، م/
وكان: أ ب = ب ج = ج د فإن: أ/ ب/ = ب/ ج/ = ج/ د/

مثال
٧) في الشكل المقابل أوجد القيمة العددية لكل من س، ص.
الحل
∵ أ ب // ج د // هـ و، ب د = د و
∴ أ ج = ج هـ
ويكون: ٢ س - ٣ = س + ٢ ∴ س = ٥
∵ ب د = د و، س = ٥ ∴ ص + ٣ = ٥ + ١ ∴ ص = ٣

مثال
٨) الربط بالصناعة: تنقل عبوات الأسمدة من إنتاج أحد
المصانع بانزلاقها عبر أنبوب مائل لتحملها السيارات إلى
مراكز التوزيع كما في الشكل المقابل.
فإذا كانت ى، هـ، و مساقط النقط أ، ب، جـ على الأفقى
بنفس الترتيب، أ ب = ١,٢م، ى هـ = ٨٠سم، هـ و = ١٢متراً
أوجد طول الأنبوب لأقرب متر.
الحل
∵ ى، هـ، و مساقط النقط أ، ب، جـ على الأفقى
∵ أ ى // ب هـ // ج و ، ى و قاطعان لها
ويكون: أ ج / أ ب = ى و / ى هـ
∴ أ ج = ١,٢ × ١٢ / ٠,٨ = ١٩,٢ متراً
∴ أ ى // ب هـ // ج و
∴ أ ج / أ ب = ى و / ى هـ
∴ أ ج = ١٩ متراً
