.. اب / ب ج = ٧ / ٩
ويكون اب / ب ج = ١٦ / ٩
.. اب + ب ج / ب ج = ٩ + ٧ / ٩ (خواص التناسب)
.. ب ج = ٢٧ سم ، اب = ٢١ سم

حاول أن تحل
٢) اب ج مثلث قائم الزاوية في ب. رسم أد ينصف < أ، ويقطع ب ج في د.
إذا كان طول ب د = ٢٤ سم، ب أ : أ ج = ٣ : ٥ فأوجد محيط ∆ اب ج.

ملاحظة هامة
١- في المثلث اب ج حيث اب ≠ اج:
إذا كان أد ينصف < ب اج،
أهـ ينصف الزاوية الخارجة للمثلث عند أ.
فإن: بد / دج = اب / اج ، بهـ / هـج = اب / اج
ويكون بد / دج = بهـ / هـج
أى أن ب ج تنقسم من الداخل في د ومن الخارج في هـ بنسبة واحدة
ويكون المنصفين أد ، أهـ متعامدين . (لماذا)؟

٢- إذا كان اب > اج، قطع منصف < أ الضلع ب ج في د حيث ب د > د ج، أما منصف الزاوية الخارجة
عند أ فيقطع ب ج في هـ حيث ب هـ > هـ ج.

تفكير ناقد
> كلما كبر اج ماذا يحدث للنقطة د؟
> إذا كان اج = اب أين تقع النقطة د؟ وما وضع أهـ بالنسبة إلى ب ج عندئذ؟
> عندما يصبح اج > اب ما العلاقة بين د ج، د ب؟ وأين تقع هـ عندئذ؟ قارن إجابتك مع زملائك.

مثال
٣) اب ج مثلث فيه اب = ٦ سم، اج = ٤ سم، ب ج = ٥ سم. رسم أد ينصف < أ ويقطع ب ج في د،
ورسم أهـ ينصف < أ الخارجة ويقطع ب ج في هـ. احسب طول د هـ.

الحل
.. أد ينصف < أ، أهـ ينصف < أ الخارجة
.. د، هـ تقسمان ب ج من الداخل ومن الخارج بنفس النسبة.
أى أن: بد / دج = بهـ / هـج = اب / اج
.. بد / دج = بهـ / هـج = ٦ / ٤ = ٣ / ٢
.. ب ج = ب د + د ج = ٥، ب هـ - هـ ج = ب ج = ٥ سم
