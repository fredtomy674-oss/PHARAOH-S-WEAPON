تشابه المثلثات

ويكون أ ب / س ص = ب ج / ص و = ج أ / و س
.. أ س = و هـ (عملاً)
.. أ ب / س ص = ب ج / ص و (١)
.. أ ب / و هـ = ب ج / و س (معطيات) (٢)
من (١)، (٢) ينتج أن: س ص = هـ و ، ص أ = و س
ويكون Δ أ س ص ≡ Δ و هـ و (تطابق الأضلاع الثلاثة لنظائرها في الآخر)
.. Δ و هـ و ~ Δ أ س ص
.. Δ أ ب جـ ~ Δ أ س ص (برهانا)
.. Δ أ ب جـ ~ Δ و هـ و (وهو المطلوب)

مثال
٥ في الشكل المقابل: ب، ص، جـ على استقامة واحدة. أثبت أن:
أ) Δ أ ب جـ ~ Δ س ب ص
ب) ب جـ ينصف ∠ أ ب س
الحل
أ) في المثلثين أ ب جـ، س ب ص نجد أن:
أ ب / س ب = ١٢ / ٩ = ٤ / ٣ ، ب جـ / ب ص = ١٨ / ٦ + ١٨ = ١٨ / ٢٤ = ٣ / ٤
أ جـ / س ص = ١٨ / ١٣,٥ = ٤ / ٣
ويكون أ ب / س ب = ب جـ / ب ص = أ جـ / س ص أي أن الأضلاع المتناظرة متناسبة
.. Δ أ ب جـ ~ Δ س ب ص
ب) .. Δ أ ب جـ ~ Δ س ب ص
أي أن: ∠ (أ ب جـ) = ∠ (س ب ص)
أي أن: ب جـ ينصف ∠ أ ب س

٦ في الشكل المقابل: أ ب ∩ جـ د = {هـ} حيث أ هـ / هـ ب = أ جـ / هـ د أثبت أن أ جـ // ب د
الحل
.. أ هـ / هـ ب = أ جـ / هـ د (من خواص التناسب) (١)
.. أ جـ / هـ د = أ جـ / هـ د (من خواص التناسب) (٢)
من (١)، (٢) ينتج أن: أ هـ / هـ ب = جـ هـ / و ب
