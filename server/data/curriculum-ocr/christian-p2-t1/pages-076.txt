الأنشطة والممارسات ؟

نشاط (1): “لعبة القرارات“
ضع علامة / أمام القرار الصحيح في كل موقف:
1- أرسل لي شخص مجهول على إنستجرام طلب صداقة .
- أقبله وأبدأ محادثته. ( )
- أتجاهله أو أستشير والداي. ( )
2- قرأت خبرًا غريبًا عن الكنيسة
- أشاركة فورًا مع أصحابي ( )
أتحقق من مصدره أولاً ( )
3- صديقي يلعب أونلاين ٦ ساعات يوميًا.
- أقلده حتى لا أكون مُملاً. ( )
- أختار وقتًا مناسبًا للعب ووقتًا للأنشطة الأخرى ( )
4- شاهدت فيديو يحتوي على كلام مسيء عن الكنيسة
- أرسله لأصدقائي. ( )
- أبلغ خادمي أو أحد الكبار وأتوقف عن مشاهدته ( )
5- أحد الأشخاص في “الجروب“ طلب مني إرسال صورتي الشخصية
- أرسلها لأنه يبدو لطيفًا. ( )
- أرفض وأخبر أهلي فورًا ( )
6- رأيت إعلانًا عن ربح جوائز مجانيًّا من خلال الضغط على رابط
- أضغط الرابط فورًا وأكتب بياناتي ( )
- أتجاهل الإعلان وأحذفه ( )
7- شعرت بالحزن بسبب تعليق سخيف من شخص على السوشيال ميديا
- أرد عليه بنفس الأسلوب ( )
- أتجاهل التعليق وأحكي لشخص أثق فيه ( )
