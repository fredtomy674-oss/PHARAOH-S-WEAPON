حل المعادلات باستخدام التحليل بإخراج العامل المشترك الأكبر

خاصية :
إذا كان a ، b عددين حقيقيين، وكان a × b = 0 فإن :
إما a = 0 أو b = 0 أو كليهما يساوى صفراً.

مثال 5
أوجد مجموعة حل كل من المعادلات الآتية في R :
1) 3x² + 6x = 0
2) 10x³ - 25x² = 0
3) x² = 3x

1) 3x² + 6x = 0
∴ 3x (x + 2) = 0
∴ إما 3x = 0 ومنها x = 0
أو x + 2 = 0 ومنها x = -2
∴ مجموعة الحل = { -2 , 0 }

2) 10x³ - 25x² = 0
∴ 5x² (2x - 5) = 0
∴ إما 5x² = 0 ومنها x = 0
أو 2x - 5 = 0 ومنها x = 5/2
∴ مجموعة الحل = { 0 , 5/2 }

3) x² = 3x
∴ x² - 3x = 0
∴ x (x - 3) = 0
∴ إما x = 0
أو x - 3 = 0 ومنها x = 3
∴ مجموعة الحل = { 0 , 3 }
