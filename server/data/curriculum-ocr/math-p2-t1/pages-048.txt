التحقق من صحة الحل
يمكنك التحقق من صحة الحل بالتعويض بكل قيمة لـ X في المعادلة الأصلية للتحقق من تساوى طرفى المعادلة.

∴ X² + 30 = - 13 X
∴ X² + 13 X + 30 = 0 (2)
∴ (X + 3) (X + 10) = 0
∴ إما 0 = 3 + X ومنها X = - 3
أو 0 = 10 + X ومنها X = - 10
∴ مجموعة الحل = { - 10 , - 3 }

∴ 6 X² - 13 X + 6 = 0
∴ (2 X - 3) (3 X - 2) = 0 (3)
∴ إما 0 = 3 - 2 X ومنها X = 3/2
أو 0 = 2 - 3 X ومنها X = 2/3
∴ مجموعة الحل = { 2/3 , 3/2 }
