مثال 1
حلل كلًا مما يأتي تحليلاً تاماً :
ax + by + ay + bx 1
3x^3 + 2x^2 - 3x - 2 3
3x^2 - 3y + xy - 9x 2
x^2 - 5x - y^2 + 5y 4
2x^3y - 6x^2y - 18xy + 54y 5

حل آخر
ax + by + ay + bx
= (ax + bx) + (by + ay)
= x (a + b) + y (b + a)
= (a + b) (x + y)

لاحظ أن
في رقم 2 إذا تم التقسيم كالتالي :
3x^2 - 3y + xy - 9x
= (3x^2 - 3y) + (xy - 9x)
= 3 (x^2 - y) + x (y - 9)
لا يوجد عامل مشترك
ولذلك يفشل هذا التقسيم ونحاول
التقسيم بترتيب آخر.

ax + by + ay + bx
= (ax + ay) + (by + bx)
= a (x + y) + b (y + x)
= (x + y) (a + b)

3x^2 - 3y + xy - 9x
= (3x^2 - 9x) + (xy - 3y)
= 3x (x - 3) + y (x - 3)
= (x - 3) (3x + y)

3x^3 + 2x^2 - 3x - 2
= (3x^3 + 2x^2) + (- 3x - 2)
= x^2 (3x + 2) - (3x + 2)
= (3x + 2) (x^2 - 1)
= (3x + 2) (x - 1) (x + 1)

x^2 - 5x - y^2 + 5y = (x^2 - y^2) + (5y - 5x)
= (x - y) (x + y) + 5 (y - x)
لاحظ أن
y - x = - (x - y)
= (x - y) (x + y) - 5 (x - y)
= (x - y) (x + y - 5)

2x^3y - 6x^2y - 18xy + 54y = 2y (x^3 - 3x^2 - 9x + 27)
= 2y [(x^3 - 3x^2) + (- 9x + 27)]
= 2y [x^2 (x - 3) - 9 (x - 3)]
= 2y (x - 3) (x^2 - 9)
= 2y (x - 3) (x - 3) (x + 3)
= 2y (x - 3)^2 (x + 3)
