تقييم الدرس

أولاً قياس المفاهيم
اختر الإجابة الصحيحة من بين الإجابات المعطاة :
(1) ما العامل المشترك الأكبر بين حدود كثيرة الحدود 8x - 12x² ؟
(أ) 2
(ب) 4
(ج) 2x
(د) 4x

(2) أي مما يلي يمثل تحليلاً لكثيرة الحدود 24x³ - 16x² بإخراج ع . م . أ ؟
(أ) 8x(2x - 3x²)
(ب) 4x²(4 - 6x)
(ج) 8x²(2 - 3x)
(د) 8(2x² - 3x³)

(3) 6a - 8b = ............
(أ) 6 (a - 2b)
(ب) 4 (2a - 4b)
(ج) 2 (3a - 4b)
(د) 14 (a - b)

(4) x²y - xy² = ............
(أ) xy (x - y)
(ب) x²y (1 - y)
(ج) xy² (x - 1)
(د) xy (y - x)

(5) x (a + b) + y (a + b) = ............
(أ) (x - y) (a - b)
(ب) (x + y) (a + b)
(ج) (x - y) (a + b)
(د) (x + y) (a - b)

(6) إذا كان a - b = 7 ، x + y = 10 فإن :
x (a - b) - y (b - a) = ............
(أ) 3
(ب) 17
(ج) 51
(د) 70

اكتشف الخطأ :
(7) قام كل من سامح وإسلام بحل المعادلة 8x = 4x² كما هو موضح أمامك :
أي منهما حله صحيح ؟ ناقش.

حل سامح :
4x² = 8x
4x² / 4x = 8x / 4x
x = 2

حل إسلام :
4x² = 8x
4x² - 8x = 0
4x (x - 2) = 0
إما 4x = 0 ومنها x = 0
أو x - 2 = 0 ومنها x = 2
