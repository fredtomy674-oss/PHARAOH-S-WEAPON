أوجد مجموعة حل المعادلة :
0 = 4 - 2x - x² في R

مثال 5
أوجد مجموعة حل المعادلة : 0 = 3 + 8x - x² في R

x² - 8x + 3 = 0 ∴
x² - 8x = - 3 ∴
بإضافة (8x/2)² = 16 إلى طرفي المعادلة
x² - 8x + 16 = - 3 + 16 ∴
(x - 4)² = 13 ∴
x - 4 = ±√13 ∴
x = 4 ±√13 ∴
مجموعة الحل = {4 - √13 ، 4 + √13} ∴

لاحظ أن
لا نستطيع حل هذا المثال باستخدام تحليل ثلاثية الحدود، ولكن يمكن حله باستخدام إكمال المربع.

2a³ - 3a²b - 4ab + 6b²

مثال 6
إذا كان 8 = y - 2x ، 31 = 3y + x² ،
فما القيمة العددية للمقدار : 2x³ - x²y + 6xy - 3y² ؟

2x³ - x²y + 6xy - 3y² = (2x³ - x²y) + (6xy - 3y²)
= x² (2x - y) + 3y (2x - y)
= (2x - y) (x² + 3y) = 8 × 31 = 248

مثال 7

حجم الحوض = 5 م³

x (x - 2) (2x - 1) = 5 ∴
x (2x² - 5x + 2) = 5 ∴
(2x³ - 5x²) + (2x - 5) = 0 ∴
(2x - 5) (x² + 1) = 0 ∴
2x³ - 5x² + 2x - 5 = 0 ∴
x² (2x - 5) + (2x - 5) = 0 ∴
إما 0 = 5 - 2x ومنها x = 5/2 ∴
أو 0 = 1 + x² ومنها 1 - = x² (مرفوض)
