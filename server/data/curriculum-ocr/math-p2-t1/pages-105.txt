تقييم ذاتي (4)
في الشكل التالي :
ما عدد أضلاع المضلع المنتظم عند اكتمال رسمه بنفس النمط ؟

مثال (4)
أوجد عدد أضلاع المضلع المنتظم في كل مما يأتي :
1 إذا كان قياس إحدى زواياه الداخلة = 150°
2 إذا كان قياس إحدى زواياه الخارجة = 24°

1 ∵ المضلع منتظم وقياس إحدى زواياه الداخلة = 150°
(n - 2) × 180° / n = 150°
∴ 180° n - 360° = 150° n
∴ 180° n - 150° n = 360°
∴ 30° n = 360°
∴ n = 360° / 30° = 12
∴ عدد أضلاع المضلع = 12 ضلعًا.

2 ∵ المضلع منتظم وقياس إحدى زواياه الخارجة = 24°
360° / n = 24°
∴ 24° n = 360°
∴ n = 360° / 24° = 15
∴ عدد أضلاع المضلع = 15 ضلعًا.

الصيغة الرياضية لعدد أقطار المضلع المحدب
عدد أقطار المضلع المحدب الذي عدد أضلاعه n يساوي n (n - 3) / 2

تقييم ذاتي (5)
أوجد كلاً مما يأتي :
1 عدد أقطار المضلع الخماسي المحدب.
2 عدد أضلاع مضلع محدب له 27 قطرًا.

مثال (5)
1 أوجد عدد أقطار المضلع الثماني المحدب.
2 أوجد عدد أضلاع مضلع محدب عدد أقطاره 35 قطرًا.

1 عدد أقطار المضلع الثماني المحدب = n (n - 3) / 2 = 8 (8 - 3) / 2 = 20 قطرًا.

2 ∵ عدد الأقطار = 35
n (n - 3) / 2 = 35
∴ n (n - 3) = 70
∴ n² - 3 n - 70 = 0
∴ (n + 7) (n - 10) = 0
∴ إما n + 7 = 0 ومنها n = - 7 (مرفوض)
أو n - 10 = 0 ومنها n = 10
∴ عدد الأضلاع = 10 أضلاع.
