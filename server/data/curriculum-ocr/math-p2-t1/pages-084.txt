مثال 1
في الشكل المقابل :
l1 // l2 // l3 // l4
المستقيمان t1 ، t2 قاطعان لهم.
أوجد قيمة كل من x ، y.

l1 A t1 t2
l2 B 4x سم
l3 C 8 سم
l4 D (y+1) سم

∴ l1 // l2 // l3 // l4 ، AB = BC = CD
∴ 4x = 8
∴ x = 8/4 = 2
y + 1 = 8
∴ y = 8 - 1 = 7
