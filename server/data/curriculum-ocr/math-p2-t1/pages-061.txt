إكمال المربع
إكمال المربع هو عملية إضافة حد إلى ثنائية حدود لتصبح ثلاثية حدود على صورة مربع كامل.
يمكن أن يتم إكمال المربع بإحدى الطريقتين الآتيتين :
1 إما إضافة (الحد الأوسط) = (الحد الثالث √ × الحد الأول √ 2±)
فمثلاً : (49 + 2x) يُضاف إليها 49 √ 2x ± = 14x ±
فيكون (49 + 14x + 2x) مربعاً كاملاً أي يكتب على الصورة (7 ± x)2
2 وإما إضافة (الحد الثالث) = (مربع الحد الأوسط) / (4 × الحد الأول)
فمثلاً : (10x + 2x) يُضاف إليها 25 = (10x)2 / 4x2
فيكون (25 + 10x + 2x) مربعاً كاملاً أي يكتب على الصورة (5 + x)2
والأمثلة التالية توضح ذلك.

تقييم ذاتي 4
حلل كلاً مما يأتي :
1) 64 + 4x
2) 9 + 11x2 + 4x4

لاحظ أن
لتحليل كثيرات الحدود التي تشتمل على حدين على الأقل كل منهما مربع كامل، وأسس متغيراتها تكون 4 أو مضاعفاتها، نستخدم طريقة إكمال المربع وذلك بإضافة وطرح (ضعف حاصل ضرب جذري الحدين المربعين) حتى لا تؤثر على قيمة كثيرة الحدود، ثم يتم التحليل بالتقسيم.

مثال 4
حلل كلاً مما يأتي :
1) 4 + 81x4
2) 64y4 + 15x2y2 + x4

1
4 + 81x4 = 81x4 + 4 + 36x2 - 36x2
« إضافة وطرح 36x2 = 2√81x4 √4 »
= (81x4 + 36x2 + 4) - (36x2)
= (9x2 + 2)2 - (6x)2
= (9x2 + 2 - 6x) (9x2 + 2 + 6x)
= (9x2 - 6x + 2) (9x2 + 6x + 2)

2
64y4 + 15x2y2 + x4 = x4 + 15x2y2 + 64y4 + 16x2y2 - 16x2y2
« إضافة وطرح 16x2y2 = 2√x4 √64y4 »
= (x4 + 16x2y2 + 64y4) + 15x2y2 - 16x2y2
= (x2 + 8y2)2 - x2y2
= (x2 + 8y2 - xy) (x2 + 8y2 + xy)
