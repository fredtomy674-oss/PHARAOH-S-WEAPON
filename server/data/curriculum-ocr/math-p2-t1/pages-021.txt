خواص العمليات على الأعداد الحقيقية
إذا كانت : a , b , c ثلاثة أعداد حقيقية، فإن :

| الخاصية | عملية الجمع | عملية الضرب |
| :--- | :--- | :--- |
| الانغلاق | a + b ∈ R | a × b ∈ R |
| الإبدال | a + b = b + a | a × b = b × a |
| الدمج (التجميع) | (a + b) + c = a + (b + c) | (a × b) × c = a × (b × c) |
| توزيع الضرب على الجمع | | a (b + c) = a b + a c |
| المحايد | المحايد الجمعي هو 0 <br> a + 0 = 0 + a = a | المحايد الضربي هو 1 <br> a × 1 = 1 × a = a |
| المعكوس | المعكوس الجمعي للعدد a <br> هو (- a) <br> حيث : a + (- a) = 0 | المعكوس الضربي للعدد a <br> هو 1/a (حيث a ≠ 0) <br> حيث : a × 1/a = 1 |

■ فكر وناقش
لأي ثلاثة أعداد حقيقية a , b , c
1 هل a - b = b - a ؟
2 هل a/b = b/a ؟
3 هل a/b ∈ R ؟
4 هل a (b - c) = ab - ac ؟

(2 + 5√) = y
فأوجد في أبسط صورة قيمة
المقدار x² - y²

■ معلومة سابقة
• (x + y) (x - y) = x² - y²
• (x + y)² = x² + 2xy + y²
• (x - y)² = x² - 2xy + y²

3) (1 - 2√) (1 + 2√)
4) (5 - 5√)²

1) 3√4 - (3√ + 4) 3√2 = 3√4 - 3√ × 4 + 3√ × 3√2
= 3√4 - 6 + 3 × 2
= 3√4 - 6 + 3√8
= 6 + 3√4 - 3√8 = 6 + 3√4 - 3√4
2) (3 + 7√) (1 - 7√) = 7√ × 1 - 7√ × 7√ + 3 × 1 - 3 × 7√
= 7√ - 7 + 3 - 3 7√
= (3 - 7) + (7√ - 3 7√)
= 4 - 2 7√
3) (1 - 2√) (1 + 2√) = (1)² - (2√)² = 1 - 2 = 1 -
4) (5 - 5√)² = (5)² + (2 × 5√ × (5-)) + (5-)²
= 25 - 5 20 + 25
= 50 - 5 20
