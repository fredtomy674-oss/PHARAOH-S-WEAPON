مثال 5
حلل كلا مما يأتي :
1) 1/4 x^2 - 1/25 y^2
2) 8 y^3 - 1/27
3) a^3 b^3 + 1/216
4) 1/4 x^2 + 2/3 x + 4/9

لاحظ أن
يمكن تحليل كثيرات حدود تحتوي على معاملات وثوابت نسبية إلى حاصل ضرب عوامل كل عامل منها عبارة عن كثيرة حدود تحتوي أيضا على معاملات وثوابت نسبية.

1) 1/4 x^2 - 1/25 y^2 = (1/2 x - 1/5 y) (1/2 x + 1/5 y)
2) 8 y^3 - 1/27 = (2y - 1/3) (4y^2 + 2/3 y + 1/9)
3) a^3 b^3 + 1/216 = (ab + 1/6) (a^2 b^2 - 1/6 ab + 1/36)
4) 1/4 x^2 + 2/3 x + 4/9 = (1/2 x + 2/3)^2

مثال 6
حلل كلا مما يأتي تحليلا تاما :
1) 5x^5 - 320x^2
2) 16x^4 - y^4
3) 64 - (a + b)^2
4) 12x - 9x^2 - 4

لاحظ أن
يتم أخذ العامل المشترك الأكبر أولا ثم نحلل القوس الناتج إن أمكن.

1) 5x^5 - 320x^2 = 5x^2 (x^3 - 64)
= 5x^2 (x - 4) (x^2 + 4x + 16)
2) 16x^4 - y^4 = (4x^2 - y^2) (4x^2 + y^2)
= (2x - y) (2x + y) (4x^2 + y^2)
3) رتب أولا كثيرة الحدود تنازليا حسب أسس x كالتالي :
-9x^2 + 12x - 4 = -(9x^2 - 12x + 4)
= -(3x - 2)^2
4) 64 - (a + b)^2 = (8 + (a + b)) (8 - (a + b))
= (8 + a + b) (8 - a - b)

لاحظ أن
كثيرة الحدود (-9x^2 + 12x - 4) ليست مربعا كاملا، أما كثيرة الحدود (9x^2 - 12x + 4) فهي مربع كامل.
