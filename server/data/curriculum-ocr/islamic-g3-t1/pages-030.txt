مُرَاجَعَةٌ عَلَى الْوَحْدَةِ الْأُولَى

* اخْتَرِ الْإِجَابَةَ الصَّحِيحَةَ مِمَّا بَيْنَ الْقَوْسَيْنِ:
١ أَرْكَانُ الْإِيمَانِ (أَرْبَعَةٌ - خَمْسَةٌ - سِتَّةٌ)
٢ طَلَبَ زَكَرِيَّا عَلَيْهِ السَّلَامُ مِنَ اللَّهِ (تَعَالَى) (وَلَدًا صَالِحًا - مَالًا كَثِيرًا - بَيْتًا كَبِيرًا)
٣ مِنْ أَرْكَانِ الْإِيمَانِ (صَوْمُ رَمَضَانَ - الْإِيمَانُ بِالْمَلَائِكَةِ - حَجُّ الْبَيْتِ)
٤ دَوْرُ النَّبِيِّ ﷺ نَحْوَ قَوْمِهِ (الدَّعْوَةُ إِلَى الْحَقِّ - إِجْبَارُهُمْ عَلَى الْإِيمَانِ - الدُّعَاءُ عَلَيْهِمْ)
٥ نُصَلِّي الْجُمُعَةَ فِي وَقْتِ (الظُّهْرِ - الْفَجْرِ - الْعَصْرِ)
٦ حَزِنَ الرَّسُولُ ﷺ لِوَفَاةِ عَمِّهِ الَّذِي كَانَ يَحْمِيهِ مِنْ إِيذَاءِ الْكُفَّارِ. (أَبِي لَهَبٍ - أَبِي طَالِبٍ - الْعَبَّاسِ)

* ضَعْ (✓) أَمَامَ الصَّحِّ وَ (X) أَمَامَ الْخَطَأُ:
١ الْإِيمَانُ سَبَبُ سَعَادَةِ الْإِنْسَانِ فِي الدُّنْيَا وَالْآخِرَةِ. ( )
٢ نَزَلَتْ سُورَةُ الْغَاشِيَةِ فِي الْمَدِينَةِ الْمُنَوَّرَةِ. ( )
٣ تَدْعُونَا سُورَةُ الْغَاشِيَةِ إِلَى التَّأَمُّلِ فِي مَخْلُوقَاتِ اللَّهِ (تَعَالَى). ( )
٤ فِي يَوْمِ الْجُمُعَةِ نُصَلِّي، ثُمَّ نَسْتَمِعُ إِلَى الْخُطْبَةِ. ( )
٥ اشْتَدَّتِ الْمَصَائِبُ عَلَى رَسُولِ اللَّهِ ﷺ فِي عَامِ الْحُزْنِ. ( )
٦ اسْتَجَابَ اللَّهُ (تَعَالَى) لِدُعَاءِ نَبِيِّهِ زَكَرِيَّا عَلَيْهِ السَّلَامُ. ( )
٧ الْمُؤْمِنُ الَّذِي يَثِقُ بِاللَّهِ لَا يَقْلَقُ وَلَا يَخَافُ. ( )

* أَجِبْ عَنِ الْأَسْئِلَةِ الْآتِيَةِ:
١ اذْكُرْ ثَلَاثَةً مِنْ أَرْكَانِ الْإِيمَانِ.
٢ مَا مَصِيرُ الْكَافِرِينَ يَوْمَ الْقِيَامَةِ؟
٣ لِمَاذَا سُمِّيَ عَامُ الْحُزْنِ بِهَذَا الِاسْمِ؟
