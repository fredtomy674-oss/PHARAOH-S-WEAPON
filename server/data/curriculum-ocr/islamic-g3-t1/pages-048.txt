نشاط (٣) اخْتَرِ الإِجَابَةَ الصَّحِيحَةَ:

١ لِمَاذَا ذَهَبَ النَّبِيُّ ﷺ إِلَى الطَّائِفِ؟
(أ) لِلرَّاحَةِ وَالنُّزْهَةِ. (ب) لِدَعْوَةِ أَهْلِهَا لِلإِسْلَامِ. (ج) لِزِيَارَةِ أَصْدِقَائِهِ.

٢ مَاذَا فَعَلَ النَّبِيُّ ﷺ حِينَ رَمَوْهُ بِالْحِجَارَةِ؟
(أ) دَعَا اللَّهَ أَنْ يَهْدِيَهُمْ. (ب) غَضِبَ وَتَرَكَ المَدِينَةَ. (ج) قَاتَلَهُمْ.

٣ اسْتَقْبَلَتْ قَبِيلَةُ ثَقِيفٍ دَعْوَةَ النَّبِيِّ ﷺ بِـ
(أ) التَّرْحِيبِ وَالإِسْلَامِ. (ب) الاسْتِمَاعِ وَالمُنَاقَشَةِ. (ج) الرَّفْضِ وَالتَّكْذِيبِ.

٤ طَلَبَ مَلَكُ الجِبَالِ مِنَ النَّبِيِّ ﷺ أَنْ
(أ) يُطْبِقَ الجِبَالَ عَلَى أَهْلِ الطَّائِفِ.
(ب) يُعِيدَ بِنَاءَ الطَّائِفِ.
(ج) يَنْصُرَ النَّبِيُّ ﷺ بِسِلَاحٍ قَوِيٍّ.

نشاط (٤) ضَعْ (✓) أَمَامَ الصَّحِّ، وَ(X) أَمَامَ الْخَطَأِ:
١ تَوَجَّهَ النَّبِيُّ ﷺ إِلَى الطَّائِفِ بَعْدَ وَفَاةِ أَبِي طَالِبٍ وَالسَّيِّدَةِ خَدِيجَةَ. ( )
٢ رَحَّبَ أَهْلُ الطَّائِفِ بِدَعْوَةِ النَّبِيِّ ﷺ وَأَسْلَمُوا جَمِيعًا. ( )
٣ دَعَا النَّبِيُّ ﷺ عَلَى أَهْلِ الطَّائِفِ بَعْدَ أَنْ آذَوْهُ. ( )
٤ أَرْسَلَ اللَّهُ ﷺ مَلَكَ الجِبَالِ لِيَسْتَأْذِنَ النَّبِيَّ ﷺ فِي إِهْلَاكِ أَهْلِ الطَّائِفِ. ( )
