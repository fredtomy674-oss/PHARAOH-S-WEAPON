الْأَنْشِطَةُ وَالتَّدْرِيبَاتُ

نَشَاط (١) امْلَأِ الْبِطَاقَةَ الْآتِيَةَ بِمَا تَعَلَّمْتَهُ مِنْ قِصَّةِ عِيسَى عَلَيْهِ السَّلَامُ:

نَشَاط (٢) ضَعْ (✓) أَمَامَ الصَّحِّ، وَ(X) أَمَامَ الْخَطَأِ:
١ وَلَدَتِ السَّيِّدَةُ مَرْيَمُ عِيسَى عَلَيْهِ السَّلَامُ تَحْتَ نَخْلَةٍ بِمُعْجِزَةٍ مِنَ اللَّهِ (تَعَالَى). ( )
٢ نَجَّى اللَّهُ عَلَيْهِ السَّلَامُ عِيسَى عَلَيْهِ السَّلَامُ مِنَ الْيَهُودِ. ( )
٣ كَانَ عِيسَى عَلَيْهِ السَّلَامُ يَعْبُدُ اللَّهَ (تَعَالَى) وَحْدَهُ. ( )
٤ كَانَ لِلسَّيِّدَةِ مَرْيَمَ مِحْرَابٌ خَاصٌّ بِهَا لِلْعِبَادَةِ. ( )
٥ اعْتَزَلَتِ السَّيِّدَةُ مَرْيَمُ عَلَيْهَا السَّلَامُ قَوْمَهَا عِنْدَمَا اقْتَرَبَ مَوْعِدُ الْوِلَادَةِ. ( )
٦ تَكَلَّمَ سَيِّدُنَا عِيسَى عَلَيْهِ السَّلَامُ وَهُوَ طِفْلٌ رَضِيعٌ. ( )
٧ كَانَ عِيسَى عَلَيْهِ السَّلَامُ يُحْيِي الْمَوْتَى بِإِذْنِ اللَّهِ (تَعَالَى). ( )
٨ يُؤَيِّدُ اللَّهُ (تَعَالَى) رُسُلَهُ وَأَنْبِيَاءَهُ بِالْمُعْجِزَاتِ. ( )
