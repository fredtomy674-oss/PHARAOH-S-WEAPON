نشاط (٣) اخْتَرِ الإِجَابَةَ الصَّحِيحَةَ:
١ مَنْ الَّذِي يُحِبُّهُ الْمُؤْمِنُ أَوَّلًا؟
(أ) أَصْدِقَاءَهُ (ب) اللَّهَ (ج) نَفْسَهُ

٢ مَاذَا نَفْعَلُ لِنُظْهِرَ مَحَبَّتَنَا لِلنَّاسِ؟
(أ) نُسَاعِدُهُمْ. (ب) نَبْتَسِمُ لَهُمْ. (ج) كِلَاهُمَا صَوَابٌ.

٣ لِكَيْ تَشْعُرَ بِمَحَبَّةِ اللَّهِ عَلَيْكَ أَنْ:
(أ) تَعْتَذِرَ عَنْ أَخْطَائِكَ. (ب) تَتَفَكَّرَ فِي نِعَمِ اللَّهِ. (ج) تَصْبِرَ عَلَى مَا أَصَابَكَ.

نشاط (٤) ضَعْ (✓) أَمَامَ الصَّحِّ، وَ(X) أَمَامَ الْخَطَأِ:
١ الْمُؤْمِنُ يُحِبُّ اللَّهَ وَرَسُولَهُ فَقَطْ، وَلَا يُحِبُّ النَّاسَ. ( )
٢ الْمَحَبَّةُ تَجْعَلُ الْقَلْبَ سَعِيدًا. ( )
٣ الْمَحَبَّةُ الْحَقِيقِيَّةُ تَظْهَرُ فِي الْأَقْوَالِ فَقَطْ دُونَ الْحَاجَةِ إِلَى الْأَفْعَالِ. ( )
٤ مَحَبَّةُ الْمُؤْمِنِ تَشْمَلُ حُبَّ اللَّهِ وَرَسُولِهِ، وَحُبَّ أُسْرَتِهِ، وَحُبَّ الْمُجْتَمَعِ، وَحُبَّ جَمِيعِ النَّاسِ. ( )
٥ كَانَ النَّبِيُّ ﷺ يُقَابِلُ الْإِسَاءَةَ بِالْإِسَاءَةِ. ( )

شَارِكْ أُسْرَتَكَ
• شَارِكْ زُمَلَاءَكَ فِي مَجْمُوعَاتٍ، وَأَجِيبُوا عَنِ الْأَسْئِلَةِ الْآتِيَةِ:
• لِمَاذَا نُحِبُّ كُلًّا مِنَ:
١ اللَّهَ تَعَالَى:
٢ رَسُولَ اللَّهِ ﷺ:
٣ أُسْرَتَنَا:
٤ الْبَشَرَ جَمِيعًا:
