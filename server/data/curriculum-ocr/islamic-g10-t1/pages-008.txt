التربية الدينية الإسلامية
الوحدة الأولى

{ لَوْ كَانَ فِيهِمَا آلِهَةٌ إِلَّا اللَّهُ لَفَسَدَتَا فَسُبْحَانَ اللَّهِ رَبِّ الْعَرْشِ عَمَّا يَصِفُونَ } وهي الآية رقم ٢٢ من سورة الأنبياء، وتأتي الآية رقم ٢٤ في نفس السورة { أَمِ اتَّخَذُوا مِن دُونِهِ آلِهَةً قُلْ هَاتُوا بُرْهَانَكُمْ هَذَا ذِكْرُ مَن مَّعِيَ وَذِكْرُ مَن قَبْلِي بَلْ أَكْثَرُهُمْ لَا يَعْلَمُونَ الْحَقَّ فَهُم مُّعْرِضُونَ }
برهانكم : دليلكم. ذكر من معي : القرآن الكريم. ذكر من قبلي : كتب الأنبياء السابقين.

وفي سورة المؤمنون { مَا اتَّخَذَ اللَّهُ مِن وَلَدٍ وَمَا كَانَ مَعَهُ مِنْ إِلَهٍ إِذًا لَّذَهَبَ كُلُّ إِلَهٍ بِمَا خَلَقَ وَلَعَلَا بَعْضُهُمْ عَلَى بَعْضٍ سُبْحَانَ اللَّهِ عَمَّا يَصِفُونَ } (المؤمنون: ٩١)
{ يَا صَاحِبَيِ السِّجْنِ أَأَرْبَابٌ مُّتَفَرِّقُونَ خَيْرٌ أَمِ اللَّهُ الْوَاحِدُ الْقَهَّارُ * مَا تَعْبُدُونَ مِن دُونِهِ إِلَّا أَسْمَاءً سَمَّيْتُمُوهَا أَنتُمْ وَآبَاؤُكُم مَّا أَنزَلَ اللَّهُ بِهَا مِن سُلْطَانٍ إِنِ الْحُكْمُ إِلَّا لِلَّهِ أَمَرَ أَلَّا تَعْبُدُوا إِلَّا إِيَّاهُ ذَلِكَ الدِّينُ الْقَيِّمُ وَلَكِنَّ أَكْثَرَ النَّاسِ لَا يَعْلَمُونَ } (يوسف: ٣٩ - ٤٠)

هل تعلم: من صفات الكمال لله :
العلم: { عَالِمُ الْغَيْبِ وَالشَّهَادَةِ } وجاءت صفته "العليم" ٣٢ مرة في القرآن الكريم
{ أَلَمْ يَعْلَمُوا أَنَّ اللَّهَ يَعْلَمُ سِرَّهُمْ وَنَجْوَاهُمْ وَأَنَّ اللَّهَ عَلَّامُ الْغُيُوبِ } (التوبة: ٧٨)

إذا تأملت الآيات السابقة بتدبر وتفكير سليم فستجد أنها تخاطب العقل السليم، وتقدم الأدلة العقلية على وحدانية الله؛ فلو لم يكن واحدا لكانوا أكثر من واحد، ولو كانوا كذلك لاختلفوا وتقاتلوا فيما بينهم، فهذا يريد شيئا وغيره لا يريده، وهل يرضى إله بأن يقع في ملكه ما لا يريد؟ وبناء عليه فإن المعارك بينهم سوف تشتعل، ويتفرغون لحرب بعضهم البعض، ويتركون الكون بدون إله يدبر أمره فتفسد الحياة، وصدق المولى الكريم حين قال: { لَوْ كَانَ فِيهِمَا آلِهَةٌ إِلَّا اللَّهُ لَفَسَدَتَا فَسُبْحَانَ اللَّهِ رَبِّ الْعَرْشِ عَمَّا يَصِفُونَ } (الأنبياء: ٢٢)

قد يرد مدع ويقول : فليقسموا الخلق بينهم؛ لو فعلوا ذلك لاستقل كل إله بخلقه فتتعارض المصالح فيتقاتلون ويتصارعون ويريد كل منهم الاستيلاء والاستعلاء، وإن كانوا اثنين فسيحدث بينهما اختلاف وتنافس - أيضا - فإذا انهزم أحدهما أيصلح أن يكون إلها مع ضعفه وانكساره؟
{ مَا اتَّخَذَ اللَّهُ مِن وَلَدٍ وَمَا كَانَ مَعَهُ مِنْ إِلَهٍ إِذًا لَّذَهَبَ كُلُّ إِلَهٍ بِمَا خَلَقَ وَلَعَلَا بَعْضُهُمْ عَلَى بَعْضٍ سُبْحَانَ اللَّهِ عَمَّا يَصِفُونَ } (الأنبياء: ٩١)

وقوله تعالى "ما اتخذ الله من ولد" ترد على من ادعوا بأن عزيرا ابن الله، وعلى من ادعوا بأن المسيح ابن الله { وَقَالَتِ الْيَهُودُ عُزَيْرٌ ابْنُ اللَّهِ وَقَالَتِ النَّصَارَى الْمَسِيحُ ابْنُ اللَّهِ } (التوبة: ٣٠)
