٢. ضع علامة (✓) أو (x) أمام كل عبارة مما يأتي:
أ. توفر مواقع المعلومات المتخصصة بيانات دقيقة ومُحدَّثة حول موضوعات معينة. ( )
ب. جميع المعلومات الموجودة على الإنترنت موثوقة ويمكن الاعتماد عليها دائمًا. ( )
ج. يمكن لمواقع المعلومات العامة والمتخصصة أن تكون مفيدة عند البحث عن الاحتباس الحراري. ( )

٣. تخيل أنك مكلف بتصميم حملة إلكترونية لتوعية زملائك حول الاحتباس الحراري.
أ. حدد نوع المعلومات التي ستجمعها، والمواقع التي ستعتمد عليها.
ب. اقترح وسيلة لنشر المعلومات (مثل منشور إلكتروني، فيديو، إنفوجرافيك).
ج. اشرح كيف ستتأكد من صحة المعلومات قبل نشرها.
