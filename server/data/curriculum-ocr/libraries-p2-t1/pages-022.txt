المكتبات ومهارات البحث

٢. ضع علامة (✓) أو (✗) أمام كل عبارة مما يأتي:
أ. المكتبة المدرسية تهدف إلى حفظ التراث الوطني. ( )
ب. المكتبة الرقمية تتيح الوصول إلى المعلومات عبر الإنترنت. ( )
ج. المكتبة العامة تقدم خدماتها لجميع فئات المجتمع. ( )
٣. زُرت مكتبة في منطقتك (مدرسية، عامة، متخصصة، وطنية، أو رقمية). اكتب تقريرًا موجزًا تصف فيه تجربتك، واذكر نوع المكتبة والخدمة التي استفدت منها.
أرفق صورة أو ارسم شكلًا يعبّر عن المكتبة ونشاطها الأساسي.
