تقييم الوحدة الأولى

السؤال الأول: أمامك خريطة صماء للوطن العربي، حدد ما يلي عليها:
١ - أكبر دول الوطن العربي من حيث المساحة.
٢ - جبال أطلس.
٣ - هضبة حضرموت.
٤ - نهر يمر في أكثر من دولة عربية إفريقية.
٥ - دولة عربية تقع في المحيط الهندي.
٦ - دولة تطل على بحر ومحيط.

السؤال الثاني: اكتب كلمة (صواب) أمام العبارة الصحيحة، وكلمة (خطأ) أمام العبارة غير الصحيحة:
١ - يمتد الوطن العربي بين قارتي آسيا وأوروبا. ( )
٢ - أحد العوامل المؤثرة في المناخ الموقع الفلكي. ( )
٣ - توجد سهول فيضية في العراق ومصر. ( )
٤ - تقع جبال أطلس في شبه الجزيرة العربية. ( )
٥ - نهر النيل من السهول الخصبة في الوطن العربي. ( )
٦ - يفصل البحر الأحمر بين جناحي وطننا العربي. ( )
٧ - جبال البحر الأحمر من الجبال الالتوائية في وطننا العربي. ( )
٨ - أكبر هضاب الوطن العربي تقع في الجناح الإفريقي. ( )
٩ - يسود المناخ الصحراوي معظم أراضي الوطن العربي. ( )
١٠ - يؤدي التنوع المناخي إلى تنوع النبات الطبيعي. ( )
