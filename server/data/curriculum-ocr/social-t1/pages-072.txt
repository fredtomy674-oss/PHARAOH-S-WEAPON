تقييم الوحدة الثانية

السؤال الأول: اكتب كلمة (صواب) أمام العبارة الصحيحة، وكلمة (خطأ) أمام العبارة غير الصحيحة:
١ - الدولة الإسلامية بدأت بعد وفاة النبي (ﷺ). ( )
٢ - هجرة المسلمين الأولى كانت إلى الحبشة. ( )
٣ - أبو بكر الصديق (رضي الله عنه) هو أول من جمع القرآن الكريم. ( )
٤ - الخلفاء الراشدون (رضي الله عنهم) عددهم أربعة. ( )
٥ - نشأت الدولة الأموية في المدينة. ( )
٦ - فُتحت العراق على يد سعد بن أبي وقاص في خلافة عمر بن الخطاب (رضي الله عنه). ( )
٧ - عمر بن الخطاب (رضي الله عنه) كان أول من أدخل الدواوين إلى الدولة الإسلامية. ( )
٨ - العباسيون اهتموا بالفتوحات العسكرية فقط. ( )
٩ - كانت بغداد هي عاصمة الدولة العباسية بداية من عصر أبي جعفر المنصور. ( )
