مراجعة عامة على
الفصل الدراسي الأول

السؤال الأول: اكتب كلمة (صواب) أمام العبارة الصحيحة، وكلمة (خطأ) أمام
العبارة غير الصحيحة فيما يلي:
١ - يمتد الوطن العربي في قارتي آسيا وإفريقيا. ( )
٢ - تسود الغابات الاستوائية في معظم أراضي الوطن العربي. ( )
٣ - عاصمة الدولة العباسية كانت دمشق. ( )
٤ - الهجرة النبوية كانت بسبب حماية الدعوة. ( )
٥ - تسهم السياحة في دعم الاقتصاد العربي. ( )
٦ - الطاقة الشمسية من مصادر الطاقة المتجددة. ( )
٧ - من نتائج الهجرة تأسيس مجتمع إسلامي في المدينة. ( )
٨ - يُعد بيت الحكمة مركزًا للترجمة والبحث العلمي. ( )
٩ - الخلافة هي نظام حكم إسلامي. ( )
١٠ - تعد الرياح من مصادر الطاقة غير المتجددة. ( )
١١ - أشهر القبائل في شبه الجزيرة العربية قبيلة قريش. ( )
١٢ - من عادات العرب الحسنة قبل الإسلام الكرم والشجاعة. ( )
١٣ - فُتحت العراق على يد سعد بن أبي وقاص في خلافة عمر بن الخطاب. ( )
١٤ - وصلت الدولة الإسلامية إلى أقصى اتساع لها في عهد الأمويين. ( )
١٥ - أسس معاوية بن أبي سفيان مدينة القيروان بتونس. ( )

السؤال الثاني: اختر الإجابة الصحيحة مما بين القوسين:
١ - من المحاصيل السكرية في الوطن العربي ........................ (القطن - القمح - الكتان - قصب السكر)
٢ - أنشأ مكتبة بيت الحكمة الخليفة ........................ (هارون الرشيد - المنصور - عمر - معاوية)
٣ - الطاقة الكهرومائية تنتج من ........................ (الرياح - السدود - الشمس - البترول)
٤ - صناعة السيارات تعتمد على معدن ........................ (الكبريت - الحديد - الذهب - النحاس)
٥ - الدولة الأموية اتخذت عاصمتها في ........................ (المدينة - الكوفة - بغداد - دمشق)
٦ - الفتوحات الإسلامية انتشرت في عهد الخليفة ........................ (عثمان - عمر - علي - أبي بكر)
٧ - الدولة الإسلامية بعد وفاة النبي (ﷺ) قادها ........................
(معاوية - أبو بكر - العباس - خالد بن الوليد)
