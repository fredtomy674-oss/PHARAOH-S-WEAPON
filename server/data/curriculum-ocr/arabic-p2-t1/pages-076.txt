القَوَاعِدُ الإِمْلَائِيَّةُ
( الأَلِفُ اللَّيِّنَةُ فِي الحُرُوفِ )

أَقْرَأُ الأَمْثِلَةَ الآتِيَةَ، وَأَتَأَمَّلُ الكَلِمَاتِ المُلَوَّنَةَ:

١. لَا تُضَيِّعْ وَقْتَكَ.
٣. مَا أغضبتُ والِدَيَّ قَطُّ.
٥. يَا أبناء مصر، صُونُوا لها حقَّها.

٢. احرص على مُذاكرتك.
٤. أَلَم تَذْهَب إِلى المَدرَسَةِ؟ بَلَى، ذَهَبْتُ.
٦. جَدَّ واجتهد؛ حَتَّى تَكُونَ ذا شأنٍ.

أَلاحِظُ

١ الكلمات الملونة باللون الأحمر انتهت بِأَلِفٍ ساكِنَةٍ كُتِبَتْ أَلِفًا.
٢ الكلمات الملونة باللون الأخضر انتهت بِأَلِفٍ ساكِنَةٍ كُتِبَتْ يَاءً.

أَسْتَنْتِجُ:

• هُنَاكَ حُرُوف في اللُّغَةِ العَرَبِيَّةِ تُنْتَهي بِأَلِفِ نُطْقًا وكتابَةً، مِثْلُ: (لَا - يَا - مَا).
• هُنَاكَ حُرُوف تُنْتَهي بِأَلِفٍ نُطْقًا ولكِنْ ياء كتابةً، مِثْلُ: (عَلَى - حَتَّى - إِلَى - بَلَى).
• كِلَا الشَّكْلَيْنِ يُسَمَّى بالأَلِف اللينة.

نَشاط ( ١ ) : أَضَعُ علامةَ (√) أمام العِبَارَةِ الصَّحِيحَةِ إِمْلَائِيًّا، وعلامة (X) أمام العِبَارَة غير الصحيحة إِمْلَائِيًّا فيما يَلِي:

١. اسم بأخلاقك؛ حَتَّى يَعْلُو شأنُك. ( )
٢. حققنا النصر عَلا العدو. ( )
٣. أَلَيْسَتْ الطَّبِيعَة مُذهلةً؟ بَلَى، مُذْهِلةً. ( )

نَشاط ( ٢ ) : أُكْمِلُ الجُمَلَ الآتِيَةَ بِكِلْمَةٍ تُنْتَهي بِأَلِفٍ لَيِّنَةٍ:

١. .......... قَرَأْتُ الكِتَابَ بَعْد.
٢. استمعتُ .............. المُعَلِّم باهتمام.
٣. .......... طالب العِلْمِ، الطَّرِيق طويل، لَكِنَّ ثِمَاره عَظِيمَة.
٤. .......... تُؤْذِ غَيْرَكَ بِكِلْمَة؛ فَالكَلمَاتِ سهام لَا تَرَى.
