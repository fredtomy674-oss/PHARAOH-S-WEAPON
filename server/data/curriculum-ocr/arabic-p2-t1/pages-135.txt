القواعدُ الإِمْلائِيَّةُ
(تَطْبِيقَاتٌ عَلَى التَّاءِ المَرْبُوطَةِ وَالتَّاءِ المَفْتُوحَةِ وَالهَاءِ)

نَشَاطُ (١) : أَضَعُ عَلامَةَ (√) أَمَامَ العِبَارَةِ الصَّحِيحَةِ إِمْلَائِيًّا، وعلامةَ (X) أَمَامَ العِبَارَةِ غيرِ الصحيحةِ إمْلَائِيًّا فيما يلي:

١. نُقْطَةُ مياةٍ تُسَاوِي حَيَاةً.
( )

٢. الصلاةُ عمادُ الدِّينِ.
( )

٣. لَيْتَ الشبابَ يعودُ يَومًا.
( )

٤. الفواكه غنيَّةٌ بالفيتَامِينَاْتِ.
( )

نَشَاطُ (٢) : أُمَثِّلُ بِجُمَلٍ مِنْ إِنْشَائِي بِكَلِمَاتٍ تَنْتَهي بِـ:

١. تاءٍ مَرْبُوطَةٍ: ...................

٢. تاءٍ مَفْتُوحَةٍ: ...................

٣. هَاءٍ: ...................

نَشَاطُ (٣) : أَتَخَيَّرُ الإجابة الصحيحةَ مِنْ بينِ القَوْسَيْنِ مَمَّا يَلِي:

١. هَذِهِ سَيَّارُ ............... أَبِي.
(ه - ة - ت).

٢. قَرَأْتُ قِصَّ ............... مُفِيدَة.
(ة - ت - ه).

٣. تَحْتَاجُ التُّرْبُ ............... إِلَى التَّهْوِي ............... الجيِّدة.
(هـ، ة - هـ، هـ - ة، ة).

٤. نَشَأَ ............... الابنةُ على حُبِّ القراءةِ.
(ة - ت - ه).
