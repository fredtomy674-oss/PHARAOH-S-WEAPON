د حِمَايَةِ البِحَارِ وَالأَنْهَارِ، وَالاسْتِفَادَةِ مِنْهَا دُونَ الإِضْرَارِ بِهَا».
مِنْ خِلَالِ اسْتِفَادَتِي مِمَّا دَرَسْتُ فِي مَادَّتَيْ العُلُومِ وَالدِّرَاسَاتِ الاجْتِمَاعِيَّةِ،
أُقَدِّمُ مُقْتَرَحَاتِ غَيْرَ نَمَطِيَّةٍ لِتَحْقِيقِ مَا وَرَدَ فِي العِبَارَةِ السَّابِقَةِ.

أَتَدَوَّقُ المَفْرُوءَ، وَأُنْقِدُهُ
أُحَدِّدُ مِنَ النَّصِّ مَا يَدْعَمُ فِكْرَةَ: «أَيَّةُ جُهُودٍ مُخْلِصَةٍ سَوْفَ تُؤْتِي ثِمَارَهَا المَرْجُوَّةَ، المُهِمُّ أَنْ نَبْدَأَ».
أَذْكُرُ رَأْيِي فِيمَا وَرَدَ فِي العِبَارَةِ التَّالِيَةِ:
«التَّنْمِيَةُ السِّيَاحِيَّةُ بِإِقَامَةِ مَشْرُوعَاتِ سِيَاحِيَّةٍ عَلَى شَوَاطِئِ البَحْرِ الأَحْمَرِ، مَعَ الحِفَاظِ عَلَيْهِ مِنَ التَّلَوُّثِ».
أُمَيِّزُ الفِكْرَةَ المُبَاشِرَةَ مِنَ الضِّمْنِيَّةِ بِوَضْعِ عَلَامَةِ (√) كَالْمِثَالِ:

| نَوْعُهَا | الفِكْرَةُ |
| --- | --- |
| ضِمْنِيَّةٌ | مُبَاشِرَةٌ |
| | ١. «أَطْلَقَتِ الدَّوْلَةُ مُبَادَرَةَ (تَحَضَّرْ لِلْأَخْضَرِ)؛ لِتَشْجِيعِ <br> اسْتِخْدَامِ الطَّاقَةِ النَّظِيفَةِ». | √ |
| | ٢. «وَلَمْ تَغْفُلْ مِصْرُ عَنِ الاِقْتِصَادِ الأَزْرَقِ». | |
| | ٣. «تَحْوِيلُ السِّيَّارَاتِ لِلْعَمَلِ بِالْغَازِ الطَّبِيعِيِّ». | |
| | ٤. «وَمَعَ عِظَمِ مَا تَحَقَّقَ، فَمَا أُنْجِزَ لَيْسَ مَدْعَاةً لِلْفَخْرِ <br> فَقَطْ». | |
| | ٥. «لَمْ يَكُنْ مَا حَقَّقَتْهُ هَذِهِ المَشْرُوعَاتُ مُجَرَّدَ إِنْجَازٍ <br> يُضَافُ إِلَى سِجِلِّ النَّجَاحَاتِ». | |

أَتَعَلَّمُ وَأُطَبِّقُ
أ وَأَسْفَرَتْ تِلْكَ الجُهُودُ عَنْ تَحَسُّنٍ نِسْبِيٍّ فِي تَغْيِيرِ السُّلُوكِيَاتِ، فَضْلًا عَنْ نَشْرِ الوَعْيِ البيئيّ».

أُكْمِلُ مَا يَلِي:
مُقْتَرَحَاتِي لِنَشْرِ الوَعْيِ البِيئِيِّ:
١. المُقْتَرَحُ الأَوَّلُ :
٢. المُقْتَرَحُ الثَّانِي:
٣. المُقْتَرَحُ الثَّالِثُ:
ب أَسْتَخْرِجُ مِنَ النَّصِّ أَدَوَاتِ الرَّبْطِ، مُبَيِّنًا وَظِيفَةَ كُلِّ أَدَاةٍ.
