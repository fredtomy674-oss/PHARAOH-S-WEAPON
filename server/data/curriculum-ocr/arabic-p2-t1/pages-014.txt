أ أضعُ عَلَامَةَ (✓) أَمَامَ العِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ العِبَارَةِ الخَطَأِ فِيمَا يَلِي:
١. لَمْ يَتَوَقَّفْ مُسْتَشْفَى السُّوَيْسِ الأَمِيرِيُّ عَنْ تَقْدِيمِ خَدَمَاتِهِ لِلْجَرْحَى وَالمَرْضَى خِلَالَ الحَرْبِ. (  )
٢. أَطِبَّاءُ هَيْئَةِ تَمْرِيضِ مُسْتَشْفَى السُّوَيْسِ قَاوَمُوا مُحَاوَلَاتِ العَدُوِّ الإِسْرَائِيلِيِّ لِاقْتِحَامِ المَدِينَةِ. (  )
