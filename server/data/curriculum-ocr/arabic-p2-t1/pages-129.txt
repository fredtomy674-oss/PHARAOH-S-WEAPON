أقْرَأُ، ثُمَّ أُجِيبُ
«أَي بُني، إِنَّ أَخاكَ ذَكَرَ لِي أَنَّهُ صَحِبَ مُهَندِسًا يُحِبُّ القِراءةَ في جَميعِ الكُتبِ مثلِ: الكُتُبِ الأَدَبِيَّةِ، وَفي كُتُبِ عِلمِ
النَّفْسِ وَالاجتِماعِ، وَأَنَّهُ بِمُصادَقَتِهِ تَعَلَّمَ مِنْهُ حُبَّ القِراءةِ... فَكانَ يُرْشِدُهُ إلى الكُتُبِ القَيِّمَةِ، وَيَسْتَحِثُّهُ أَنْ يُقْبِلَ عَلَى
المَكْتَباتِ، فَنَمَتْ عِنْدَهُ مَلَكَةُ القِراءةِ، وانْضَمَّ إلَى مُنْتَدًى ثَقافِيٍّ يَجْتَمِعُ أَعْضَاؤُهُ كُلَّ أُسْبُوعٍ، وَيَحْضُرُ أَحَدُ أَعْضَائِهِ بِالتَّنَاوُبِ
حَدِيثًا يَعْرِضُهُ عَلَيْهِمْ، وَبَعْدَ سَمَاعِهِ يَتَنَاقَشُونَ فِيهِ، وَانْقَلَبَتْ هَذِهِ الجَلْسَةُ إلَى لَذَّةٍ عَقْلِيَّةٍ مُمْتِعَةٍ لَهُ حَتَّى كَانَ يَتَرَقَّبُ تِلْكَ
السَّاعَةَ وَيَتَمَنَّاهَا طُولَ الأُسْبُوعِ، وَأَنَّهُ اسْتَفَادَ مِنْهَا فَائِدَةً كُبْرَى غَيَّرَتْ حَيَاتَهُ، وَغَيَّرَتْ عَقْلِيَّتَهُ. وَمِنْ ذَلِكَ الحِينِ أَصْبَحَتْ لَهُ
مَكْتَبَةٌ تَشْمَلُ كُتُبًا مُتَنَوِّعَةً».

أَتَذَوَّقُ المَقْرُوءَ، وَأَنْقُدُهُ
أ أُحَدِّدُ الفِكْرَةَ الَّتِي لَا تَتَّصِلُ بِالنَّصِّ بِوَضْعِ عَلَامَةِ (X) أَمَامَهَا:
• النَّجَاحُ مُرْتَبِطٌ بِزَرْعِ المَعْرِفَةِ فِي العَقْلِ. (   )
• أَهَمِّيَّةُ القِرَاءَةِ لِبِنَاءِ الإِنْسَانِ المُثَقَّفِ الوَاعِي. (   )
• تَأْثِيرُ القِرَاءَةِ فِي زِيَادَةِ الدَّخْلِ وَتَحْقِيقِ الثَّرَاءِ. (   )
• تَأْثِيرُ الْأَنْدِيَةِ الثَّقَافِيَّةِ وَالنِّقَاشَاتِ الْفِكْرِيَّةِ فِي الإِنْسَانِ. (   )
