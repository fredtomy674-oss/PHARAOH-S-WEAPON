ب أُحَدِّدُ رَأْيًا ذَكَرَهُ الكَاتِبُ فِي النَّصِّ، ثُمَّ أُبَيِّنُ مَا يُؤَيِّدُهُ مِنَ النَّصِّ، كَالْمِثَالِ:

رَأْيُ ذَكَرَهُ الكَاتِبُ فِي النَّصِّ
مَا يُؤَيِّدُهُ مِنَ النَّصِّ

فَالعَقْلُ وَحْدَهُ، وَثَقَافَتُهُ فِي أَيِّ مَوْضُوعٍ آخَرَ تُفِيدُهُ فِي
المَوْضُوعِ الَّذِي تَخَصَّصَ فِيهِ.
فَكَمْ أَتَتْ فِكْرَةٌ هَنْدَسِيَّةٌ عَظِيمَةٌ مِنْ قِرَاءَةِ كِتَابٍ فِي الأَدَبِ،
أَوْ فِي الإِجْتِمَاعِ !

جـ أُكْمِلُ الجَدْوَلَ كَالْمِثَالِ:

الفِكْرَةُ
المَعْنَى فِيهَا مُبَاشِرٌ
المَعْنَى فِيهَا ضِمْنِيٌّ

١. اجْتَهِدْ، ثُمَّ اشْغَلْ وَقْتَ فَرَاغِكَ، لِتَكُونَ
لَكَ هِوَايَةٌ.
(✔)
(   )

٢. إِنَّ أَخَاكَ ذَكَرَ لِي أَنَّهُ صَحِبَ مُهَنْدِسًا
يُحِبُّ القِرَاءَةَ فِي جَمِيعِ الكُتُبِ.
(   )
(   )

٣. القِرَاءَةُ هِيَ السِّلاحُ، حِينَ يَعْصِفُ بِنَا
طُوفَانُ الزَّيْفِ.
(   )
(   )

٤. فَالقِرَاءَةُ هِيَ المِفْتَاحُ السِّحْرِيُّ الَّذِي
يَفْتَحُ لَنَا أَبْوَابَ العَوَالِمِ.
(   )
(   )

٥. انْضَمَّ إِلَى مُنْتَدَى ثَقَافِيٌّ، يَجْتَمِعُ أَعْضَاؤُهُ
كُلَّ أُسْبُوعٍ.
(   )
(   )

د أُحَدِّدُ فِي النَّصِّ قِيمَتَيْنِ، ثُمَّ أُبَيِّنُ مَدَى أَثَرِهِمَا فِي حَيَاتِي الشَّخْصِيَّةِ.
