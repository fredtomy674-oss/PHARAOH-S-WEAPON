L’accord et la place
des adjectifs; les pronoms possessifs
Observez ces phrases :
• « Elle porte une jolie veste noire. »
• « Je préfère les couleurs neutres et les coupes simples. »
• « Cette veste originale est la mienne. »
• « Son style est classique ; le mien est plus urbain. »
1. Les adjectifs : accord et place
Règle Exemple
L’adjectif s’accorde en genre et en nombre avec le nom. un look simple ; des tenues simples ; une veste
élégante
La plupart des adjectifs descriptifs se placent après le nom. une veste noire ; un style décontracté
Quelques adjectifs fréquents se placent souvent avant le nom. un beau manteau ; une petite veste ; un
nouveau look
2. Les pronoms possessifs
Masculin Féminin
le mien / les miens la mienne / les miennes
le tien / les tiens la tienne / les tiennes
le sien / les siens la sienne / les siennes
le nôtre / les nôtres la nôtre / les nôtres
le vôtre / les vôtres la vôtre / les vôtres
le leur / les leurs la leur / les leurs
Le pronom possessif remplace un nom déjà cité. Il s’accorde avec ce nom, et non avec la
personne qui possède : mes baskets → les miennes.
Exercices
A. Accordez et placez correctement les adjectifs entre parenthèses.
1. Elle porte une ____________ veste ____________ (joli / noir).
2. Il a choisi un ____________ manteau ____________ (nouveau / élégant).
3. Nous aimons les tenues ____________ et ____________ (moderne / audacieux).
4. Mes accessoires ____________ sont très ____________ (préféré / coloré).
B. Remplacez le complément indiquant le possesseur par un pronom possessif.
1. Ce pull est à moi. → C’est ____________________.
2. Cette veste est à Amélie. → C’est ____________________.
3. Ces baskets sont à vous. → Ce sont ____________________.
4. Ces accessoires sont à nous. → Ce sont ____________________.
5. Cette tenue est à eux. → C’est ____________________.
C. Défi d’écriture courte :
Chloé vous demande : « Décrivez votre style en quatre ou cinq lignes et comparez-le à
celui d’une autre personne. » Utilisez au moins quatre adjectifs et deux pronoms
possessifs.
