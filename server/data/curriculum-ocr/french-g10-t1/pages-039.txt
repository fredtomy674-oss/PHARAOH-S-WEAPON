J’applique
Votre mission
Chloé lance un grand projet : créer avec toute la classe un
guide « Voyage écoresponsable ». Chaque élève rédigera
une partie. À la fin, vous imprimerez le guide ou le
publierez en ligne.
Le guide contiendra quatre sections (une par leçon) :
Pour compléter la section « Imaginer le voyage du futur », vous rédigerez un texte de 100
à 120 mots décrivant le voyage en 2050.
Boîte à idées :
Pour le futur simple :
« Les voyageurs prendront... », « Les avions seront... », « On voyagera... », « Les gens découvriront... »
Pour exprimer le but :
« Pour réduire les émissions… », « Afin de protéger la nature… », « Pour éviter les longs trajets… »
Vocabulaire utile :
tourisme durable, énergies propres, hydrogène, solaire, réalité virtuelle, tourisme de proximité, train,
vélo, empreinte carbone, innovant, écolodge
Section Contenu
1. Découvrir Des carnets de voyage inspirants
2. Comprendre Les impacts du tourisme expliqués
3. Agir Dix conseils écologiques
4. Imaginer Le voyage du futur
Consignes de rédaction :
Votre texte doit contenir :
Au moins trois verbes au futur simple (par exemple : les voyageurs prendront, on
voyagera…)
Au moins deux expressions de but (pour / afin de)
Au moins trois mots ou expressions du lexique (tourisme durable, énergies
propres, innovant, tourisme de proximité…)
Une description d’une solution innovante pour voyager en polluant moins
Rédigez un texte de 100 à 120 mots.
