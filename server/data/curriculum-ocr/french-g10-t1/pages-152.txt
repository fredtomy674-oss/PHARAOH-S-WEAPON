Les structures de projet
et l’expression du but
Les expressions de but suivies de l’infinitif relient généralement deux actions qui ont le même
sujet. Devant une voyelle, de devient d’ : « envisager d’organiser », « afin d’expliquer ».
A. Complétez en conjuguant la structure indiquée.
1. Adam ........................................... lancer une série appelée « Villes invisibles ». (compter)
2. Nous ........................................... collaborer avec d’autres jeunes artistes. (envisager)
3. Je ........................................... respecter les droits et les autorisations. (se promettre)
4. Lina ........................................... publier ses photos sur le site de son établissement. (avoir l’intention)
B. Reliez les deux phrases avec l’expression de but indiquée.
1. Je diffuse mon travail. Je veux toucher un public nouveau. (pour)
2. J’écris une légende. Je veux expliquer mon intention. (afin de)
3. Nous créons une plateforme. Nous voulons partager nos œuvres plus facilement. (dans le but de)
4. Je limite les informations personnelles. Je veux protéger ma vie privée. (afin de)
C. Défi d’écriture courte :
Chloé vous demande : « Quel projet artistique comptez-vous réaliser et comment le diffuserez-vous ? » Répondez
en cinq ou six lignes avec au moins deux structures de projet et deux expressions de but.
4
Observez ces phrases :
• « Je compte créer une série de photos. »
• « Nous envisageons d’organiser une exposition. »
• « Je me promets de respecter les droits d’auteur. »
• « J’écris une légende afin d’expliquer mon intention. »

Structure Valeur Exemple

Je compte publier une image chaque

2. L’expression du but
Structure Exemple
pour + infinitif Je publie une sélection pour présenter mon travail.
afin de + infinitif Je limite les informations personnelles afin de protéger ma vie privée.
dans le but de + infinitif Nous créons une plateforme dans le but de partager nos œuvres.
pour ne pas / afin de ne pas +
infinitif
Je demande une autorisation pour ne pas utiliser une image sans
accord.
