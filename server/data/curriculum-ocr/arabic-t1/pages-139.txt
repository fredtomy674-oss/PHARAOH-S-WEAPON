الوحدة الثالثة: العلم والخيال والمستقبل

قَيِّمْ نَفْسَكَ

النصوص المتحررة أَقْرَأُ الأَبْيَاتَ التَّالِيَةَ، ثُمَّ أُجِيبُ:
بِنَشْرِ الْعِلْمِ فِي قَوْمِي وَرُوحِ الْعَوْنِ وَالْعَزْمِ
سَيَعْمُرُ مِصْرَنَا خَيْرٌ بِحُسْبَانٍ مَعَ الْفَهْمِ
هُنَا زَرْعٌ هُنَا نَبْنِي وَلَنْ نَعْيَا فَذَا عِلْمِي
فَأَرْضِي جَنَّةُ الدُّنْيَا سَأُعْلِيهَا إِلَى النَّجْمِ

أولاً أَخْتَارُ الإِجَابَةَ الصَّحِيحَةَ مِمَّا بَيْنَ الْقَوْسَيْنِ:
١) مَعْنَى (نَعْيَا) : (نكسَلَ - نعجِزَ - نرفُضَ - نتحَيَّرَ)
٢) جَمْعُ (رُوح) : (أَرْواح - رياح - مراوح - روائح)
٣) مُضَادُّ (يَعْمُرُ) : (يُتعب - يُقلِّل - يُضَيِّق - يُخرب)

ثانياً أَضَعُ عَلامَةَ (✓) أَمَامَ العِبَارَةِ الصَّحِيحَةِ، وعلامةَ (X) أَمَامَ العِبَارَةِ غيرِ الصَّحِيحَةِ:
١) العِلمُ أساسُ نهضةِ الأُمَمِ. ( )
٢) الشبابُ قادرونَ على تعميرِ أوطانِهم. ( )
٣) لا نحتاجُ إلى التعاونِ والمُشارَكةِ حتَّى نبنيَ أوطانَنا. ( )
