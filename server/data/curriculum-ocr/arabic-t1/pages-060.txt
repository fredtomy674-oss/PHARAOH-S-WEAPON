الدرس الثاني: قوة الكلمات

هَيَّا نَفْهَمُ وَنُنَاقِشُ
ه أَقْرَأُ النَّصَّ قِرَاءَةً صَامِتَةً، ثُمَّ أَضَعُ عَلامَةَ (✓) أَوْ عَلامَةَ (✗) أَمَامَ الْجُمَلِ الآتِيَةِ مَعَ تَصْوِيبِ الْخطأ:
( أ ) قَابَلَ التلامِيدُ فِكْرَةَ المُعَلِّمَةِ بلهفةٍ وحماسٍ. ( )
( ب) تمنَّتْ فريدةُ الخيرَ لجميعِ الناسِ بعدَ أنْ سَمِعَتْ كَلِمَةَ (خَيْر). ( )
(ج) نتعلَّمُ من تجربةِ سميرٍ أنَّ الأَمَلَ يَجْعَلُ لدينا دافعًا لمساعدةِ الآخرينَ. ( )
( د ) الحَمَامُ الأبيَضُ الذي يحمِلُ أغصانَ الزيتونِ يرمزُ للمستقبلِ. ( )
(هـ) الكلماتُ الإيجابيةُ ليسَ لها تأثيرٌ على الآخرينَ. ( )
( و ) تعلَّمَ الطلابُ في نهايةِ القصةِ أنَّ الكلماتِ قُوَّةٌ تُغَيِّرُ العَالَمَ. ( )

هَلْ أَنتُم مُستَعِدُّونَ للتَّحَدِّي؟
٦ أُجِيبُ عَنِ الأَسْئِلَةِ الآتِيَةِ:
( أ ) ما المقصودُ بـ «الكلماتُ مثل البذورِ التي نزرعُها في القُلوبِ»؟
الدرسُ قصةٌ جميلةٌ، استخدمَ فيها الكاتبُ الوصفَ والتعبيرَ عن المشاعرِ لإظهارِ «قُوَّةِ الكلماتِ».
( ب) اذكرْ جُملتينِ من النصِّ تُعَبِّرانِ عن مشاعرِ التلاميذِ.
(ج) علينا أنْ نختارَ كلماتِنا بعنايةٍ. هل تتَّفِقُ مع العبارةِ؟ ولماذا؟
( د ) لخص الهدفَ من النصِّ في عبارةٍ واحدةٍ. (....................................................................)

القراءةُ والأداءُ
٧ أَقْرَأُ الفَقْرَةَ التي عَبَّرَت فيها (مريمُ) عن مشاعرِها مُستخدِمًا تعبيراتِ الوجهِ وتنغيماتِ الصوتِ المُناسِبَةِ.
حاول من خلال الأداء أن تحكي القصة وتُعَبِّر عما فيها من وصف ومشاعر.
