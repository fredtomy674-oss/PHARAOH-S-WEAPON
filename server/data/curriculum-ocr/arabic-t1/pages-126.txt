الدرس الثالث: رحلة إلى المستقبل

٢ أَسْتَخْرِجُ اسْمَ الْحَرْفِ النَّاسِخِ وَخَبَرَهُ وَنَوْعَ الْخَبَرِ كَالْمِثَالِ:

| نَوْعُ الْخَبَرِ | خَبَرُهُ | اسْمُهُ | |
| :--- | :--- | :--- | :--- |
| شبه جملة | من الأخلاق | الصدق | (أ) إِنَّ الصدقَ من الأخلاقِ الحميدةِ. |
| | | | (ب) لَعَلَّ الحافلةَ أمامَ البيتِ. |
| | | | (ج) عَرَفْتُ أَنَّكَ صادقٌ. |
| | | | (د) لَيْتَ ماءَ البَحْرِ عَذْبٌ. |
| | | | (هـ) طارَتِ العُصْفورةُ، لكنَّها سَقَطَتْ. |

اسم إن وأخواتها
يكون اسماً
ظاهراً أو ضميراً
متصلاً.

٣ أَكْمِلُ الْجُمَلَ الْآتِيَةَ بِما هُوَ مَطْلوبٌ:
(أ) عَلِمْتُ أَنَّ السفرَ .................................................... (خَبَرُ شِبْهُ جُمْلَةٍ ظَرْفٌ)
(ب) الجوُّ حارٌّ، لكنَّ السماءَ ........................................... (خَبَرُ جُمْلَةٍ فِعْلِيَّةٌ)
(ج) لَعَلَّكَ ................................................................. (خَبَرُ جارٌّ ومجرورٌ)
(د) إِنَّ الفريقَ ............................................................ (خَبَرُ جُمْلَةٍ اسْمِيَّةٌ)
(هـ) كَأَنَّ الْجُنْدِيَّ ........................................................ (خَبَرُ مُفْرَدٌ)

٤ أَحْذِفُ الْفِعْلَ النَّاسِخَ فِي الْجُمَلِ الْآتِيَةِ، وَأُغَيِّرُ ما يَلْزَمُ:
(أ) لَعَلَّ الحقيبتينِ في السيارةِ. ....................................................
(ب) إِنَّ القائدَ يهتمُّ بفريقهِ. ....................................................
(ج) إِنَّكم ماهرونَ في عَمَلِكم. ....................................................
(د) لَيْتَ أخاكَ جاءَ أمسِ. ....................................................

٥ أُعْرِبُ ما تحته خَطٌّ إعرابًا كامِلًا، كالمثالِ:
(أ) لَعَلَّ المتسابقينَ فائزونَ. .................... خبر لعل مرفوع، وعلامة رفعه الواو؛ لأنه جمع مذكر سالم.
(ب) إِنَّ القراءةَ غذاءُ العُقولِ. ....................................................
(ج) عَلِمْتُ أَنَّ الأرضَ تدورُ. ....................................................

١٢٥
