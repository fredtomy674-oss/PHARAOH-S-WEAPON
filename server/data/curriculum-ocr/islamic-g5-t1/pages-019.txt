الْأَنْشِطَةُ وَالتَّدْرِيبَاتُ

نَشَاط (١) اخْتَرِ الْإِجَابَةَ الصَّحِيحَةَ:
١ حُرُوفُ الْإِدْغَامِ مَجْمُوعَةٌ فِي كَلِمَةِ ....................................
(أ) قُطْب (ب) يَرْمُلُونَ (ج) أَنَيْت
٢ الْحُكْمُ الَّذِي تُقْلَبُ فِيهِ النُّونُ السَّاكِنَةُ وَالتَّنْوِينُ إِلَى (مِيمٍ) هُوَ ....................................
(أ) الْإِدْغَامُ (ب) الْإِخْفَاءُ (ج) الْإِقْلَابُ
٣ أَيُّ مِمَّا يَلِي يُوجَدُ بِهِ حُكْمُ الْإِخْفَاءِ؟
(أ) ﴿وَلَكِن لِّيَطْمَئِنَّ قَلْبِي﴾ (ب) ﴿وَمِن شَرِّ﴾ (ج) ﴿أَنبِئْهُم﴾

نَشَاط (٢) ضَعْ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ الْعِبَارَةِ الْخَطَأِ:
١ عِلْمُ التَّجْوِيدِ هُوَ عِلْمٌ يُعْرَفُ بِهِ كَيْفِيَّةُ تِلَاوَةِ الْقُرْآنِ الْكَرِيمِ تِلَاوَةً صَحِيحَةً. ( )
٢ حُرُوفُ الْإِظْهَارِ الْحَلْقِيِّ جُمِعَتْ فِي كَلِمَةِ يَرْمُلُونَ. ( )
٣ عَلَامَةُ الْإِقْلَابِ بِالْمُصْحَفِ هِيَ حَرْفُ (م). ( )
٤ تُنْطَقُ النُّونُ السَّاكِنَةُ أَوِ التَّنْوِينُ بِدُونِ غُنَّةٍ بَعْدَ حُرُوفِ الْإِظْهَارِ الْحَلْقِيِّ. ( )
٥ حُرُوفُ الْإِخْفَاءِ سَبْعَةَ عَشَرَ حَرْفًا. ( )

نَشَاط (٣) اكْتُبْ أَمَامَ كُلِّ آيَةٍ حُكْمَ التِّلَاوَةِ لِلْجُزْءِ الْمُلَوَّنِ مِنْهَا:
