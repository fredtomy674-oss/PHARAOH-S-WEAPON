الْأَنْشِطَةُ وَالتَّدْرِيبَاتُ

نَشَاط ١ اخْتَرِ الْإِجَابَةَ الصَّحِيحَةَ مِمَّا يَأْتِي:
١ كَيْفَ اسْتَقْبَلَ كِسْرَى مَلِكُ الْفُرْسِ رِسَالَةَ النَّبِيِّ ﷺ؟
(أ) مَزَّقَهَا وَغَضِبَ مِنْهَا
(ب) أَسْلَمَ بَعْدَ قِرَاءَتِهَا
(ج) أَرْسَلَ الْهَدَايَا إِلَى النَّبِيِّ ﷺ
٢ مِنَ الْمُلُوكِ الَّذِينَ أَسْلَمُوا بَعْدَ تَلَقِّي رِسَالَةِ النَّبِيِّ ﷺ
(أ) مَلِكُ الرُّومِ
(ب) مَلِكُ الْفُرْسِ
(ج) مَلِكُ الْبَحْرَيْنِ
٣ بَعَثَ النَّبِيُّ ﷺ رَسَائِلَهُ إِلَى الْمُلُوكِ بَعْدَ
(أ) غَزْوَةِ بَدْرٍ
(ب) فَتْحِ مَكَّةَ
(ج) صُلْحِ الْحُدَيْبِيَةِ

نَشَاط ٢ ضَعْ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (x) أَمَامَ الْعِبَارَةِ الْخَطَأِ:
١ أَرْسَلَ الْمُقَوْقِسُ إِلَى النَّبِيِّ ﷺ هَدِيَّةً، لَكِنَّهُ لَمْ يُسْلِمْ. ( )
٢ جَمِيعُ الرُّسُلِ الَّذِينَ بَعَثَهُمُ النَّبِيُّ ﷺ لَا يُجِيدُونَ لُغَةَ الْأَقْوَامِ الَّذِينَ أُرْسِلُوا إِلَيْهِمْ. ( )
٣ مَزَّقَ هِرَقْلُ مَلِكُ الرُّومِ رِسَالَةَ النَّبِيِّ ﷺ. ( )
٤ أَرْسَلَ النَّبِيُّ ﷺ الرَّسَائِلَ بِأُسْلُوبٍ لَبِقٍ وَمُحْتَرَمٍ. ( )
٥ الْإِسْلَامُ دِينٌ عَالَمِيٌّ، وَلَيْسَ خَاصًّا بِالْعَرَبِ فَقَطْ. ( )
٦ أَرْسَلَ النَّبِيُّ ﷺ رَسَائِلَ إِلَى مُلُوكِ الْجَزِيرَةِ الْعَرَبِيَّةِ. ( )

نَشَاط ٣ أَكْمِلِ الْفَرَاغَاتِ:
١ بَعْدَ صُلْحِ الْحُدَيْبِيَةِ، قَرَّرَ النَّبِيُّ ﷺ نَشْرَ دَعْوَتِهِ خَارِجَ ....................................
٢ مِنَ الْمُلُوكِ الَّذِينَ أَسْلَمُوا بَعْدَ تَلَقِّيِهِمْ رِسَالَةَ النَّبِيِّ ﷺ .................................... وَ ....................................
٣ قَالَ النَّبِيُّ ﷺ عِنْدَمَا مَزَّقَ كِسْرَى رِسَالَتَهُ: ....................................
٤ مِنْ نَتَائِجِ إِرْسَالِ النَّبِيِّ ﷺ الرُّسُلَ إِلَى الْمُلُوكِ انْتِشَارُ .................................... خَارِجَ الْجَزِيرَةِ الْعَرَبِيَّةِ.
