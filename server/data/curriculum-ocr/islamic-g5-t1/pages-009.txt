الْأَنْشِطَةُ وَالتَّدْرِيبَاتُ

نَشَاط (١) اخْتَرِ الْإِجَابَةَ الصَّحِيحَةَ:
١ أَنْزَلَ اللَّهُ عَزَّ وَجَلَّ الْإِنْجِيلَ عَلَى نَبِيِّهِ
(أ) مُوسَى عَلَيْهِ السَّلَامُ (ب) عِيسَى عَلَيْهِ السَّلَامُ (ج) دَاوُدَ عَلَيْهِ السَّلَامُ
٢ الْكِتَابُ السَّمَاوِيُّ الَّذِي أُنْزِلَ بِاللُّغَةِ الْعَرَبِيَّةِ هُوَ
(أ) التَّوْرَاةُ (ب) الْإِنْجِيلُ (ج) الْقُرْآنُ الْكَرِيمُ
٣ مِنْ أَرْكَانِ الْإِيمَانِ، الْإِيمَانُ بِـ
(أ) حَجِّ الْبَيْتِ (ب) الْكُتُبِ السَّمَاوِيَّةِ وَالرُّسُلِ (ج) صَوْمِ رَمَضَانَ

نَشَاط (٢) ضَعْ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ الْعِبَارَةِ الْخَطَأِ:
١ الْقُرْآنُ الْكَرِيمُ مَحْفُوظٌ مِنَ التَّحْرِيفِ. ( )
٢ أَنْزَلَ اللَّهُ عَزَّ وَجَلَّ التَّوْرَاةَ عَلَى نَبِيِّهِ مُحَمَّدٍ ﷺ. ( )
٣ الزَّبُورُ كِتَابٌ سَمَاوِيٌّ أُنْزِلَ عَلَى نَبِيِّ اللَّهِ دَاوُدَ عَلَيْهِ السَّلَامُ. ( )

نَشَاط (٣) أَكْمِلِ الْفَرَاغَ فِي الْجُمَلِ التَّالِيَةِ بِكَلِمَةٍ مُنَاسِبَةٍ:
١ أَنْزَلَ اللَّهُ عَزَّ وَجَلَّ التَّوْرَاةَ عَلَى نَبِيِّهِ ................. عَلَيْهِ السَّلَامُ.
٢ الْكِتَابُ السَّمَاوِيُّ الَّذِي أُنْزِلَ عَلَى نَبِيِّ اللَّهِ عِيسَى عَلَيْهِ السَّلَامُ هُوَ .................
٣ الْقُرْآنُ الْكَرِيمُ مَحْفُوظٌ مِنَ .................

نَشَاط (٤) رَتِّبِ الْكُتُبَ السَّمَاوِيَّةَ التَّالِيَةَ مِنَ الْأَقْدَمِ إِلَى الْأَحْدَثِ:
الْإِنْجِيلُ ( ) التَّوْرَاةُ ( ) الزَّبُورُ ( ) صُحُفُ إِبْرَاهِيمَ ( ) الْقُرْآنُ الْكَرِيمُ ( )

نَشَاط (٥) اكْتُبْ بَعْضَ آثَارِ الْإِيمَانِ بِالْكُتُبِ السَّمَاوِيَّةِ:
