• La chaîne alimentaire du Nil :
Dans le fleuve Nil, il existe un magnifique cycle de vie : de petits crustacés se nourrissent de plantes aquatiques, des poissons (comme le tilapia du Nil) se nourrissent de ces crustacés, puis les oiseaux aquatiques et les humains se nourrissent de ces poissons.
