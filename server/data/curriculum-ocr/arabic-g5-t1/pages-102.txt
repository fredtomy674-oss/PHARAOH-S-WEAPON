الدرس الثاني: كيف يصبح العالم أجمل؟

هَيَّا نَفْهَمُ وَنُنَاقِشُ

٥ أَقْرَأُ النَّصَّ قِرَاءَةً صَامِتَةً، ثُمَّ أَضَعُ عَلامَةَ (✓) أَوْ عَلامَةَ (✗) أَمَامَ مَا يَلِي مَعَ تَصْوِيبِ الْخَطَأِ:
( أ ) بَدَأَ طَارِقٌ جَوْلَتَهُ بِزِيَارَةِ الْجَنَاحِ الْعَرَبِيِّ ثُمَّ الْآسِيَوِيِّ. ( )
(ب) كَانَتِ الْمَنْسُوجَاتُ وَالْأَبَارِيقُ النُّحَاسِيَّةُ فِي الْجَنَاحِ الْعَرَبِيِّ. ( )
(ج) لاحَظَ طَارِقٌ زِيَّ الْكِيمُونُو التَّقْلِيدِيَّ فِي الْجَنَاحِ الْعَرَبِيِّ. ( )
( د ) حَاوَلَ طَارِقٌ نُطْقَ بَعْضِ الْكَلِمَاتِ بِلُغَاتٍ أَجْنَبِيَّةٍ. ( )
(هـ) أَدْرَكَ طَارِقٌ أَنَّ اللَّوحَةَ الْجَمِيلَةَ تَتَكَوَّنُ مِنْ أَلْوَانٍ مُتَعَدِّدَةٍ. ( )

٦ أَسْتَخْدِمُ الْجَدْوَلَ التَّالِيَ فِي الْمُقَارَنَةِ بَيْنَ الْأَجْنِحَةِ الْمُخْتَلِفَةِ الَّتِي رَآهَا طَارِقٌ فِي الْمِهْرَجَانِ:
| الْجَنَاحُ | الْأَزْيَاءُ | الْمَصْنُوعَاتُ الْيَدَوِيَّةُ |
| :--- | :--- | :--- |
| ( أ ) الْجَنَاحُ الْإِفْرِيقِيُّ. | | |
| (ب) الْجَنَاحُ الْعَرَبِيُّ. | | |
| (ج) الْجَنَاحُ الْآسِيَوِيُّ. | | |

هَلْ أَنْتُمْ مُسْتَعِدُّونَ لِلتَّحَدِّي؟
٧ أُجِيبُ عَنِ الْأَسْئِلَةِ الْآتِيَةِ:
( أ ) حَدِّدِ الْفِكْرَةَ الرَّئِيسَةَ لِلنَّصِّ.

(ب) حَدِّدْ ثَلَاثَ فِكَرٍ فَرْعِيَّةٍ فِي النَّصِّ.

(ج) مَا الَّذِي اسْتَنْتَجَهُ طَارِقٌ فِي نِهَايَةِ الْمِهْرَجَانِ؟

( د ) قَالَ وَالِدُ طَارِقٍ: «عِنْدَمَا نَحْتَرِمُ اخْتِلَافَاتِنَا يُصْبِحُ الْعَالَمُ أَجْمَلَ». هَلْ تَتَّفِقُ مَعَهُ؟ وَلِمَاذَا؟

(هـ) اقْتَرِحْ عُنْوَانًا آخَرَ لِلنَّصِّ.
