الوحدة الثانية: فن التواصل

هَيَّا نَفْهَمُ وَنُنَاقِشُ

ه أَقْرَأُ النَّصَّ قِرَاءَةً صَامِتَةً، ثُمَّ أَضَعُ عَلامَةَ (✓) أَو عَلامَةَ (X) أَمَامَ مَا يَلِي مَعَ تَصْوِيبِ الْخَطَأِ:
(أ) يَتَحَدَّثُ النَّصُّ عَن تَطَوُّرِ وَسَائِلِ الْمُوَاصَلَاتِ. ( )
(ب) كَانَتِ الرَّسَائِلُ بِالْحَمَامِ الزَّاجِلِ تَصِلُ فِي سُرْعَةِ الْبَرْقِ. ( )
(ج) كَانَ النَّاسُ يَنْتَظِرُونَ سَاعِيَ الْبَرِيدِ وَيَسْتَقْبِلُونَ رَسَائِلَهُ بِشَوْقٍ. ( )
(د) الرَّسَائِلُ بِالْبَرِيدِ الْإِلِكْتِرُونِيِّ تَصِلُ أَبْطَأَ مِن رَسَائِلِ سَاعِي الْبَرِيدِ. ( )
(هـ) تَوَقَّفَ تَطَوُّرُ الرِّسَالَةِ فِي هَذَا الْعَصْرِ وَلَن تَتَطَوَّرَ فِي الْعُصُورِ التَّالِيَةِ. ( )

٦ أُرَتِّبُ مَرَاحِلَ تَطَوُّرِ الرِّسَالَةِ حَسَبَ وُرُودِهَا بِالنَّصِّ، ثُمَّ أُعَبِّرُ عَنْهَا بِجُمْلَةٍ:

٧ أُحَدِّدُ الْحَقِيقَةَ وَالْخَيَالَ فِي الْجُمَلِ الْآتِيَةِ:
(أ) قَفَزَتِ الرِّسَالَةُ عَبْرَ آلَةِ الزَّمَنِ.
(ب) كَانَ السَّاعِي يَحْمِلُ حَقِيبَتَهُ الْمُمْتَلِئَةَ بِالرَّسَائِلِ.
(ج) تَصِلُ الرِّسَالَةُ الْإِلِكْتِرُونِيَّةُ إِلَى أَيِّ مَكَانٍ فِي الْعَالَمِ.
(د) فِي الْمُسْتَقْبَلِ سَتَنْتَقِلُ الْفِكْرَةُ مِن رَأْسِ صَاحِبِهَا إِلَى الْآخَرِ دُونَ كَلَامٍ.
