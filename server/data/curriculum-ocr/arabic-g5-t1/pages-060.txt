الدرس الثاني: لغة النصر

القَوَاعِدُ النَّحْوِيَّةُ
إعرابُ المَفْعولِ به (جَمْعِ المُؤَنَّثِ السالِمِ)

أولًا أَقْرَأُ الجُمَلَ الآتِيَةَ:
(١) يَسقي الفَلَّاحُ النَّباتاتِ.
(٢) رَسَمَتِ البِنتُ اللَّوْحاتِ.
(٣) تَقرأُ الفَتياتُ المَجَلَّاتِ.

ثانيًا أُلاحِظُ
• الجُمَلُ السَّابِقَةُ كُلُّها جُمَلٌ فِعْلِيَّةٌ.
• الكَلِماتُ المُلَوَّنَةُ في الجُمَلِ السَّابِقَةِ جَمْعُ مُؤَنَّثٍ سالِمٌ.
• الكَلِماتُ المُلَوَّنَةُ وَقَعَ عَلَيها فِعْلُ الفاعِلِ، فَتُعرَبُ مفعولًا به.
• نِهاياتُ الكَلِماتِ المُلَوَّنَةِ تَحتَها كَسرةٌ.

ثالثًا أَستنتج
• جَمْعُ المُؤَنَّثِ السالِمُ إِذا جاءَ مَفْعولًا به في الجُملةِ؛ فَإِنَّ عَلامَةَ نَصْبِهِ تَكُونُ الكَسْرَةَ.

١ أَضَعُ علامةَ (✓) أمامَ الجُملةِ التي تَشتَمِلُ على مفعولٍ به جمعِ مُؤَنَّثٍ سالِمٍ، كالمثالِ:
(أ) اجتازَ الطُّلَّابُ الاختباراتِ. (✓)
(ب) سَمِعَ المُعَلِّمُونَ أغنياتِ الأطفالِ. ( )
(ج) يُحِبُّ خالدٌ رياضةَ كُرةِ القَدَمِ. ( )
(د) شاهَدَ الطِّفْلُ العصافيرَ فوقَ الأشجارِ. ( )
(هـ) قرأتُ سما قِصَصًا خياليَّةً. ( )
(و) كَرَّمَ المُديرُ المُتَفَوِّقاتِ. ( )

٢ أَختارُ الإجابةَ الصحيحةَ مِمَّا بَينَ القَوسينِ:
(أ) تحكي الجَدَّةُ ................................. (الحكاياتُ - الحكاياتِ)
(ب) طَهَا الطَّبَّاخُ ................................. (الدجاجاتُ - الدجاجاتِ)
(ج) تُنَظِّفُ ................................. الطَّاوِلاتِ. (العاملاتُ - العاملاتِ)
(د) احترَمَ السائقُ ................................. المرورِ. (إشاراتُ - إشاراتِ)
