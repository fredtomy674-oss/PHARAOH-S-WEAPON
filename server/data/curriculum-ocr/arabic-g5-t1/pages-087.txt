أخي الإنسان

هَيَّا نَتَعَلَّمُ مُفْرَدَاتٍ جَدِيدَةً

١ أَخْتَارُ الْمَعْنَى الْمُنَاسِبَ لِلْكَلِمَةِ الْمُلَوَّنَةِ:
( أ ) الرَّئِيسُ يُصَافِحُ الْعُلَمَاءَ فِي عِيدِ الْعِلْمِ. (يَشْكُرُ - يُهَنِّئُ - يُقَابِلُ - يُحَيِّي بِالْيَدِ)
(ب) أَشْعُرُ بِقَلْبِي يَخْفِقُ عِنْدَمَا أَبْذُلُ مَجْهُودًا حَرَكِيًّا. (يَفْرَحُ - يَرْتَاحُ - يَنْبِضُ - يَهْدَأُ)
(ج) أَحَالَ الْفَلَّاحُ أَرْضَنَا جَنَّاتٍ خَضْرَاءَ. (أَلْبَسَ - حَوَّلَ - ظَنَّ - تَخَيَّلَ)
( د ) نَحْنُ أَعْوَانٌ عَلَى فِعْلِ الْخَيْرِ. (مُتَنَاصِحُونَ - مُقْبِلُونَ - مُتَعَاوِنُونَ - مُصَمِّمُونَ)
(هـ) يَسْعَدُ الْأَطْفَالُ بِالْحَدَائِقِ وَالْمُتَنَزَّهَاتِ. (يَفْرَحُ - يَجْرِي - يَلْعَبُ - يَجْلِسُ)

هَيَّا نَفْهَمُ وَنُنَاقِشُ

٢ أَضَعُ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (✗) أَمَامَ الْعِبَارَةِ غَيْرِ الصَّحِيحَةِ مَعَ تَصْوِيبِ الْخَطَأِ:
( أ ) اقْتَصَرَ الشَّاعِرُ فِي كَلَامِهِ عَلَى أَبْنَاءِ الْوَطَنِ الْعَرَبِيِّ. ( )
(ب) عَبَّرَ الشَّاعِرُ عَنْ حُبِّهِ لِكُلِّ النَّاسِ فِي كُلِّ مَكَانٍ. ( )
(ج) الْمُصَافَحَةُ بَيْنَ النَّاسِ دَلِيلٌ عَلَى الْحُبِّ وَالْإِخَاءِ. ( )
(د) الْهَدَفُ مِنَ الْحَيَاةِ أَنْ يَعِيشَ النَّاسُ فِي سَلَامٍ وَمَحَبَّةٍ. ( )

٣ أَصِلُ كُلَّ بَيْتٍ بِالْمَعْنَى الْمُنَاسِبِ:
( أ ) أَخِي فِي الْعَالَمِ الْوَاسِـعِ فِي الْمَغْرِبِ وَالْمَشْرِقِ
(ب) وَنَسْعَدُ بِالْحَيَاةِ مَعًا أَحِبَّـــــاءَ وَأَعْوَانَـــــا
(ج) وَلَوْ شِئْنَا أَحَلْنَا جَنَّـــــــــــــــةَ الْفِرْدَوْسِ دُنْيَانَا
يَسْعَدُ الْبَشَرُ بِالتَّعَاوُنِ.
الْحُبُّ يُحَوِّلُ الدُّنْيَا إِلَى جَنَّةٍ.
الْبَشَرُ كُلُّهُمْ إِخْوَةٌ.

هَلْ أَنْتُمْ مُسْتَعِدُّونَ لِلتَّحَدِّي؟
٤ أُجِيبُ عَمَّا يَلِي:
( أ ) مَا الْفِكْرَةُ الَّتِي دَعَا إِلَيْهَا الشَّاعِرُ فِي الْأَبْيَاتِ؟
(ب) اذْكُرْ مِنَ النَّصِّ مَا يَدُلُّ عَلَى حُبِّ الشَّاعِرِ لِلسَّلَامِ.
(ج) كَيْفَ نَجْعَلُ حَيَاتَنَا جَنَّةً عَلَى الْأَرْضِ؟
(د) صِفْ شَخْصِيَّةَ الشَّاعِرِ مِنْ خِلَالِ فَهْمِكَ لِلْأَبْيَاتِ.

كَيْفَ تَنْجَحُ فِي التَّحَدِّي؟
• افْهَمِ السُّؤَالَ جَيِّدًا.
• أَعِدْ قِرَاءَةَ الْأَبْيَاتِ.
• أَجِبْ بِدِقَّةٍ وَوُضُوحٍ.
• رَاجِعْ إِجَابَتَكَ دَائِمًا.
