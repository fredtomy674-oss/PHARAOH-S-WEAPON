الوحدة الثانية: فن التواصل

٣ أُكَمِّلُ الْجُمَلَ الْآتِيَةَ بِجَمْعِ مُؤَنَّثٍ سالِمٍ، وَأَضْبِطُ آخِرَهُ:
( أ ) رَكِبَ التَّلامِيذُ ....................، وَذَهَبُوا إِلَى الْمَدْرَسَةِ.
(ب) جَمَعَ الْفَلَّاحُونَ .................... النَّاضِجاتِ.
(ج) شَكَرَتْ .................... الْعامِلاتِ فِي الْحَفْلِ.
( د ) يَزُورُ الطَّالِبُ ....................؛ لِيَقْرَأَ الْكُتُبَ الْمُفِيدَةَ.

انتبه
• قبل ضبط آخر الكلمة
يجب أن تُحدِّد موقعها
(فاعِلًا - مَفْعُولًا به...).

٤ أَصَوِّبُ ما تحته خَطٌّ فِي كُلِّ جُمْلَةٍ مِمَّا يَلِي:
( أ ) تَتَنافَسُ الْمُتسابِقاتِ لِلْفَوْزِ بِالسِّباقِ.
(ب) كَتَبَ الْمُشْرِفُ الملاحظةِ.
(ج) قَرَأَ الطُّلابُ اللافتاتُ.
( د ) تَعْتَزُّ الْمُجْتَمَعَاتِ بِانْتِصاراتِها.

٥ أَعْرِبُ الْكَلِمَاتِ الْمُلَوَّنَةَ فِيما يَلِي، كَالْمِثالِ:
( أ ) يُقَدِّمُ الْجُنُودُ التضحياتِ لِلْوَطَنِ. .................... مفعول به منصوب، وعلامة نصبه الكسرة.......
(ب) أَجْرَى الْقائِدُ الاتصالاتِ مَعَ الْجُنُودِ. ........................................................
(ج) تُساعِدُ الْمُوَظَّفاتُ المواطنينَ. ........................................................
( د ) باعَ التُّجَّارُ الْمُنْتَجاتِ بِسِعْرٍ رَخِيصٍ. ........................................................

٦ أَقْرَأُ الْفَقْرَةَ الْآتِيَةَ، ثُمَّ أُجِيبُ:
«سافَرَتِ الْأُسْرَةُ إِلَى أَسْوانَ، وَزارَتْ أَشْهَرَ الْمَعابِدِ هُناكَ، وتَعَلَّمَ الْأَبْناءُ كَلِماتٍ مِنَ اللُّغَةِ النُّوبِيَّةِ».
( أ ) أَسْتَخْرِجُ مِنَ الْفَقْرَةِ ما يَلِي:
• فاعِلًا: .................... • جَمْعَ مُؤَنَّثٍ سالِمًا: ....................، أَعْرِبُهُ: ....................
(ب) أَخْتارُ: (الْمَعابِدِ): جَمْعُ .................... (مُذَكَّرٍ سالِمٌ - تَكْسِيرٍ - مُؤَنَّثٍ سالِمٍ)
(ج) أُكَمِّلُ بِمَفْعُولٍ بِهِ، وَأَضْبِطُ آخِرَهُ: قَرَأَ الْأَطْفالُ ....................
