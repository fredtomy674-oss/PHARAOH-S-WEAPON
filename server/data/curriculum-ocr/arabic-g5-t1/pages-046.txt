الدرس الرابع: حكاية عطاء

قَيِّمْ نَفْسَكَ

النَّصُّ الشِّعْرِيُّ أَقْرَأُ الْأَبْيَاتَ التَّالِيَةَ، ثُمَّ أُجِبْ:
يَا أَغْلَى أَنْهَارِ الدُّنْيَا مِنْكِ السُّقْيَا سِرُّ الْمَحْيَا
تَحْوِي مَاءً حَلْوًا عَذْبًا وَالطُّهْرَ لِمَنْ يَرْجُو قُرْبَا
وَتُحَوِّلُ صَحْرَانَا حَقْلًا كَالسُّنْدُسِ يَمْنَحُنَا ظِلًّا
أَنْتَ الْمِنْوَالُ وَهُمْ لَبِسُوا رَيَّانُ تَرْوِي لِمَنْ غَرَسُوا

أولًا أَخْتَارُ الْإِجَابَةَ الصَّحِيحَةَ مِمَّا بَيْنَ الْقَوْسَيْنِ:
(١) مَعْنَى (رَيَّان): ........................................... بِالماءِ. (مُمْتَلِئٌ - مُبَرَّدٌ - مُحَلَّى - مَغْسُولٌ)
(٢) جَمْعُ (الدُّنْيَا): ........................................... (الدَّنَايَا - الدُّنَا - الْأَنْدِيَة - الْمَدَائِن)

ثانيًا أَضَعُ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ الْعِبَارَةِ غَيْرِ الصَّحِيحَةِ:
(١) يَتَحَدَّثُ الشَّاعِرُ عَنْ وَاجِبِنَا نَحْوَ نَهْرِ النِّيلِ. ( )
(٢) نَهْرُ النِّيلِ هُوَ سِرُّ الْحَيَاةِ فِي مِصْرَ. ( )
(٣) بَيْنَ (حَلْوًا - عَذْبًا) تَضَادٌّ يُؤَكِّدُ الْمَعْنَى. ( )

ثالثًا أُرَتِّبُ الْفِكَرَ الْآتِيَةَ حَسَبَ وُرُودِهَا فِي الْأَبْيَاتِ:
( ) النِّيلُ لَهُ فَضْلٌ عَلَى الْمِصْرِيِّينَ فِي مَلَابِسِهِم.
( ) تَأْثِيرُ نَهْرِ النِّيلِ فِي أَرْضِ مِصْرَ.
( ) نَهْرُ النِّيلِ سِرُّ الْحَيَاةِ.

رابعًا أَكْتُبُ الْبَيْتَ الْمُعَبِّرَ عَنْ كُلِّ مَعْنًى مِمَّا يَلِي:
(١) مَاءُ النِّيلِ صَافٍ تَقِيٌّ.
......................................................................................................................................
(٢) نَهْرُ النِّيلِ حَوَّلَ أَرْضَ مِصْرَ إِلَى جَنَّاتٍ خَضْرَاءَ.

٤٥
