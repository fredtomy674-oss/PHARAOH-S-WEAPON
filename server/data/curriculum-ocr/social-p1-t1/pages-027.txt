السؤال الثاني: اكتب كلمة (صواب) أمام العبارة الصحيحة، وكلمة (خطأ) أمام العبارة غير الصحيحة مع تصويب الخطأ:
١ - قامت مصر بإنشاء خزان جبل الأولياء في أوغندا لتوليد الكهرباء. ( )
٢ - تقترب قارة إفريقيا من قارة أوروبا عند مضيق موزمبيق. ( )
٣ - يسترد النيل قوته بعد التقاء نهر السوباط ببحر الجبل. ( )
٤ - ظهرت حضارة أكسوم في غرب إفريقيا. ( )
٥ - تُعد هضبة الحبشة أكثر هضاب قارة إفريقيا ارتفاعًا. ( )
٦ - يكثر وجود المنخفضات فوق هضبة شمال إفريقيا. ( )

السؤال الثالث: اختر الإجابة الصحيحة مما بين القوسين:
١ - نشأت حضارة قرطاج في ............... (حاليًا). (السودان - تونس - مصر - إثيوبيا)
٢ - يمثل أعلى قمة جبلية في سلسلة جبال أطلس جبل ............... (العوينات - كلمنجارو - توبقال - كينيا)
٣ - يُعد من أهم مصادر مياه بحيرة فيكتوريا نهر ............... (كاجيرا - السوباط - النيل الأبيض - النيل الأزرق)
٤ - يُطلق على تجمع دول حوض النيل اسم الأندوجو ويعني ........... (المحبة - الصدق - الإخاء - العهد)
