المراجعة العامة على الفصل الدراسي الأول
السؤال الأول: لاحظ خريطة إفريقيا، ثم اكتب مدلول الأرقام الموقعة عليها:
١ - بحيرة
٢ - مضيق
٣ - مضيق
٤ - جبل
٥ - نظام غابات
٦ - نظام حشائش
۷ - نظام الغابات
۸ - صحراء
السؤال الثاني: اكتب كلمة (صواب) أمام العبارة الصحيحة، وكلمة (خطأ) أمام العبارة غير
الصحيحة مع تصويب الخطأ:
١ - يفصل المحيط الأطلنطي بين قارتي إفريقيا وآسيا.
(
)
٢ - الحفاظ على أمن سيناء أحد أسس الأمن القومي المصري الإفريقي. (
)
٣ - تعتمد الزراعة في سهول البحر المتوسط على الأمطار الصيفية.
(
)
٤ - أرسل الملك نخاو الثاني بعثة للدوران حول إفريقيا.
)
٥ - يمر مدار السرطان بجنوب قارة إفريقيا.
)
٦ - تقع هضبة الحبشة غرب إفريقيا.
)
۷ - تأتي معظم مياه نهر النيل من المنابع الدائمة.
)
۸ - نجح حكام طيبة في تأسيس الأسرة الحادية عشرة.
)
۹ - استطاع الملك أحمس الأول القضاء على حركات التمرد في جنوب البلاد. (
)
١٠ - عقد الملك تحتمس الثالث أقدم معاهدة سلام في التاريخ.
)
١١ - أعاد إخناتون فتح المعابد التي أغلقت في عهد توت عنخ آمون.
)
۱۲ - امتدت الإمبراطورية المصرية في عهد أحمس الأول إلى فينيقيا.
)
١٣ - يتسم نظام حشائش السافانا بارتفاع المدى الحراري السنوي.
)
١٤ - الإستبس غطاء نباتي كثيف من الأشجار العالية.
)
١٥ - تتعرض مساحات واسعة من الأراضي الإفريقية للتصحر.
)
١٦ - تنخفض الحرارة شتاءً إلى الصفر في بعض المناطق الداخلية لنظام الصحاري الحارة. (
