تقييم ختامي على الوحدة الثالثة

السؤال الأول: لاحظ خريطة إفريقيا، ثم اكتب مدلول الأرقام الموقعة عليها:
١ - إقليم تنمو به حشائش ....................
٢ - حشائش ....................
٣ - نهر ....................
٤ - بحيرة ....................
٥ - نظام ....................
٦ - نظام غابات ....................
٧ - نهر ....................
٨ - صحراء ....................

السؤال الثاني: اكتب كلمة (صواب) أمام العبارة الصحيحة، وكلمة (خطأ) أمام العبارة غير الصحيحة مع تصويب الخطأ:
١ - تسقط الأمطار طوال العام في نظام الغابات المدارية المطيرة. ( )
٢ - تربى الأغنام والماعز في غابات البحر المتوسط. ( )
٣ - يندر النبات والحيوان بشكل واضح في نظام الصحاري الحارة. ( )
٤ - تُعد حشائش الإستبس أحد نظم الغابات المدارية المطيرة. ( )
٥ - يصنف الأراضي الرطبة ضمن النظم البيئية الأرضية. ( )
٦ - توفر الشعاب المرجانية غذاء ومأوى للعديد من الكائنات البحرية. ( )
٧ - غابات البحر المتوسط دائمة الخضرة لسقوط الأمطار عليها طوال العام. ( )

السؤال الثالث: اختر الإجابة الصحيحة مما بين القوسين:
١ - أحد المكونات الحية في النظام البيئي .................... (الحرارة - الرطوبة - الفطريات - الأمطار)
٢ - تنمو في نظام غابات البحر المتوسط أشجار .................... (الماهوجني - الأبنوس - المطاط - الصنوبر)
٣ - تنمو السافانا البستانية في مناطق أقرب إلى .................... (دائرة الاستواء - مدار الجدي - مدار السرطان - الدائرة القطبية)
٤ - يمكن إقامة مشروعات استغلال الطاقة الشمسية في نظام .................... (الصحاري المعتدلة - الصحاري القطبية - الصحاري الحارة - حشائش الإستبس)
٥ - أحد نظم المياه المالحة في إفريقيا .................... (نهر النيجر - بحيرة تشاد - المستنقعات المغطاة - الشعاب المرجانية)

٢ - التطرف الشديد في درجات الحرارة أحد خصائص نظام ....................
