المراجعة العامة على الفصل الدراسي الأول

١٧ - أدت زيادة حدة موجات الجفاف في الصحاري الإفريقية إلى ندرة النبات الطبيعي. (     )
١٨ - تنتشر أشجار المانجروف في السواحل الغربية لإفريقيا أكثر من السواحل الشرقية. (     )
١٩ - تتسم تربة الغابات المدارية المطيرة بغناها وارتفاع خصوبتها. (     )
٢٠ - قامت شبه جزيرة سيناء بدور مهم في دخول الإسلام للقارة الإفريقية. (     )
٢١ - زادت أهمية البحر الأحمر في نشر الإسلام بعد حفر قناة خليج أمير المؤمنين. (     )
٢٢ - دخل المسلمون الأوائل للحبشة عن طريق مضيق جبل طارق. (     )
٢٣ - ساعدت الظواهر الطبيعية عمرو بن العاص في فتح طرابلس. (     )
٢٤ - أعطى الإسلام المرأة حرية اختيار الزوج. (     )
