١ أُكَمِّلُ بِعَلَامَةِ التَّرْقِيمِ الْمُنَاسِبَةِ:
! ؟ . ؛ ،

الأَبُ: يَا بُنَيَّ ( ) كُنْ مُتَفَائِلًا ( ) لِكَيْ تَرَى الْجَانِبَ الْمُنِيرَ مِنَ الْحَيَاةِ ( )
الابْنُ: كَيْفَ أَكُونُ مُتَفَائِلًا يَا أَبِي ( )
الأَبُ: التَّفَاؤُلُ طَرِيقَةُ تَفْكِيرٍ يُمْكِنُنَا تَعَلُّمُهَا وَتَطْوِيرُهَا، وَلِكَيْ نَكُونَ مُتَفَائِلِينَ ( ) يَجِبُ أَنْ نُرَكِّزَ عَلَى الْجَوَانِبِ
الْإِيجَابِيَّةِ فِي حَيَاتِنَا، كَمَا يَجِبُ أَنْ نَتَحَلَّى بِالصَّبْرِ وَالْعَزِيمَةِ، وَأَلَّا نَسْتَسْلِمَ أَبَدًا عِنْدَ مُوَاجَهَةِ الصُّعُوبَاتِ ( )
الابْنُ: وَمَاذَا لَوْ لَمْ أَنْجَحْ ( )
الأَبُ: الْفَشَلُ جَانِبٌ مِنَ الْحَيَاةِ نَتَعَلَّمُ مِنْهُ ( ) وَالنَّجَاحُ أَيْضًا جَانِبٌ آخَرُ نَتَعَلَّمُ مِنْهُ ( )
الابْنُ: مَا أَجْمَلَ الْحَيَاةَ عِنْدَمَا نَكُونَ مُتَفَائِلِينَ ( )

٢ أَخْتَارُ عَلَامَةَ التَّرْقِيمِ الْمُنَاسِبَةِ مِمَّا بَيْنَ الْقَوْسَيْنِ:
(أ) قَالَ خَالِدٌ ( ) قَرَأْتُ الْكِتَابَ، وَاسْتَمْتَعْتُ بِهِ، وَتَعَلَّمْتُ مِنْهُ الْكَثِيرَ. ( ، - ؛ - : )
(ب) قَالَ الطَّبِيبُ: الصِّحَّةُ تَاجٌ عَلَى رُءُوسِ الْأَصِحَّاءِ ( ) ( ، - ؛ - . )
(ج) مَا أَفْضَلَ التَّفْكِيرَ قَبْلَ الِانْدِفَاعِ ( ) ( ، - ! - : )
(د) قَالَ الطَّالِبُ: مَتَى الِامْتِحَانُ ( ) ( ، - ؛ - ؟ )

٣ أَكْتُبُ فَقْرَةً بِمُسَاعَدَةِ الْكَلِمَاتِ الْآتِيَةِ مُسْتَخْدِمًا عَلَامَاتِ التَّرْقِيمِ الْمُنَاسِبَةِ:
(التَّحَكُّم - كَيْفَ - الِانْدِفَاع - الْغَضَب - التَّفْكِير)
