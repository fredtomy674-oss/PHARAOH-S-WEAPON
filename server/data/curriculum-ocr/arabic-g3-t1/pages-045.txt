تَدْرِيبَاتِ الزَّهْرَةُ وَالصَّبَّارُ

أَسْتَمِعُ إِلَى النَّصِّ، ثُمَّ أُجِيبُ:
(نص الاستماع في آخر الكتاب)

نشاط (1) أَضَعُ عَلَامَةَ (√) أَوْ عَلَامَةَ (×) أَمَامَ الْعِبَارَاتِ التَّالِيَةِ:

(أ) الزَّهْرَةُ جَمِيلَةٌ، لَكِنَّهَا مَغْرُورَةٌ. ( )
(ب) لَمْ تَتَأَثَّرِ الزَّهْرَةُ الْجَمِيلَةُ بِقِلَّةِ الْمَطَرِ. ( )
(ج) تُخَزِّنُ الزَّهْرَةُ الْمَاءَ لِفَصْلِ الصَّيْفِ. ( )
(د) مَنَعَ الصَّبَّارُ الطَّائِرَ مِنْ شُرْبِ الْمَاءِ. ( )
(هـ) انْتَقَمَ الصَّبَّارُ مِنَ الزَّهْرَةِ فِي نِهَايَةِ الْقِصَّةِ. ( )

نشاط (2) أَصِلُ كُلَّ مَوْقِفٍ بِشُعُورِ الزَّهْرَةِ دَاخِلَ الْقِصَّةِ:

(أ) قَالَتِ الزَّهْرَةُ: أَنَا أَهَمُّ نَبَاتِ؛ لِأَنِّي زَهْرَةٌ جَمِيلَةٌ. - دَهْشَة
(ب) نَظَرَتِ الزَّهْرَةُ إِلَى الصَّبَّارِ، فَوَجَدَتْ شَكْلَهُ لَمْ يَتَغَيَّرْ. - نَدَم
(ج) قَالَتِ الزَّهْرَةُ: لَقَدْ كُنْتُ مُخْطِئَةً وَمَغْرُورَةً، أَنَا آسِفَةٌ. - غُرُور

نشاط (3) أُحَلِّلُ الْكَلِمَتَيْنِ إِلَى مَقَاطِعَ صَوْتِيَّةٍ:

سَنَةٌ
الزَّهْرَةُ

هَيَّا نَلْعَبْ وَنَتَعَلَّمْ
• وَزِّعْ أَدْوَارَ (الزَّهْرَةُ الْجَمِيلَةُ - الصَّبَّار - الطَّائِر)
بَيْنَكَ وَبَيْنَ زُمَلَائِكَ، وَمَثِّلُوا الْقِصَّةَ.
