تَدْرِيبَات
الْعُصْفُورُ الْجَرِيءُ

أَسْتَمِعُ إِلَى النَّصِّ، ثُمَّ أُجِيبُ:
نَشَاط (١) أَضَعُ عَلَامَةَ (✓) أَوْ عَلَامَةَ (✗) أَمَامَ الْعِبَارَاتِ التَّالِيَةِ: (نص الاستماع في آخر الكتاب)
( ) (أ) بَنَى الْعُصْفُورُ عُشَّهُ فَوْقَ شَجَرَةٍ أَمَامَ الْمَنْزِلِ.
( ) (ب) الطَّائِرُ الْغَرِيبُ أَرَادَ أَنْ يَسْرِقَ طَعَامَ الْعُصْفُورِ.
( ) (ج) الدِّفَاعُ عَنِ الْأَشْيَاءِ الْمُهِمَّةِ يَحْتَاجُ إِلَى شَجَاعَةٍ.
( ) (د) الْجَيْشُ يَحْمِي الْبِلَادَ مِنَ الْأَعْدَاءِ.

نَشَاط (٢) أَصِلُ مِنَ الْعَمُودِ الْأَوَّلِ مَا يُنَاسِبُهُ فِي الْعَمُودِ الثَّانِي:
(أ) يَقِفُ الطِّفْلُ فِي شُرْفَةِ مَنْزِلِهِ؛ • • لِهُجُومِ طَائِرٍ غَرِيبٍ عَلَى الْعُشِّ.
(ب) ارْتَفَعَ صَوْتُ الْعُصْفُورِ؛ • • لِأَنَّهُ نَجَحَ فِي حِمَايَةِ عُشِّهِ.
(ج) كُلُّ بَلَدٍ لَهُ جَيْشٌ؛ • • لِيَسْتَمْتِعَ بِصَوْتِ غِنَاءِ الْعُصْفُورِ.
(د) عَادَ الْعُصْفُورُ يُغَنِّي بِصَوْتٍ جَمِيلٍ؛ • • لِيُدَافِعَ عَنْهُ ضِدَّ أَيِّ عَدُوٍّ.

نَشَاط (٣) أُرَتِّبُ الْحُرُوفَ التَّالِيَةَ، وَأُكَوِّنُ كَلِمَاتٍ:
(أ) (يَ - رَ - تَ - فَ - شُ) = ____________________
(ب) (طَ - وَ - نُ) = ____________________

هَيَّا نُبْدِعُ وَنَتَعَلَّمُ
نَشَاط (٤) أَتَأَمَّلُ الصُّورَتَيْنِ، ثُمَّ أُجِيبُ:
(أ) عَبِّرْ عَنْ كُلِّ صُورَةٍ بِجُمْلَةٍ مُنَاسِبَةٍ.
(ب) مَا الشَّيْءُ الْمُشْتَرَكُ بَيْنَ الصُّورَتَيْنِ؟
