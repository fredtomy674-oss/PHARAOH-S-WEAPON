تَقْيِيم
وَطَنِي

أَقْرَأُ الْأَبْيَاتَ، ثُمَّ أُجِيبُ:
وَطَنِي وَطَنِي مَا أَعْلَاهُ
هُوَ فِي قَلْبِي لَا أَنْسَاهُ
أَنَا أَبْنِيهِ أَنَا أَرْعَاهُ
وَطَنِي الْغَالِي أَنَا أَهْوَاهُ

أَوَّلًا: أَخْتَارُ الْإِجَابَةَ الصَّحِيحَةَ مِمَّا بَيْنَ الْقَوْسَيْنِ:
( أ ) مَعْنَى (أَهْوَاهُ): (أُسَاعِدُهُ - أُحِبُّهُ - أَسْكُنُ بِهِ)
( ب ) مُضَادُّ (الْغَالِي): (الرَّخِيص - الْبَعِيد - الْوَفِيّ)
( ج ) جَمْعُ (قَلْب): (قَوَالِب - أَلْقَاب - قُلُوب)

ثَانِيًا: أَضَعُ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (✗) أَمَامَ الْعِبَارَةِ غَيْرِ الصَّحِيحَةِ:
( ) الشَّاعِرُ يُحِبُّ وَطَنَهُ وَلَا يَنْسَاهُ.
( ) أَبْنَاءُ الْوَطَنِ يَهْتَمُّونَ بِبِنَائِهِ وَرِعَايَتِهِ.
( ) الْوَطَنُ غَالٍ عَلَى جُنُودِهِ فَقَطْ.
( ) النَّشِيدُ يَتَحَدَّثُ عَنْ جَمَالِ الطَّبِيعَةِ.

ثَالِثًا: أَسْتَخْرِجُ مِنَ الْأَبْيَاتِ كَلِمَتَيْنِ لَهُمَا نَفْسُ نِهَايَةِ كَلِمَةِ (أَعْلَاهُ):
