هَيَّا نَتَعَلَّمُ كَلِمَاتٍ جَدِيدَةً

نَشَاط (١) أَصِلُ الْجُمْلَةَ بِمَعْنَى الْكَلِمَةِ الْمُلَوَّنَةِ:
(أ) اخْتَرِ الرَّفِيقَ قَبْلَ الطَّرِيقِ.
(ب) سَعَى الطَّالِبُ لِتَحْقِيقِ النَّجَاحِ.
(ج) أَتْقَنَ أَخِي اللُّغَةَ الْإِيطَالِيَّةَ.

هَيَّا نَفْهَمُ وَنُنَاقِشُ

نَشَاط (٢) أَضَعُ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (✗) أَمَامَ الْعِبَارَةِ غَيْرِ الصَّحِيحَةِ:
(أ) النَّاجِحُ يَتَمَسَّكُ بِأَمَلِهِ حَتَّى يُحَقِّقَ مَا يُرِيدُ. ( )
(ب) مِنْ صِفَاتِ الْإِنْسَانِ النَّاجِحِ الْمُحَافَظَةُ عَلَى الْوَقْتِ. ( )
(ج) تَتَحَقَّقُ الْأَحْلَامُ دُونَ الْعَمَلِ. ( )
(د) إِتْقَانُ الْعَمَلِ مِنْ أَسْبَابِ النَّجَاحِ. ( )
(هـ) طَاعَةُ اللَّهِ أَسَاسُ الْخَيْرِ فِي حَيَاةِ الْإِنْسَانِ. ( )

نَشَاط (٣) أَخْتَارُ الْإِجَابَةَ الصَّحِيحَةَ مِمَّا بَيْنَ الْقَوْسَيْنِ:
(أ) (الْعَسَل - الْعَمَل) الْكَلِمَتَانِ .................... (مَعْنَاهُمَا وَاحِدٌ - تَنْتَهِيَانِ بِنَفْسِ الصَّوْتِ - بَيْنَهُمَا تَضَادٌّ)
(ب) «يَعِيشُ يَوْمَهُ كَنَحْلَةِ الْعَسَلِ» تَعْبِيرٌ يَدُلُّ عَلَى .................... (النَّشَاط - الرَّاحَة - التَّسَامُح)

نَشَاط (٤) أَضَعُ الصِّفَاتِ الْآتِيَةَ فِي مَكَانِهَا الْمُنَاسِبِ مِنَ الْجَدْوَلِ:
(مُتَفَائِلٌ - كَسُولٌ - حَرِيصٌ عَلَى وَقْتِهِ - مُهْمِلٌ - مُطِيعٌ لِرَبِّهِ - مُتَشَائِمٌ)
