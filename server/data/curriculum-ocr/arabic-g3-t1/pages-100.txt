هَيَّا نَفْهَمُ وَنُنَاقِشُ

نَشَاط (١) أَضَعُ عَلَامَةَ (✓) أَوْ عَلَامَةَ (X) أَمَامَ الْعِبَارَاتِ التَّالِيَةِ:
(أ) قَرَأَ آدَمُ كِتَابًا عَنْ تَارِيخِ الْقِرَاءَةِ وَالْوَرَقِ. ( )
(ب) كَانَ النَّاسُ يَكْتُبُونَ بِالنَّقْشِ عَلَى الْحِجَارَةِ قَبْلَ اخْتِرَاعِ الْوَرَقِ. ( )
(ج) صَنَعَ الْمِصْرِيُّونَ الْقُدَمَاءُ الْوَرَقَ مِنْ نَبَاتِ الْقَمْحِ. ( )
(د) يَأْتِي السَّائِحُونَ لِمِصْرَ لِزِيَارَةِ آثَارِهَا الْعَظِيمَةِ. ( )
(هـ) التَّعْبِيرُ عَنْ حُبِّنَا لِمِصْرَ يَكُونُ بِالْأَفْعَالِ وَالْأَقْوَالِ. ( )
