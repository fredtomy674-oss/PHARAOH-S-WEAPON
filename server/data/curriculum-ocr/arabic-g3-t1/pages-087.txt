هَيَّا نَفْهَمُ وَنُنَاقِشُ

نَشَاط (١) أَضَعُ عَلَامَةَ (✓) أَمَامَ الْعِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (✗) أَمَامَ الْعِبَارَةِ غَيْرِ الصَّحِيحَةِ:
( أ ) صَنَعَتْ سَلْمَى مَقْلَمَةً مِنْ أَدَوَاتٍ قَدِيمَةٍ. ( )
( ب ) غَضِبَتْ الْمُعَلِّمَةُ بِسَبَبِ مَا فَعَلَتْهُ سَلْمَى. ( )
( ج ) الْأَشْيَاءُ الْقَدِيمَةُ لَا تَصْلُحُ لِإِعَادَةِ الْاِسْتِخْدَامِ. ( )
( د ) اقْتَدَى التَّلَامِيذُ بِسَلْمَى، وَفَكَّرُوا فِي فِكَرٍ مِثْلَهَا. ( )
( هـ ) شَرَحَتْ الْمُعَلِّمَةُ الْخُطُوَاتِ الْمُنَاسِبَةَ لِتَنْفِيذِ الْفِكَرِ. ( )

عَالَمُ الْقِصَّةِ

( ب ) لِمَاذَا نُعِيدُ اسْتِخْدَامَ الْأَشْيَاءِ الْقَدِيمَةِ؟ ....................................................................
