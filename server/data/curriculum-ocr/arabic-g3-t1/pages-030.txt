الْقَوَاعِدُ
الْإِمْلَائِيَّةُ
مُرَاجَعَةٌ عَلَى الْمَقَاطِعِ الصَّوْتِيَّةِ

نَشَاط (١) أَدْمِجُ الْمَقَاطِعَ، وَأُكَوِّنُ كَلِمَةً كَالْمِثَالِ:
(أ) يَلْ / عَ / بُ  ← يَلْعَبُ
(ب) رَوْ / عَ / ةٌ  ←
(ج) كُ / رَاةٌ  ←

نَشَاط (٢) أُكْمِلُ الْمَقَاطِعَ النَّاقِصَةَ، ثُمَّ أُكَوِّنُ مِنْهَا اسْمَ الصُّورَةِ كَالْمِثَالِ:
بِطْ / طِي / خٌ  ← بِطِّيخٌ
/ دَ / عُ  ←
/ شَ / ةٌ  ←

نَشَاط (٣) أُحَلِّلُ الْكَلِمَاتِ الْآتِيَةَ إِلَى مَقَاطِعَ صَوْتِيَّةٍ:
تَسَابُقٌ
خَلِيجٌ
مَجَلَّةٌ
