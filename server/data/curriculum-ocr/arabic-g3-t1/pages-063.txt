هَيَّا نَفْهَمُ وَنُنَاقِشُ

نَشَاط (١) أَضَعُ عَلَامَةَ (✓) أَوْ عَلَامَةَ (✗) أَمَامَ الْعِبَارَاتِ التَّالِيَةِ:
( أ ) بَدَأَ الْمُعَلِّمُ الْحِصَّةَ بِحَلِّ الْمَسْأَلَةِ الْحِسَابِيَّةِ. ( )
( ب ) خَافَتْ إِيمَانُ حِينَ سَمِعَتْ سُؤَالَ الْمُعَلِّمِ وَلَمْ تَرْفَعْ يَدَهَا. ( )
( ج ) شَجَاعَةُ إِيمَانَ دَفَعَتْ زُمَلَاءَهَا إِلَى الْمُشَارَكَةِ. ( )
( د ) الدَّرْسُ الَّذِي عَلَّمَتْهُ إِيمَانُ لِزُمَلَائِهَا هُوَ مَحَبَّةُ الْآخَرِينَ. ( )

نَشَاط (٢) أُرَتِّبُ أَحْدَاثَ الْقِصَّةِ مِنْ خِلَالِ الصُّوَرِ:
لِإِعَادَةِ تَرْتِيبِ أَحْدَاثِ الْقِصَّةِ انْظُرْ لِكُلِّ صُورَةٍ، ثُمَّ عَبِّرْ عَنْهَا شَفَهِيًّا، ثُمَّ ضَعْ تَرْقِيمَ كُلِّ صُورَةٍ حَتَّى نِهَايَةِ الْقِصَّةِ.

أَنَا أَسْتَطِيعُ
نَشَاط (٣) مَاذَا يَحْدُثُ لَوْ؟
( أ ) لَمْ يُشَجِّعِ الْمُعَلِّمُ التَّلَامِيذَ عَلَى الْمُحَاوَلَةِ.
( ب ) خَافَ كُلُّ التَّلَامِيذِ مِنَ الْمُشَارَكَةِ.
