نشاط ٣ أُكْمِلُ بِحَرْفِ الْجَرِّ الْمُنَاسِبِ:
( أ ) تَحَدَّثَ الطَّبِيبُ ........................ فَوَائِدِ الْفَاكِهَةِ.
( ب) وَضَعْتُ الْكِتَابَ ........................ الْحَقِيبَةِ.
( جـ) عَرَفْتُ مَعْلُومَاتٍ كَثِيرَةً ........................ حَيَاةِ النَّحْلِ.
( د ) قَفَزَ الْقِطُّ ........................ النَّافِذَةِ عَلَى الْأَرْضِ.

تَذَكَّرْ
مِنْ حُرُوفِ الْجَرِّ (مِنْ - إِلَى - فِي).

نشاط ٤ أُصَوِّبُ الْخَطَأَ، وَأَسْتَخْدِمُ حَرْفَ الْجَرِّ الْمُنَاسِبَ كَالْمِثَالِ:
( أ ) رَكِبَ الْفَارِسُ عَنِ الْحِصَانِ. - ركب الفارس على الحصان.
( ب) الْبَيْتُ بَعِيدٌ عَلَى الْمَدْرَسَةِ. -
( جـ) يُحَافِظُ خَالِدٌ عَنْ أَدَوَاتِهِ. -
( د ) قَرَأْتُ قِصَّةً مُمْتِعَةً عَلَى الْفَضَاءِ. -

نشاط ٥ أُجِيبُ مُسْتَخْدِمًا حَرْفَ الْجَرِّ الْمُنَاسِبَ (عَنْ - عَلَى) كَالْمِثَالِ:
( أ ) أَيْنَ وَضَعَ التَّلْمِيذُ الْكُتُبَ؟ - وضع التلميذ الكتب على المكتب.
( ب) عَنْ مَاذَا تَحَدَّثَتِ الْمُعَلِّمَةُ؟ -
( جـ) أَيْنَ يَقِفُ الْعُصْفُورُ؟ -
( د ) أَيْنَ الْكِتَابُ؟ -
