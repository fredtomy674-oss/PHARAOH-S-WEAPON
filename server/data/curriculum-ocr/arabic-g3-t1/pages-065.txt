الْأَسَالِيبُ وَالتَّرَاكِيبُ أُسْلُوبُ النَّفْيِ (لَمْ - لَنْ)

أَقْرَأُ وَأُلَاحِظُ:

لَمْ يَذْهَبْ مُحَمَّدٌ إِلَى الْمَدْرَسَةِ أَمْسِ.
لَنْ يَلْعَبَ مُحَمَّدٌ كُرَةَ الْقَدَمِ غَدًا.

. (لَمْ): يَأْتِي بَعْدَهَا فِعْلٌ مُضَارِعٌ، وَتَنْفِي حُدُوثَهُ فِي الْمَاضِي.
. (لَنْ): يَأْتِي بَعْدَهَا فِعْلٌ مُضَارِعٌ، وَتَنْفِي حُدُوثَهُ فِي الْمُسْتَقْبَلِ.

نَشَاط (١) أَصِلُ الْجُمَلَ بِأَدَاةِ النَّفْيِ الْمُنَاسِبَةِ كَالْمِثَالِ:

لَنْ تُسَافِرَ الْأُسْرَةُ الصَّيْفَ الْمُقْبِلَ.
يَسْتَخْدِمُ عُمَرُ الْهَاتِفَ مُنْذُ سَاعَةٍ.
يَزُورُ السَّائِحُ الْأَهْرَامَاتِ غَدًا.

لَنْ
نُشَاهِدُ الْمُبَارَاةَ أَمْسِ.
نَسْمَعُ قِصَّةَ الْأُسْبُوعِ الْمَاضِي.
أَرْسُمُ اللَّوْحَةَ فِي الْإِجَازَةِ الْقَادِمَةِ.

نَشَاط (٢) أُلَاحِظُ اسْتِخْدَامَ (لَمْ - لَنْ)، ثُمَّ أَضَعُ عَلَامَةَ (✓) أَوْ (X) كَالْمِثَالِ:

(أ) لَمْ نُسَافِرِ الصَّيْفَ الْقَادِمَ. ( X )
(ب) لَنْ نَزُورَ الْمَكْتَبَةَ بَعْدَ غَدٍ. ( )
(ج) لَمْ أَذْهَبْ إِلَى الْحَدِيقَةِ الْأُسْبُوعِ الْمَاضِي. ( )
(د) لَنْ يَرْكَبَ أَمِيرُ الْقَارِبَ أَمْسِ. ( )
(هـ) لَمْ تُشَاهِدْ سَارَةُ التِّلْفَازَ الْأُسْبُوعَ الْمَاضِي. ( )
