تَقْيِيمَاتُ التَّقْيِيمُ النِّهَائِيُّ

اخْتَرِ الإِجَابَةَ الصَّحِيحَةَ مِمَّا يَأْتِي:
1 الرُّكْنُ الأَعْظَمُ فِي الحَجِّ هُوَ
( أ ) الطَّوَافُ بِالكَعْبَةِ. ( ب ) الوُقُوفُ بِعَرَفَةَ. ( ج ) السَّعْيُ بَيْنَ الصَّفَا وَالمَرْوَةِ.
2 نَزَلَتْ سُورَةُ «المَعَارِجِ» فِي
( أ ) مَكَّةَ المُكَرَّمَةِ. ( ب ) المَدِينَةِ المُنَوَّرَةِ. ( ج ) الطَّائِفِ.
3 كَانَ حِصَارُ الطَّائِفِ بَعْدَ غَزْوَةِ
( أ ) بَدْرٍ. ( ب ) حُنَيْنٍ. ( ج ) أُحُدٍ.
4 الصَّحَابِيُّ الَّذِي اشْتَهَرَ بِرِوَايَةِ الحَدِيثِ وَكَانَ مِنْ أَهْلِ الصُّفَّةِ هُوَ
( أ ) عَلِيُّ بْنُ أَبِي طَالِبٍ رَضِيَ اللَّهُ عَنْهُ . ( ب ) أَبُو هُرَيْرَةَ رَضِيَ اللَّهُ عَنْهُ . ( ج ) عُمَرُ بْنُ الخَطَّابِ رَضِيَ اللَّهُ عَنْهُ .
5 مِنْ أَسْمَاءِ يَوْمِ القِيَامَةِ الَّتِي وَرَدَتْ فِي القُرْآنِ الكَرِيمِ
( أ ) الغَاشِيَةُ. ( ب ) الفَاتِحَةُ. ( ج ) الصَّادِمَةُ.
6 مِنْ نَتَائِجِ حِصَارِ الطَّائِفِ أَنَّ أَهْلَهَا
( أ ) ظَلُّوا عَلَى شِرْكِهِمْ حَتَّى وَفَاةِ النَّبِيِّ ﷺ.
( ب ) أَعْلَنُوا إِسْلَامَهُمْ بَعْدَ فَتْرَةٍ مِنَ الحِصَارِ.
( ج ) عَقَدُوا مُعَاهَدَةَ صُلْحٍ مَعَ المُسْلِمِينَ دُونَ دُخُولِ الإِسْلَامِ.
7 كَانَ الإِمَامُ أَبُو حَنِيفَةَ يَعْتَمِدُ فِي اجْتِهَادِهِ عَلَى
( أ ) الحَدِيثِ فَقَطْ. ( ب ) القِيَاسِ الفِقْهِيِّ والرَّأْيِ. ( ج ) الاجْتِهَادِ بِدُونِ قَوَاعِدَ.
8 يَدُلُّ حَدِيثُ فِي كُلِّ كَبِدٍ رَطْبَةٍ أَجْرٌ عَلَى
( أ ) وُجُوبِ الصَّدَقَةِ عَلَى الفُقَرَاءِ فَقَطْ.
( ب ) العِنَايَةِ بِجَمِيعِ الكَائِنَاتِ الحَيَّةِ.
( ج ) رِعَايَةِ الأَطْفَالِ الأَيْتَامِ فَقَطْ.

٩٤
