نَشَاط 3 رَتِّبِ الأَحْدَاثَ الآتِيَةَ حَسَبَ مَا وَرَدَتْ بِالدَّرْسِ:
( ) شُعُورُ المُسْلِمِينَ بِالثِّقَةِ الزَّائِدَةِ بِسَبَبِ كَثْرَةِ عَدَدِهِمْ.
( ) ثَبَاتُ النَّبِيِّ ﷺ وَعَوْدَةُ الجَيْشِ المُسْلِمِ لِلتَّمَاسُكِ.
( ) فَتْحُ المُسْلِمِينَ مَكَّةَ المُكَرَّمَةَ فِي العَامِ الثَّامِنِ مِنَ الهِجْرَةِ.
( ) اضْطِرَابُ صُفُوفِ جَيْشِ المُسْلِمِينَ وَفِرَارُ بَعْضِهِمْ مِنْ هَوْلِ المُفَاجَأَةِ.
( ) اسْتِعْدَادُ قَبِيلَتَيْ هَوَازِنَ وَثَقِيفٍ لِحَرْبِ المُسْلِمِينَ.

نَشَاط ٤ أَجِبْ عَنِ الأَسْئِلَةِ التَّالِيَةِ:
1 لِمَادَا وَقَعَتْ غَزْوَةُ حُنَيْنٍ؟
2 كَيْفَ أَثَّرَتِ الثِّقَةُ الزَّائِدَةُ بِالنَّفْسِ عَلَى المُسْلِمِينَ فِي بِدَايَةِ الغَزْوَةِ؟
3 كَيْفَ تَعَامَلَ النَّبِيُّ ﷺ مَعَ الأَسْرَى بَعْدَ المَعْرَكَةِ؟
4 مَا الآيَةُ القُرْآنِيَّةُ الَّتِي تَحَدَّثَتْ عَنْ أَحْدَاثِ غَزْوَةِ حُنَيْنٍ؟ وَمَاذَا تَعَلَّمْنَا مِنْهَا؟
5 مَا الدُّرُوسُ المُسْتَفَادَةُ مِنْ غَزْوَةِ حُنَيْنٍ؟
