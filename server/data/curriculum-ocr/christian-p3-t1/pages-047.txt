الأنشطة والممارسات

نشاط: مَنْ هُوَ الرُّوحُ القُدُسُ؟
- أَكْمِلِ الْجَدْوَلَ مُسْتَعِينًا بِالْعِبَارَاتِ التَّالِيَةِ:
- (نَسْجُدُ لَهُ مَعَ الْآبِ وَالِابْنِ - يُقَدِّسُ الْمُؤْمِنِينَ وَيَمْنَحُهُمُ الْحَيَاةَ الْأَبَدِيَّةَ - مَوْجُودٌ فِي كُلِّ مَكَانٍ
- ظَهَرَ فِي مَعْمُودِيَّةِ السَّيِّدِ الْمَسِيحِ مَعَ الْآبِ وَالِابْنِ - أَقْنُومٌ إِلَهِيٌّ - خَالِقٌ

| الرُّوحُ الْقُدُسُ فِي بِدْعَةِ مَقْدُونِيُوس | الرُّوحُ الْقُدُسُ فِي إِيمَانِ الْكَنِيسَةِ الْمُسْتَقِيمِ (الَّذِي دَافَعَ عَنْهُ الْبَابَا تِيمُوثَاؤُسُ) |
| :--- | :--- |
| مُجَرَّدُ قُوَّةٍ أَوْ مَلَاكٍ عَظِيمٍ. | |
| مَخْلُوقٌ، لَيْسَ لَهُ قُدْرَةُ الْخَلْقِ. | |
| مَحْدُودُ الْمَكَانِ. | |
| أَقَلُّ مِنَ الْآبِ وَالِابْنِ. | |
| لَا يُعْبَدُ لِأَنَّهُ لَيْسَ إِلَهًا. | |
| لَا يَمْنَحُ الْحَيَاةَ الْإِلَهِيَّةَ | |

أسئلة الدرس
صِلْ بَيْنَ الْعِبَارَاتِ
اقرأ عِبَارَاتِ الْعَمُودِ (أ) جَيِّدًا، ثُمَّ اخْتَرِ الرَّقْمَ الْمُنَاسِبَ مِنَ الْعَمُودِ (ب)، وَاكْتُبْهُ دَاخِلَ الْقَوْسَيْنِ.

| العمود(أ) | العمود(ب) |
| :--- | :--- |
| ١- الْبَابَا تِيمُوثَاؤُسُ الْأَوَّلُ ( ) | ١- دَعَا إِلَى انْعِقَادِ الْمَجْمَعِ. |
| ٢- مَقْدُونِيُوسُ ( ) | ٢- الرَّبُّ الْمُحْيِي. |
| ٣- الْقُسْطَنْطِينِيَّةُ ( ) | ٣- عَلَّمَ أَنَّ الرُّوحَ الْقُدُسَ لَيْسَ إِلَهًا. |
| ٤- الرُّوحُ الْقُدُسُ ( ) | ٤- دَافَعَ عَنْ أُلُوهِيَّةِ الرُّوحِ الْقُدُسِ. |
| ٥- الْإِمْبَرَاطُورُ تِيُودُوسِيُوسُ الْأَوَّلُ ( ) | ٥- مَكَانُ انْعِقَادِ مَجْمَعِ الْقُسْطَنْطِينِيَّةِ. |

أسئلة متنوعة
١- مَا هُوَ التَّعْلِيمُ الْخَاطِئُ الَّذِي عَلَّمَ بِهِ مَقْدُونِيُوسُ؟
٢- لِمَاذَا أَضَافَ الْمَجْمَعُ جُزْءًا جَدِيدًا إِلَى قَانُونِ الْإِيمَانِ؟
٣- بِمَاذَا دَافَعَ الْبَابَا تِيمُوثَاؤُسُ عَنِ الرُّوحِ الْقُدُسِ؟
٤- مَا مَعْنَى عِبَارَةِ: «الرُّوحُ الْقُدُسُ الرَّبُّ الْمُحْيِي»؟
٥- مَا هُوَ قَرَارُ مَجْمَعِ الْقُسْطَنْطِينِيَّةِ؟
