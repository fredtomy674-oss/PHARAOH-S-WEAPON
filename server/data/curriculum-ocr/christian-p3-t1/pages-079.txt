السؤال الثاني: ضع علامة (/) أمام العبارة الصحيحة وعلامة (X) أمام العبارة غير الصحيحة:
١. جاء في قانون الإيمان أن السيد المسيح مولود غير مخلوق ومساو للآب في الجوهر. ( )
٢. العقل وحده كاف ليعيش الإنسان مع الله دون الحاجة لسلام القلب والوجدان. ( )
٣. أنكر الرسول بطرس السيد المسيح ثلاث مرات في ليلة القبض عليه وبكى بكاءً مرّاً. ( )
٤. العلامة بنتينوس كان يثق أن كل حكمة حقيقية مصدرها الله. ( )
٥. يوحنا الرسول هو كاتب سفر الرؤيا وهو في جزيرة بطمس. ( )
٦. نؤمن بوجود ثلاثة آلهة منفصلة في الجوهر الإلهي. ( )
٧. معجزة تحويل الماء إلى خمر أظهرت أن الطبيعة والمادة لا تطيعان إلا خالقهما. ( )
٨. رفضت الشياطين الاعتراف بالسيد المسيح أو معرفة هويته الإلهية أثناء إخراجها. ( )
٩. "نعظمك" في مقدمة قانون الإيمان تعنى نرفع شأنك ونكرمك ونجلك تمجيداً لمكانتك العالية. ( )
١٠. الصلاة المقبولة هي مجرد واجب روتيني يجب تأديته سريعاً باللسان دون حاجة لتركيز القلب. ( )
١١. ينظر الله إلى كثرة الكلام والتباهي بالأعمال الخارجية كما فعل الفريسي في صلاته. ( )
١٢. اختار الله أغسطس قيصر ليرعى مريم العذراء ويهتم بها بعد خروجها من الهيكل. ( )
١٣. بدعة نسطور كانت تنادي بأن العذراء مريم هي "والدة الإله" (ثيؤطوكوس) بكل ثقة. ( )
١٤. البابا كيرلس الأول ينتمي إلى مدرسة الإسكندرية اللاهوتية التي أنارت المسكونة بتعاليمها المستقيمة. ( )
١٥. أكد مجمع أفسس المسكوني رفض تعليم نسطور وثبت لقب "والدة الإله" للعذراء مريم. ( )
١٦. دقلديانوس هو الإمبراطور الروماني الذي اتخذت الكنيسة بداية حكمه بداية لتقويم الشهداء. ( )
١٧. المسؤولية الحقيقية في الفكر الكنسي تعني التمسك بالمنصب وإرضاء رغبات الجميع ومسايرتهم. ( )
١٨. الإيمان المسيحي والتاريخ الكنسي ليس مجرد معلومات للمعرفة، بل هو حياة وقصة حفظ الله لخلاص الإنسان. ( )
١٩. نبوءة سمعان الشيخ للعذراء "وأنتِ أيضاً يجوز في نفسك سيف" تحققت من خلال آلامها عند الصليب. ( )
٢٠. شروط الصلاة قلب صادق، تواضع، إيمان، ثبات واستمرارية، واتحاد بالله. ( )
