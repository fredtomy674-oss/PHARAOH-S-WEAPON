الأنشطة والممارسات ؟

نشاط (١) : من المقصود
اقرأ كل عبارة من العبارات التالية، ثم اكتب اسم التلميذ المقصود.
١- خان السيد المسيح وسلمه مقابل ثلاثين من الفضة : ( .................... )
٢- كان يعمل عشارًا، وترك عمله عندما دعاه السيد المسيح : ( .................... )
٣- اشتهر بأنه شكاك، وأعلن إيمانه بعد القيامة قائلاً: «ربي وإلهي» : ( .................... )
٤- يُلقب بـ«التلميذ الذي كان يسوع يحبه»، ورافقه حتى الصليب : ( .................... )
٥- كان شقيق يوحنا بن زبدي، وأول من استشهد من التلاميذ : ( .................... )
٦- اختاره التلاميذ بعد صعود السيد المسيح ليكمل عدد الاثني عشر بدل يهوذا الإسخريوطي : ( .................... )

نشاط (٢) : اكتشف الخطأ
ضع دائرة حول الكلمة الخطأ ثم اكتب التصحيح :
١- استشهد يوحنا الحبيب منكس الرأس. ٢- كان متى صياد سمك قبل الدعوة.
٣- قال بطرس : «ربي وإلهي». ٤- كتب توما سفر الرؤيا.
٥- قبل صعود المسيح اختير متياس بدلًا من يهوذا.

نشاط (٣) : آية وتلميذ
اقرأ الآية، ثم اختر اسم التلميذ الذي تنطبق عليه الآية :
(نثنائيل - متياس - أندراوس - بطرس - توما - يوحنا الحبيب - متى)
١- «فَتَرَكَ كُلَّ شَيْءٍ وَقَامَ وَتَبِعَهُ» (لو ٥ : ٢٨) الشخصية : ....................
٢- «رَبِّي وَإِلهِي» (يو ٢٠ : ٢٨) الشخصية : ....................
٣- «هُوَذَا أُمُّكَ» (يو ١٩ : ٢٧) الشخصية : ....................
٥- «قَبْلَ أَنْ دَعَاكَ فِيلُبُّسُ وَأَنْتَ تَحْتَ التِّينَةِ رَأَيْتُكَ» (يو ١ : ٤٨) الشخصية : ....................
٦- «قَدْ وَجَدْنَا مَسِيَّا الَّذِي تَفْسِيرُهُ: الْمَسِيحُ» (يو ١ : ٤١) الشخصية : ....................

أسئلة الدرس
اختيار من متعدد
١- قال توما للسيد المسيح : .................... وإلهي». ( سيدي - ربي - معلمي - مخلصي )
٢- كتب يوحنا الحبيب سفر .................... ( التكوين - الأعمال - الرؤيا - المزامير )
٣- كان متى يعمل .................... قبل دعوته. ( نجارًا - صيادًا - عشارًا - راعيًا )
٤- اختير متياس الرسول بعد .................... يهوذا الإسخريوطي. ( توبة - خيانة - معجزة - شفاء )
٥- نُفي يوحنا إلى جزيرة اسمها .................... ( كريت - قبرص - بطمس - رودس )

أسئلة متنوعة
١- لماذا لُقب يوحنا الرسول بـ«رسول المحبة»؟ ٢- ماذا قال توما عندما رأى السيد المسيح بعد القيامة؟
٣- كيف استجاب متى لدعوة السيد المسيح له؟ ٤- لماذا اختار الرسل متياس الرسول؟
