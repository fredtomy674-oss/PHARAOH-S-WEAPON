الأنشطة والممارسات ؟
نشاط : اكتب أمام كل عبارة مما يلى ما يناسبها من نص "قانون الإيمان".

| العبارات | النص من قانون الإيمان |
| :--- | :--- |
| الإيمان بأن الله يدير ويدبر كل تفاصيل الكون بعنايته الإلهية ولا يخرج شيء عن سلطانه. | |
| تأكيد أن الابن ليس جزءاً من الخليقة، ولم يمر بوقت لم يكن فيه موجوداً، بل هو أزلي. | |
| اتخاذ ابن الله جسداً حقيقياً ورأينا مجده، وصار إنساناً شبيهاً بنا في كل شيء ما خلا الخطية وحدها. | |
| الإيمان بالمجيء الثاني للسيد المسيح في نهاية الأيام لتقديم الحساب العادل لكل البشر. | |
| للكنيسة صفات أربعة رئيسية تميز هويتها وإيمانها المستلم. | |

محفوظات ٢ بعض الآيات الذهبية
١. "السَّمَاوَاتُ تُحَدِّثُ بِمَجْدِ اللهِ، وَالْفَلَكُ يُخْبِرُ بِعَمَلِ يَدَيْهِ." [مز ١٩: ١].
٢. "كُلُّ الْكِتَابِ هُوَ مُوحًى بِهِ مِنَ اللهِ، وَنَافِعٌ لِلتَّعْلِيمِ وَالتَّوْبِيخِ، لِلتَّقْوِيمِ وَالتَّأْدِيبِ الَّذِي فِي الْبِرِّ." [٢ تي ٣: ١٦].
٣. "لَيْسَ أَنْتُمُ اخْتَرْتُمُونِي بَلْ أَنَا اخْتَرْتُكُمْ، وَأَقَمْتُكُمْ لِتَذْهَبُوا وَتَأْتُوا بِثَمَرٍ، وَيَدُومَ ثَمَرُكُمْ." [يو ١٥: ١٦]
٤. "وَتَعْرِفُونَ الْحَقَّ، وَالْحَقُّ يُحَرِّرُكُمْ." [يو ٨: ٣٢].
٥. "يَنْبَغِي أَنْ يُطَاعَ اللهُ أَكْثَرَ مِنَ النَّاسِ." [أع ٥: ٢٩].
