The Relation Between the Areas of two Similar Polygons

theorem
4
Ratio of the areas of the surfaces of two similar polygons equals the square of
the ratio of the lengths of any two corresponding sides of the polygons
(Proof is not required)

Given: polygon ABCDE ~ polygon A'B'C'D'E'

R.t.p.: a (polygon ABCDE) / a (polygon A'B'C'D'E') = (AB / A'B')^2

proof: from A, A' draw AC, AD, A'C', A'D'

∴ polygon ABCDE ~ polygon A'B'C'D'E'

∴ they are divided into the same number of triangles, each is similar to the corresponding
one (fact). then:
a(Δ ABC) / a(Δ A'B'C') = (BC / B'C')^2 , a(Δ ADE) / a(Δ A'D'E') = (CD / C'D')^2 , a(Δ ACD) / a(Δ A'C'D') = (DE / D'E')^2

∴ BC / B'C' = CD / C'D' = DE / D'E' = AB / A'B' (from similar polygons)

∴ a(Δ ABC) / a(Δ A'B'C') = a(Δ ACD) / a(Δ A'C'D') = a(Δ ADE) / a(Δ A'D'E') = (AB / A'B')^2

From properties of proportion

a(Δ ABC) + a(Δ ACD) + a(Δ ADE) / a(Δ A'B'C') + a(Δ A'C'D') + a(Δ A'D'E') = (AB / A'B')^2

then: a (polygon ABCDE) / a (polygon A'B'C'D'E') = (AB / A'B')^2 Q.E.D

Notice
(AB / A'B')^2 = (AB)^2 / (A'B')^2
