Example
4 ABCD is a quadrilateral in which X ∈ AB, Y ∈ AC where XY // BC,
draw YZ // CD and intersects AD at Z. Prove that XZ // DB.

Solution
In Δ ABC:
∵ XY // BC ∴ AX/XB = AY/YC (1)
In Δ ADC:
∵ YZ // CD ∴ AZ/ZD = AY/YC (2)
from (1) and (2) we deduce that: AX/XB = AZ/DZ
In Δ ABD:
∵ AX/XB = AZ/ZD ∴ XZ // DB
