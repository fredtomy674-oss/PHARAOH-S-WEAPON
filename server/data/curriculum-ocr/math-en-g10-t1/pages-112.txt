1- If sin α = cosβ (where α, β are the measures of two complementary angles) then:
➢ sin α = sin( π/2 - β) hence: α = π/2 - β i.e. α + β = π/2
➢ sin α = sin( π/2 + β) hence: α = π/2 + β i.e. α - β = π/2
Add 2nπ (where n ∈ Z) to the angle π/2 then:
when sinα = cosβ then α ± β = π/2 + 2nπ (n ∈ Z ), similarly:
when csc α = secβ then α ± β = π/2 + 2nπ (n ∈ Z ), α ≠ nπ , β ≠ (2n + 1)π/2

2- If tan α = cotβ (where α, β are the measure of two complementary angles) then :
➢ tan α = tan( π/2 - β) hence: α = π/2 - β i.e. α + β = π/2
➢ tan α = tan( 3π/2 - β) hence: α = 3π/2 - β i.e. α + β = 3π/2
Add 2nπ (where n ∈ Z) to the two angles π/2 and 3π/2 then :
when tan α = cotβ then α + β = π/2 + nπ (where n ∈ Z), α ≠ (2n + 1)π/2 , β ≠ nπ
