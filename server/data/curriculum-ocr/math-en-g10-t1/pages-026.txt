Example
3 Represent graphically f, where f(x) = x² - 2x - 3, then determine the sign of the function f.
Solution
By factorizing the equation: x² - 2x - 3 = 0
(x - 3) (x + 1) = 0
Then the two roots of the equation are: -1, 3
From the graph, we get:
➢ f(x) > 0 when x ∈ R - [- 1, 3]
➢ f(x) < 0 when x ∈ ] - 1, 3 [
➢ f(x) = 0 when x ∈ {- 1, 3}
