الدَّرْسُ الثَّانِي: ابْدَأْ بِنَفْسِكَ

نَشَاطٌ ثُنَائِيٌّ
٤ تَقْوِيمُ الْأَقْرَانِ:
• اطْلُبْ إِلَى أَحَدِ الْأَقْرَانِ التَّحَدُّثَ عَنْ حُسْنِ الْخُلُقِ وَأَثَرِهِ عَلَى الْفَرْدِ وَالْمُجْتَمَعِ وَحَاجَةِ الْعُلَمَاءِ إِلَيْهِ
وَقَوِّمْهُ أَثْنَاءَ الْحَدِيثِ بِاسْتِخْدَامِ اسْتِمَارَةِ التَّقْوِيمِ التَّالِيَةِ:

| الْمَهَارَةُ | مُسْتَوَى الْأَدَاءِ |
| :--- | :--- |
| | مَقْبُولٌ (١) | جَيِّدٌ (٢) | جَيِّدٌ جِدًّا (٣) | مُمْتَازٌ (٤) |
| يَسْتَخْدِمُ أَدَوَاتِ تَوْكِيدٍ. | | | | |
| يَسْتَخْدِمُ الْوَقَفَاتِ اسْتِخْدَامًا مُنَاسِبًا أَثْنَاءَ الْحَدِيثِ. | | | | |
| يُوَظِّفُ الْأَسَالِيبَ الْبَلَاغِيَّةَ فِي تَعْبِيرَاتِهِ. | | | | |

٥ • تَخَيَّرْ فِكْرَةً أَعْجَبَتْكَ مِنْ فِكَرِ النَّصِّ ثُمَّ تَحَدَّثْ عَنْهَا فِي خَمْسِ عَشْرَةَ جُمْلَةً مُقَسِّمًا حَدِيثَكَ إِلَى
فِكَرٍ فَرْعِيَّةٍ مُتَّصِلَةٍ بِهَذِهِ الْفِكْرَةِ الرَّئِيسَةِ.

نَشَاطٌ جَمَاعِيٌّ
٦ (ابْدَأْ بِنَفْسِكَ - اتْرُكْ مُجَازَاةَ السَّفِيهِ - هَلَّا لِنَفْسِكَ كَانَ ذَا التَّعْلِيمِ - لَا تَنْهَ عَنْ خُلُقٍ وَتَأْتِي مِثْلَهُ)
تَحَدَّثْ مَعَ زُمَلَائِكَ عَنْ آدَابِ طَالِبِ الْعِلْمِ مَعَ تَوْظِيفِ التَّعْبِيرَاتِ السَّابِقَةِ فِي حَدِيثِكَ.
٧ اقْرَأِ النَّصَّ قِرَاءَةً جَهْرِيَّةً وَاضِحَةً مُعَبِّرَةً.

نَشَاطٌ ثُنَائِيٌّ
٨ • تَعَاوَنْ مَعَ زَمِيلِكَ وَاقْرَأَا مَا بِالْجَدْوَلِ ثُمَّ أَجِبْ عَنِ الْأَسْئِلَةِ الَّتِي تَلِيهِ:

| نَمُوذَجٌ مِنَ النَّثْرِ | نَمُوذَجٌ مِنَ الشِّعْرِ |
| :--- | :--- |
| أَمَّا بَعْدُ: حَفِظَكُمُ اللَّهُ يَا أَهْلَ صِنَاعَةِ الْكِتَابَةِ، فَلَيْسَ أَحَدٌ مِنْ أَهْلِ الصِّنَاعَاتِ كُلِّهَا أَحْوَجَ إِلَى اجْتِمَاعِ جَلَالِ الْخَيْرِ الْمَحْمُودَةِ، وَخِصَالِ الْفَضْلِ الْمَذْكُورَةِ الْمَعْدُودَةِ مِنْكُمْ أَيُّهَا الْكُتَّابُ، إِذَا كُنْتُمْ عَلَى مَا يَأْتِي فِي هَذَا الْكِتَابِ مِنْ صِفَتِكُمْ، فَإِنَّ الْكَاتِبَ يَحْتَاجُ فِي نَفْسِهِ أَنْ يَكُونَ حَلِيمًا فِي مَوْضِعِ الْحِلْمِ. | يَا أَيُّهَا الرَّجُلُ الْمُعَلِّمُ غَيْرَهُ هَلَّا لِنَفْسِكَ كَانَ ذَا التَّعْلِيمِ تَصِفُ الدَّوَاءَ لِذِي السَّقَامِ وَذِي الضَّنَى كَيْمَا يَصِحَّ بِهِ وَأَنْتَ سَقِيمُ وَأَرَاكَ تَصْلُحُ بِالرَّشَادِ عُقُولَنَا أَبَدًا وَأَنْتَ مِنَ الرَّشَادِ عَقِيمُ لَا تَنْهَ عَنْ خُلُقٍ وَتَأْتِي مِثْلَهُ عَارٌ عَلَيْكَ إِذَا فَعَلْتَ عَظِيمُ |

٥- هَدَفُهُ: تَدْرِيبُ الطَّالِبِ عَلَى إِنْتَاجِ فِكَرٍ مُتَّصِلَةٍ بِمَوْضُوعِ الْحَدِيثِ.
٨- تَدْرِيبُ الطَّالِبِ عَلَى التَّفْرِيقِ بَيْنَ قِرَاءَةِ الشِّعْرِ وَقِرَاءَةِ النَّثْرِ.

الْفَصْلُ الدِّرَاسِيُّ الْأَوَّلُ ٦٩
