الدرس الثاني : شبابٌ تَسامى لِلعُلا لِلسَّموأل

٤ اسْتَمِعْ إِلَى مُعَلِّمِكَ وَامْلَأِ الشَّكْلَ التَّالِيَ:
النَّصُّ المَسْمُوعُ | نَوْعُهُ
----------------|-------
                |
                |
                |

٥ نَشَاطٌ جَمَاعِيٌّ بِالتَّعَاوُنِ مَعَ زُمَلَائِكَ اقْرَأِ الْأَبْيَاتَ ثُمَّ أَجِبْ:

تُعَيِّرُنَا أَنَّا قَلِيلٌ عَدِيدُنَا          فَقُلْتُ لَهَا إِنَّ الْكِرَامَ قَلِيلُ
وَمَا قَلَّ مَنْ كَانَتْ بَقَايَاهُ مِثْلَنَا      شَبَابٌ تَسَامَى لِلْعُلَا وَكُهُولُ
وَمَا ضَرَّنَا أَنَّا قَلِيلٌ وَجَارُنَا        عَزِيزٌ وَجَارُ الْأَكْثَرِينَ ذَلِيلُ

( ١ ) هَاتِ مَا يَلِي فِي جُمَلٍ:
- مَعْنَى : تَسَامَى 
- مُضَادُّ : تُعَيِّرُ
- مُفْرَدُ : كُهُولُ

( أ ) هَاتِ مُرَادِفَ ( تَسَامَى ) وَمُضَادَ ( تُعَيِّرُ ) وَمُفْرَدَ ( كُهُولُ ) .
( ب ) كَيْفَ تَسَامَى الشَّبَابُ كَمَا تَفْهَمُ مِنَ الْأَبْيَاتِ ؟ وَمَا عَلَاقَةُ ذَلِكَ بِالْغَرَضِ مِنَ النَّصِّ ؟
( ج ) مَا رَأْيُكَ فِي الْأَدِلَّةِ الَّتِي سَاقَهَا الشَّاعِرُ لِلدِّفَاعِ عَنْ قَوْمِهِ ؟
( د ) ( سَمَا ) ( تَسَامَى ) أَيُّهُمَا أَبْلَغُ فِي أَدَاءِ الْمَعْنَى ؟ وَلِمَاذَا ؟
( هـ ) اسْتَخْرِجْ مِنَ الْأَبْيَاتِ مُحَسِّنَيْنِ بَدِيعِيَّيْنِ ، وَبَيِّنْ أَثَرَهُمَا فِي أَدَاءِ الْمَعْنَى .

٦ اقْرَأِ النَّصَّ مَرَّةً أُخْرَى، ثُمَّ دَلِّلْ عَلَى :
( أ ) تَوْظِيفِ الشَّاعِرِ لِلْحِكْمَةِ فِي خِدْمَةِ غَرَضِهِ مِنَ النَّصِّ . ( )
( ب ) ثِقَةِ الشَّاعِرِ بِنَفْسِهِ ، وَاعْتِزَازِهِ بِهَا . ( )
( ج ) قُوَّةِ قَبِيلَةِ الشَّاعِرِ . ( )

كِتَابُ الْأَنْشِطَةِ - الْفَصْلُ الدِّرَاسِيُّ الْأَوَّلُ ٩
