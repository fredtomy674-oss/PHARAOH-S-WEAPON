Nouveau problème en plusieurs étapes :
Sélectionnez ou encerclez la question cachée dans l’histoire en plusieurs étapes
du problème que vous avez écrit.
Résoudre les problèmes en plusieurs étapes . Lisez les étapes pour résoudre
les problèmes. Ensuite, lisez le problème et les étapes que l’élève a prises pour
résoudre le problème et numérotez les étapes de 1 à 6 pour les mettre dans le bon
ordre.
Étapes pour résoudre les problèmes de l’histoire
1. Encerclez les numéros et les étiquettes importants.
2. Soulignez les questions.
3. Dessinez un cadre autour des indices d’opération.
4. Examinez les informations:
• Qu’est-ce qui est connu ?
• Qu’est-ce qui est inconnu ?
• Quelle est la question cachée ?
5. Utilisez ce qui est connu pour répondre à la question cachée.
6. Utilisez les nouvelles informations pour résoudre le problème et trouvez
