ضَعْ (✓) أَمَامَ الصَّحِّ، وَ (X) أَمَامَ الخَطَأِ:
١ اللَّهُ (تَعَالَى) الشَّكُورُ يُجَازِي عَلَى الأَعْمَالِ الصَّالِحَةِ مَهْمَا كَانَتْ صَغِيرَةً. ( )
٢ النَّبِيُّ ﷺ خَافَ مِنْ قُرَيْشٍ، وَتَوَقَّفَ عَنِ الدَّعْوَةِ الجَهْرِيَّةِ. ( )
٣ دَاوُدُ عَلَيْهِ السَّلَامُ كَانَ يَعْمَلُ حَدَّادًا، وَيَأْكُلُ مِنْ كَسْبِ يَدِهِ. ( )
٤ أُسَاعِدُ صَدِيقِي فِي الرَّخَاءِ وَالشِّدَّةِ. ( )
٥ جَالُوتُ انتَصَرَ عَلَى دَاوُدَ عَلَيْهِ السَّلَامُ فِي المَعْرَكَةِ. ( )
٦ اللَّهُ عَزَّ وَجَلَّ رَفَعَ ذِكْرَ النَّبِيِّ ﷺ كَمَا فِي سُورَةِ الشَّرْحِ. ( )
٧ رَحَّبَتْ قُرَيْشٌ بِدَعْوَةِ النَّبِيِّ ﷺ عَلَى جَبَلِ الصَّفَا. ( )
٨ الشُّكْرُ لِلَّهِ (تَعَالَى) يَجْلِبُ الحُزْنَ وَالتَّعَبَ. ( )
