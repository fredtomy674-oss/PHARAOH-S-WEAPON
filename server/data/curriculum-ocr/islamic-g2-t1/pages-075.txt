الأَنْشِطَةُ وَالتَّدْرِيبَاتُ
نشاط
(1) رَتِّبِ الأَحْدَاثَ التَّالِيَةَ:
( ) صُعُودُ النَّبِيِّ ﷺ جَبَلَ الصَّفَا، وَدَعَوْتُهُ قَوْمَهُ إِلَى الإِسْلَامِ.
( ) تَعَبُّدُ النَّبِيِّ ﷺ فِي غَارِ حِرَاءَ.
( ) إِسْلَامُ السَّيِّدَةِ خَدِيجَةَ وَأَبِي بَكْرِ الصِّدِّيقِ .
( ) نُزُولُ الْوَحْيِ عَلَى رَسُولِ اللَّهِ ﷺ فِي غَارِ حِرَاءَ.
( ) أَمْرُ اللَّهِ (تَعَالَى) لِلنَّبِيِّ ﷺ بِالْجَهْرِ بِالدَّعْوَةِ.
( ) تَكْذِيبُ بَعْضِ زُعَمَاءِ قُرَيْشٍ لِلنَّبِيِّ ﷺ.
نشاط
(٢) احْكِ لِزُمَلَائِكَ قِصَّةَ جَهْرِ النَّبِيِّ ﷺ بِالدَّعْوَةِ بِأُسْلُوبِكَ الخَاصِّ:
نشاط
(۳) بِالتَّعَاوُنِ مَعَ زُمَلَائِكَ حَدِّدِ الدُّرُوسَ المُسْتَفَادَةَ مِنَ الدَّعْوَةِ الجَهْرِيَّةِ:
