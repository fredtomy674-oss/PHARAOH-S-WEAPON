٥ التَّوَكُّلُ عَلَى اللَّهِ يَعْنِي
(أ) عَدَمَ الْعَمَلِ.
(ب) الِاعْتِمَادَ عَلَى اللَّهِ مَعَ بَذْلِ الْجَهْدِ.
(جـ) الْخَوْفَ مِنْ كُلِّ شَيْءٍ.
٦ مَنْ يَتَنَزَّلُ فِي لَيْلَةِ الْقَدْرِ؟
(أ) النَّاسُ
(ب) الْمَلَائِكَةُ
(جـ) الشَّيَاطِينُ
٧ كَمْ مَرَّةً يُقَالُ: (اللَّهُ أَكْبَرُ) فِي بِدَايَةِ الْأَذَانِ؟
(أ) مَرَّتَيْنِ
(ب) ثَلَاثَ مَرَّاتٍ
(جـ) أَرْبَعَ مَرَّاتٍ
ضَعْ (۷) أَمَامَ الصِّح, وَ (X) أَمَامَ الخَطَا:
١ اللَّهُ تَعَالَى (السَّمِيعُ) يَسْمَعُ دُعَاءَنَا حَتَّى لَوْ كَانَ خَافِتًا. ( )
٢ يَجِبُ أَنْ نَرْفَعَ صَوْتَنَا بِالدُّعَاءِ حَتَّى يَسْمَعَهُ اللَّهُ عَزَّ وَجَلَّ . ( )
٣ نَزَلَ الْوَحْيُ عَلَى النَّبِيِّ ﷺ فِي غَارِ ثَوْرٍ. ( )
٤ السَّيِّدَةُ خَدِيجَةُ وَ طَمَأَنَتِ النَّبِيَّ ﷺ بَعْدَ نُزُولِ الْوَحْيِ. ( )
٥ لَيْلَةُ الْقَدْرِ لَيْلَةٌ مَلِيئَةٌ بِالسَّلَامِ وَالْبَرَكَةِ. ( )
٦ رَفَضَ قَوْمُ مَدْيَنَ نَصِيحَةَ سَيِّدِنَا شُعَيْبٍ السَّلَامُ لَهُمْ. ( )
٧ التَّوَكُّلُ يَعْنِي أَنْ نَعْمَلَ وَنَثِقَ بِاللَّهِ عَرَ وَجَلَّ . ( )
٨ أَهْلَكَ اللَّهُ (تَعَالَى) قَوْمَ مَدْيَنَ بِعَذَابٍ شَدِيدٍ. ( )
٩ بَدَأَ نُزُولُ الْقُرْآنِ الْكَرِيمِ فِي شَهْرِ شَعْبَانَ. ( )
