نشاط (1)
ضَعْ (/) أَمامَ الصَّحِّ، وَ (X) أَمامَ الخَطَأِ:

1. اللَّهُ (تَعالى) يُخَفِّفُ عَنْ عِبادِهِ الصَّالِحِينَ.
( )
2. العُسْرُ يَسْتَمِرُّ وَلا يَنْتَهي.
( )
3. التَّوَجُّهُ إِلى اللَّهِ (تَعالى) بِالدُّعاءِ فِيهِ راحة وسَكِينَةٌ.
( )
