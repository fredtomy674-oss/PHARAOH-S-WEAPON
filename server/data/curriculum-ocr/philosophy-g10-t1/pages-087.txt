الفصل الأول : مبادئ المنطق (الحدود - القضايا)

قام معلم الفلسفة بتصميم ( لعبة الأدلة الصحيحة ) هي كروت كتب عليها عبارات يسحب الطالب منها ويحدد هل هي صحيحة او غير صحيحة مع شرح السبب

| م | الدليل | سليم | غير سليم | شرح السبب |
| :--- | :--- | :--- | :--- | :--- |
| 1 | جميع الأطعمة العضوية وحدها أكثر صحة للإنسان | | | |
| 2 | اللقاحات تسبب التوحد | | | |
| 3 | التغير المناخي ناتج عن النشاط البشري | | | |
| 4 | الأبراج الفلكية تحدد الشخصية والمصير | | | |
| 5 | التعليم يعزز الفرص الاقتصادية | | | |
| 6 | شرب الماء البارد يسبب الأمراض | | | |
| 7 | النوم الجيد يحسن الوظائف العقلية والجسدية | | | |
| 8 | التغذية المتوازنة ضرورية للصحة | | | |
| 9 | التدخين يسبب السرطان. | | | |
| 10 | اللقاحات تمنع الأمراض. | | | |

تعاون مع زملاءك في مجموعات وتمثيل مواقف تتطلب استخدام الحدود المنطقية في أحد الموضوعات التالية :
• تصنيف الكائنات الحية.
• المدن والمعالم الجغرافية .
• المهن والوظائف .
• الأطعمة والمشروبات .
• الأجهزة الإلكترونية .
• اللغات واللهجات .
صمم خريطة ذهنية توضح فيها تقسيم الحدود من حيث الكم والكيف مع ذكر أمثلة .
صمم خريطة ذهنية توضح فيها تقسيم القضايا من حيث الواقع الخارجي مع ذكر أمثلة.
