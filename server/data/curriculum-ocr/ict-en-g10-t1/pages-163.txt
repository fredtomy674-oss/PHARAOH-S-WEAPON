(2) In a “for” statement, the range() instruction can be used to specify a range for a variable.
Writing style Meaning
range(end value) The value of the variable increases by 1, starting
from (20) up to the (3end value - 1).
range(start value, end value) The value of the variable increases by 1, starting
from the (4start value) up to the (5end value - 1).
range(start value, end value, increment) The value of the variable increases by the specified
(6increment), starting from the (7start value) up to
the (8end value - increment).
<Example> A program that displays integers from 0 to 3
01 for␣i␣in␣range(0, 4): Repeat variable “i” increasing by 1
