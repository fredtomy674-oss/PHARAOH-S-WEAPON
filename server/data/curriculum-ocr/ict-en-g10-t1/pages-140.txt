clarify the relationship between a resulting

(2) (2Simple regression analysis) : Predicts the outcome

(3) (3Regression line) : Refers to the line used to
determine predicted values in a scatter plot. A
regression line can be expressed with the
(4regression line equation) in the form of a first-degree function y = ax + b.
(4) (5Least squares method) : A method used to (6minimize) the vertical error, or the (7residual), between
the actual data points and the regression line.
