س١ ضع علامة ( √ ) أمام العبارة الصحيحة . وعلامة ( × ) أما العبارة غير الصحيحة مع تصويبها:
أ - عبر الله عن ذاته بوسائل كثيرة سواء في عصر الكتابة أو عصر ما قبل الكتابة. ( )
ب - الرسل نشروا الإنجيل بنفس أسلوب التلمذه دون وجود كتاب مكتوب. ( )
ج - الوحي يجعل الكاتب مجرد متلق. ( )
د - الوحي لجميع الناس وليس لأناس معينين . ( )
هـ - الوحي يشمل كل الكتاب المقدس. ( )

س٢ اكتب باختصار عن : -
أ - معني الوحي في المسيحية .
ب - ضرورة الوحي .
ج - خصائص الوحي .
