Rules Can you always figure out the correct rule with one input and output number? Why or why not?
Variables Use the equation y = 3x to answer these questions.

A. Which variable represents the input number?
B. Which variable represents the output number?
C. Which is the dependent variable?
D. Which is the independent variable?

Let’s Chat Equations can have more than one operation. Talk with a partner about how you predicted which input and output numbers would probably have two operations.

Write an Equation Use the variables x and y, where x is the independent variable. Write the equation for “multiply by 3 and add 4.” Select the correct answer.

A. x = y + 3x + 4
B. x = 3y + 4
C. y = 3x + 4
D. y = -3 + 4x
