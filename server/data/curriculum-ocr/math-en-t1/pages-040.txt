LESSON 6
Comparing Absolute Values

Learning Targets
• I can compare absolute values using symbols.
• I can interpret the use of absolute value
  through real-world situations involving
  money and temperature.

Classroom Practices
• Reason abstractly and quantitatively.
• Construct viable arguments and critique the
  reasoning of others.

ACCESS

Absolute Values Think about some values you have compared, such as $-\frac{5}{6}$ and $\frac{2}{3}$.
Now, think about comparing the absolute values of these rational numbers. Do you
think the comparisons will be the same or different?

Absolute Value
$\left|-\frac{5}{6}\right| = \left|\frac{5}{6}\right|$
$\left|\frac{2}{3}\right| = \left|\frac{2}{3}\right|$
