5 Ahmed and Noha solved the equation:
2 X + 7 = 16
Which one of them followed the
correct solution method? Discuss.

Ahmed's Solution
2 X + 7 = 16
2 X + 7 - 7 = 16 - 7
2 X = 9
\frac{2 X}{2} = \frac{9}{2}
X = 4,5

Noha's Solution
2 X + 7 = 16
\frac{2 X}{2} + 7 = \frac{16}{2}
X + 7 = 8
X + 7 - 7 = 8 - 7
X = 1
