Example 1

Geography: If the scale drawing of a map
is 1:600,000 and the distance between two
points on the map is 4.5 cm, find the real
distance between the two points.

Since scale drawing = Distance on map
Real distance

Therefore, $\frac{1}{600,000} = \frac{4.5\text{ cm}}{\text{Real distance}}$

$1 \times \text{Real distance} = 600,000 \times 4.5\text{ cm}$
Real distance = 2,700,000 cm.

$= \frac{2,700,000}{100 \times 1,000} = 27\text{ km}$

Example 2

Geometry: The opposite figure represents
a room model, where every 1 cm in the model
represents 1.2 m in reality.
What is the room's real area?

Scale drawing = $\frac{\text{Length in drawing}}{\text{Real length}}$

$\frac{1\text{ cm}}{1.2\text{ m}} = \frac{3\text{ cm}}{\text{The room's real length}}$

The room's real length = 3 × 1.2 = 3.6 m

$\frac{1\text{ cm}}{1.2\text{ m}} = \frac{2.5\text{ cm}}{\text{The room's real width}}$

The room's real width = 2.5 × 1.2 = 3 m

The room's real area = 3.6 × 3 = 10.8 m²
