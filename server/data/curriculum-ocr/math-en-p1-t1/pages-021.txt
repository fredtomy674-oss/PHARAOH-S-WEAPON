Set Concept
Set Concept:
A set is a collection of well-defined objects, which are completely determined.
These objects are called elements of the set, and they are written inside the braces { } without repetition. The order does not matter.

Expressing Sets:
Sets can be expressed using the listing method, the set-builder method, or Venn diagrams.
For example, if $A$ is the set of natural numbers less than 4, then $A$ can be expressed using any of the following methods:

Listing Method
$$A = \{0, 1, 2, 3\}$$

Set-Builder Method
$$A = \{X : X \in \mathbb{N}, X < 4\}$$
where $\mathbb{N}$ is the set of natural numbers.

Venn Diagram
$$A = \begin{Bmatrix} .0 & .1 \\ .2 & .3 \end{Bmatrix}$$
