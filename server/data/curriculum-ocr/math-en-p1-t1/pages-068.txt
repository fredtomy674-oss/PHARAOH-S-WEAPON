Items Percentages

• Represent this data using
a pie chart.

► Calculate the total number of votes: 8 + 12 + 10 = 30.

► Calculate the measure of the central angle that represents the number
of votes for each candidate:

Measure of the central angle = $\frac{\text{Number of votes for each candidate}}{\text{Total number of votes}} \times 360^{\circ}$

"Khaled" $\frac{8}{30} \times 360^{\circ} = 96^{\circ}$

"Anas" $\frac{12}{30} \times 360^{\circ} = 144^{\circ}$

"Hamza" $\frac{10}{30} \times 360^{\circ} = 120^{\circ}$

► Draw a suitable circle, and then draw
the central angle representing the
number of votes for each candidate.
