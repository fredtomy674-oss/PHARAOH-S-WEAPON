Types of Sets
Finite Set
A set that has a finite
number of elements.
For example:
X = {2, 3, 5},
containing 3 elements.
Infinite Set
A set that has an
infinite number of
elements.
For example :
N = {0, 1, 2, 3, ...}
Empty Set (Null Set)
A set that has no
elements and is
denoted by the
symbol & or { }.
For example:
The set of integers
between 1 and 2

Inclusion (Subset)
If A = {2, 3, 4, 5, 7}, and B = {4, 7},
then 4 ∈ A, 4 ∈ B and 7 ∈ A, 7 ∈ B
i.e. Every element of set B belongs to set A.
Hence, B is a subset of A and written as BCA
You can express this as:
B is a subset of A, or A contains B.
When A and B are represented by a Venn diagram, draw B inside A.

■ Note
The symbol ∈
is read as "belongs to" and
is used to express that an
element belongs to a set.

The symbol ∉
is read as "does not
belong to" and is used to
express that an element
does not belong to a set.

Example 1
Which of the following sets is a subset of X = {1, 3, 4, 5, 6}?
1 A = {3, 5, 9}
2 B = {1, 5, 6}
