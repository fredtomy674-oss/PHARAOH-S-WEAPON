Types of Sets

Finite Set
A set that has a finite
number of elements.
For example:
$X = \{2, 3, 5\}$,
containing 3 elements.

Infinite Set
A set that has an
infinite number of
elements.
For example :
$N = \{0, 1, 2, 3, ...\}$

Empty Set (Null Set)
A set that has no
elements and is
denoted by the
symbol $\phi$ or $\{ \}$.
For example:
The set of integers
between 1 and 2

■ Note
The symbol $\in$
is read as "belongs to" and
is used to express that an
element belongs to a set.

The symbol $\notin$
is read as "does not
belong to" and is used to
express that an element
does not belong to a set.

■ Self-Evaluation (4)
Find the number of subsets
of a set that contains
5 elements.

First Term

Inclusion (Subset)

If $A = \{2, 3, 4, 5, 7\}$, and $B = \{4, 7\}$,
then $4 \in A$, $4 \in B$ and $7 \in A$, $7 \in B$.
i.e. Every element of set $B$ belongs to set $A$.
Hence, $B$ is a subset of $A$ and written as $B \subset A$.
You can express this as:
$B$ is a subset of $A$, or $A$ contains $B$.
When $A$ and $B$ are represented by a Venn diagram, draw $B$ inside $A$.

Example 1

Which of the following sets is a subset of $X = \{1, 3, 4, 5, 6\}$?
1 $A = \{3, 5, 9\}$
2 $B = \{1, 5, 6\}$

1 $9 \in A$ and $9 \notin X$, thus $A \not\subset X$. "The symbol $\not\subset$ is read as not subset"
2 Every element of $B$ is an element of $X$, hence, $B \subset X$.

Example 2

Write all the subsets of the set $A = \{4, 6, 8\}$, and mention their number.

The subsets of the set A are:
$\{4\}$, $\{6\}$, $\{8\}$
$\{4, 6\}$, $\{4, 8\}$, $\{6, 8\}$
$\{4, 6, 8\}$, $\phi$
The number of subsets of $A = 2^3 = 8$

■ Solution Guide
• The number of subsets of
an n-element set is $2^n$
• The empty set "$\phi$" and
the set A itself are called
improper subsets.
