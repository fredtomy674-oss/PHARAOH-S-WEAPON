Use Excel to calculate the arithmetic mean, the median, and the mode of
the following set of values:
5, 2, 9, 2, 4, 2, 5, 8, 3

1 Insert the numbers in one column, say, column A.

4 To Calculate the Median: Repeat steps 2 and 3 but select “MEDIAN”.
5 To Calculate the Mode: Repeat steps 2 and 3 but select “MODE”.
