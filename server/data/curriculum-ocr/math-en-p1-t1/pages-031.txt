The Set of Rational Numbers
- The set of rational numbers ($\mathbb{Q}$) is the set
of all numbers that can be expressed
in the form of $\frac{a}{b}$ where $a$ and $b$ are
integers and $b \neq 0$
$\mathbb{Q} = \{\frac{a}{b} : a \in \mathbb{Z}, b \in \mathbb{Z}, b \neq 0\}$
- Based on the above definition:
The set of counting numbers, the set
of natural numbers, and the set of
integers are all subsets of the set of
rational numbers. Discuss.
