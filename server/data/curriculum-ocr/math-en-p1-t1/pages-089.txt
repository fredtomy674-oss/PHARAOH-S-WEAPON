Example 5
In the opposite figure: $F \in \overleftrightarrow{BA}$
$m(\angle CAD) = 40^\circ$, $m(\angle B) = 70^\circ$
Prove that: $\overleftrightarrow{AD} // \overleftrightarrow{BC}$

$\because \angle BAF$ is a striaght angle
$\because m(\angle BAF) = 180^\circ$
$\because 2X + 40^\circ = 180^\circ$
$\because 2X = 180^\circ - 40^\circ = 140^\circ$
$\because X = \frac{140^\circ}{2} = 70^\circ$
$\because m(\angle FAD) = 70^\circ$
$\because m(\angle FAD) = m(\angle B)$, and they are corresponding angles.
$\because \overleftrightarrow{AD} // \overleftrightarrow{BC}$
