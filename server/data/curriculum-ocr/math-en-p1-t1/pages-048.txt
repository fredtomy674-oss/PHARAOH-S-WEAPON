If the substitution set is:

1 Addition Property:
If $A = B$ then $A + C = B + C$
For example: If $X - 1 = 3$ then $X - 1 + 1 = 3 + 1$ thus $X = 4$

2 Subtraction Property:
If $A = B$ then $A - C = B - C$
For example: If $X + 2 = 3$ then $X + 2 - 2 = 3 - 2$ thus $X = 1$

3 Multiplication Property:
If $A = B$ then $A \times C = B \times C$
For example: If $\frac{1}{3}X = 3$ then $3 \times \frac{1}{3}X = 3 \times 3$ thus $X = 9$

4 Division Property:
If $A = B$ then $\frac{A}{C} = \frac{B}{C}$ (where $C \neq 0$)
For example: If $4X = 20$ then $\frac{4X}{4} = \frac{20}{4}$ thus $X = 5$
