If a straight line intersects two parallel straight lines, then each two interior angles on the same side of the transversal are supplementary.

< 3 and < 5 are interior angles on the same side of the transversal

< 4 and < 6 are interior angles on the same side of the transversal

$m(\angle 3) + m(\angle 5) = 180^{\circ}$

$m(\angle 4) + m(\angle 6) = 180^{\circ}$

Example 1

In the opposite figure, there are three angles, the measure of each is $120^{\circ}$. Identify these angles and state the reason. Given that $n_1 // n_2$ and $m$ is the transversal.

$m(\angle 3) = 120^{\circ}$ (Vertically opposite angles)

$m(\angle 4) = 120^{\circ}$ (Corresponding angles)

$m(\angle 7) = 120^{\circ}$ (Alternating exterior angles)

i.e., the three angles are: $\angle 3$, $\angle 4$ and $\angle 7$

Example 2

In the opposite figure:

$\overleftrightarrow{AB} // \overleftrightarrow{DC}$. What is the value of X?

$\overleftrightarrow{AB} // \overleftrightarrow{DC}$, $\angle BAD$ and $\angle ADC$ are interior angles on the same side of the transversal, thus:

$m(\angle BAD) + m(\angle ADC) = 180^{\circ}$

$3X + 15^{\circ} + 75^{\circ} = 180^{\circ}$

$3X + 90^{\circ} = 180^{\circ}$

$3X = 180^{\circ} - 90^{\circ}$

$3X = 90^{\circ}$

$X = \frac{90^{\circ}}{3} = 30^{\circ}$

■ Think

Try to solve the example using different methods yourself.

■ Verifying the Solution

Substitute X with $30^{\circ}$ in the expression $(3X + 15)^{\circ}$

$3X + 15^{\circ} = 3 \times 30^{\circ} + 15^{\circ}$

$= 90^{\circ} + 15^{\circ}$

$= 105^{\circ}$

$m(\angle BAD) + m(\angle ADC)$

$= 105^{\circ} + 75^{\circ} = 180^{\circ}$

The solution is correct because the two angles are supplementary.
