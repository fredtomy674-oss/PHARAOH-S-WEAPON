Multiplication et division des racines
Les racines carrées
Si a et b sont deux nombres réels
non négatifs, alors:
√a x √b = √a x b
Exemple:
√2 x √8 = √2 x 8 = √16 = 4
√a / √b = √a/b à condition b ≠ 0
Exemple:
√6 / √2 = √6/2 = √3

Les racines cubiques
Si a et b sont deux nombres réels,
alors:
³√a x ³√b = ³√a x b
Exemple:
³√3 x ³√-4 = ³√3 x (-4) = ³√-12
³√a / ³√b = ³√a/b à condition b ≠ 0
Exemple:
³√16 / ³√2 = ³√16/2 = ³√8 = 2
