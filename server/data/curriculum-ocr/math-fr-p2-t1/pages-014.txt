Deuxièmement Les intervalles non bornés

■ Remarque que
l'intervalle ] − ∞ ; ∞ [
représente l'ensemble des
nombres réels R,
∞ ∉ R et − ∞ ∉ R

■ L'histoire des
mathématiques
Le savant
anglais
John Wallis
est le premier
qui a utilisé le
symbole de l'infini (∞).

• L'ensemble des nombres réels s'étend sur la droite numérique dans la
direction positive jusqu'à l'infini (∞) et s'étend dans la direction négative
jusqu'à l'infini (− ∞)
• Les symboles ∞ et − ∞ sont utilisés pour exprimer les ensembles infinis
comme suit:
Si a ∈ R , alors:

L'ensemble des nombres réels
supérieurs ou égaux à a
{X : X ∈ R ; X ≥ a} = [a ; ∞ [
<----|---->
     a

L'ensemble des nombres réels
inférieurs ou égaux à a
{X : X ∈ R ; X ≤ a} = ]− ∞ ; a]
<----|---->
     a

L'ensemble des nombres réels
supérieurs à a
{X : X ∈ R ; X > a} = ]a ; ∞ [
<----|---->
     a

L'ensemble des nombres réels
inférieurs à a
{X : X ∈ R ; X < a} = ]− ∞ ; a[
<----|---->
     a

■ Remarque que
• R = R⁺ ∪ {0} ∪ R⁻
où: R⁺ est l'ensemble des
nombres réels positifs,
R⁻ est l'ensemble
des nombres réels
négatifs.
• L'ensemble des nombres
réels non négatifs
= R⁺ ∪ {0}
• L'ensemble des nombres
réels non positifs
= R⁻ ∪ {0}
