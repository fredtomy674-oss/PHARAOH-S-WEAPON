Quelques applications du parallélisme
Théorème 3-1
Si une droite coupe plusieurs droites parallèles et que les parties de la sécante
comprises entre ces droites sont égales en longueur, alors les parties comprises
entre ces droits pour toute autre sécante seront également égales en longueur
Si l1 // l2 // l3 // l4,
t1, t2 sont leurs sécantes
où AB = BC = CD
alors: EF = FG = GH
