Factorise les polynômes suivants en extrayant le plus grand commun diviseur:

2 (x + 2)² + 3 (x + 2)

Exemple 3
Factorise les polynômes suivants en extrayant le plus grand commun diviseur:
1 12 x (x + y) – 18 y (x + y)
2 (x – 5)² – 2 (x – 5)
3 (x + 3)² – x – 3
■ Remarque que
On peut prendre la parenthèse répétée contenant un polynôme comme un facteur commun.
✔
1 Où le PGCD est 6 (x + y)
∴ 12 x (x + y) – 18 y (x + y) = 6 (x + y) (2 x – 3 y)
2 Où le PGCD est (x – 5)
∴ (x – 5)² – 2 (x – 5) = (x – 5) (x – 5 – 2) = (x – 5) (x – 7)
3 (x + 3)² – x – 3 = (x + 3)² – (x + 3)
= (x + 3) (x + 3 – 1)
= (x + 3) (x + 2)
