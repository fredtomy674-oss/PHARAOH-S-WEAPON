■ La vérification de la
validité de la solution
Tu peux vérifier la validité
de la solution en substituant
toutes les valeurs de X
dans l'équation d'origine
pour vérifier que les deux
membres de l'équation sont
égaux.

② ∴ X² + 30 = - 13 X ∴ X² + 13 X + 30 = 0
∴ (X + 3) (X + 10) = 0
∴ Soit X + 3 = 0 et donc X = - 3
ou X + 10 = 0 et donc X = - 10
∴ L'ensemble de solution = {- 3 ; - 10}
③ ∴ 6 X² - 13 X + 6 = 0 ∴ (2 X - 3) (3 X - 2) = 0
∴ Soit 2 X - 3 = 0 et donc X = 3/2
ou 3 X - 2 = 0 et donc X = 2/3
∴ L'ensemble de solution = {3/2 ; 2/3}
