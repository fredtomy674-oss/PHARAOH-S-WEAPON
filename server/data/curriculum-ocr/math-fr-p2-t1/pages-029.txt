Sois prêt!
Une entreprise spécialisée
dans la fabrication de jouets
éducatifs pour les enfants a
décidé de produire un jouet
sous la forme d'un cube coloré
fabriqué du plastique sûr, dont
la longueur de l'arête du cube
est de 4√3 cm. Quel est le
volume de ce cube?
Dans cette leçon, tu connaîtras les lois des exposants dans les nombres
réels, ce qui te permettra de résoudre de tels problèmes de la vie.

La multiplication répétée dans l'ensemble des nombres réels
L'expression mathématique aⁿ est utilisée pour exprimer le produit du
nombre réel a multiplié par lui-même n fois.
a x a x a x ... x a = aⁿ
Un nombre
réel répété n fois.
n ← L'exposant
↑
La base

Exemple:
√2 x √2 x √2 x √2 x √2 = (√2)⁵
5 ← L'exposant
√2 = La base
