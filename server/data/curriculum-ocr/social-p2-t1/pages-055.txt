تقييم ختامي على الوحدة الثانية

السؤال الأول: اكتب كلمة (صواب) أمام العبارة الصحيحة، وكلمة (خطأ) أمام العبارة غير الصحيحة مع تصويب الخطأ:
١ - ارتبطت مواقع الحضارات القديمة في قارة آسيا بوجود الصحاري. ( ) ( )
٢ - تأسست أول مملكة موحدة في بلاد العراق القديم في عهد سرجون الأول. ( ) ( )
٣ - ظهر أول قانون مُدوَّن في العصر البابلي الأول. ( ) ( )
٤ - كانت فينيقيا مكونة من مدينة واحدة مركزية تحكم باقي المدن. ( ) ( )
٥ - قامت علاقات تجارية بين حضارة اليمن والحضارة المصرية القديمة. ( ) ( )
٦ - كانت الصناعة هي أساس اقتصاد الحضارة الصينية القديمة. ( ) ( )
٧ - اهتم الهنود قديمًا بتخطيط المدن والطرق. ( ) ( )
٨ - عُرف نظام الخلافة في الدولة الإسلامية قبل وفاة الرسول (ﷺ). ( ) ( )

السؤال الثاني: اختر الإجابة الصحيحة مما بين القوسين:
١ - استقر الآشوريون في شمال بلاد ................. (اليمن - العراق - الهند - الصين)
٢ - أول من استقر على الشريط الساحلي شرق البحر المتوسط هم .................
(السومريون - الفينيقيون - الأكاديون - البابليون)
٣ - كانت عاصمة حضارة مَعين هي مدينة ................. (قرناو - عدن - ظفار - قنا)
٤ - نجح الأحباش في السيطرة على بلاد اليمن بعد هزيمتهم للملك .................
(سيف بن ذي يزن - ذي نواس - بيبي الثاني - حمورابي)
٥ - ظهرت النقود الإسلامية لأول مرة في عهد .................
(الرسول (ﷺ) - الخلفاء الراشدين - الدولة الأموية - الدولة العباسية)

٢ - شُيِّد سور الصين لحماية حدود الصين من جهة .................
٣ - أشهر ملكات سبأ هي الملكة .................
٤ - نشأت حضارة الصين القديمة في وادي نهر .................
٥ - نشأت الحضارة الهندية على طول نهر .................
٦ - تم القضاء على حركة الردة في عصر .................
