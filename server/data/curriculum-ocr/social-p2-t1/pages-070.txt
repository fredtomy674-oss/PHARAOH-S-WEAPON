٣ فكر وأجب
أ اكتب كلمة (صواب) أمام العبارة الصحيحة، وكلمة (خطأ) أمام العبارة غير الصحيحة، مع تصويب الخطأ:
١ - تتشابه الخصائص المناخية لكلّ من نظامي الصحاري المعتدلة والصحاري الباردة. ( )
٢ - يعيش الجمل البري ذو السنامين في نظام الحشائش الحارة. ( )
٣ - تعيش كل من الذئاب والدببة القطبية بنظام الحشائش الباردة. ( )
٤ - يوجد الطاووس الهندي في نظام الحشائش الحارة. ( )
٥ - تتراكم المواد العضوية غير المتحللة في التربة بنظام الحشائش المعتدلة. ( )
