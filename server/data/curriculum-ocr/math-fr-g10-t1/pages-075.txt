5 GPS: Pour déterminer le lieu C,
les géomètres ont mesuré et préparé le schéma ci-contre.
Calcule la distance entre les deux lieux C et A

Solution

$\overline{AB} \perp \overline{BD}$, $\overline{CD} \perp \overline{BD}$ $\therefore \overline{AB} // \overline{CD}$

$\therefore \overleftrightarrow{AC} \cap \overleftrightarrow{BD} = \{E\}$, $\overline{AB} // \overline{CD}$

$\therefore \frac{EA}{AC} = \frac{EB}{BD}$ Donc $\frac{60}{AC} = \frac{45}{45 + 105}$

$\therefore \text{AC} = \frac{60 \times 150}{45} = 200 \text{ mètres.}$
