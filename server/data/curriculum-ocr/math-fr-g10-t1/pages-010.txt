Introduction aux nombres complexes

Puissances entières de i :
Toutes les règles de puissance qui sont déjà étudiées s'appliquent sur le nombre i. Nous pouvons
calculer les différentes puissances du nombre i comme suit :
i¹ = i
i² = -1
i³ = i². i = -i
i⁴ = i² x i² = -1 x (-1) = 1
i⁵ = i⁴ x i = 1 x i = i
De manière générale, i⁴ⁿ = 1 , i⁴ⁿ⁺¹ = i , i⁴ⁿ⁺² = -1 , i⁴ⁿ⁺³ = -i où n ∈ ℤ

Exemple

1 Mets chacun des nombres suivants sous la forme la plus simple :
A i³⁰
B i⁴³
C i⁻⁶¹
D i⁴ⁿ⁺¹⁹

Solution
A i³⁰ = (i⁴)⁷ x i² = 1 x (-1) = -1
B i⁴³ = (i⁴)¹⁰ x i³ = 1 x (-i) = -i
C i⁻⁶¹ = (i⁴)⁻¹⁶ x i³ = 1 x i³ = -i
D i⁴ⁿ⁺¹⁹ = i⁴ⁿ x i¹⁹ = 1 x (i⁴)⁴ x i³ = 1 x i³ = -i
