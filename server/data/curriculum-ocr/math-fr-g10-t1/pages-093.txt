Dans la figure (2), la mesure de l'angle orienté est négative si l'orientation du côté initial <span style="display:inline-block; border-top:1px solid black; padding-top:1px;">OA</span> vers le

1 Trouve la mesure de l'angle orienté $\theta$ indiqué dans chacune des figures suivantes :

Solution

On sait que la somme des mesures des angles formés autour d'un point est égale à 360°

A <span style="font-size:1.1em; display:inline-block; padding:1px 4px; border:1px solid #7cb5ec; border-radius:50%; background-color:#e6f2ff; text-align:center;">θ</span> = - (360° - 55°) = - 305°

B <span style="font-size:1.1em; display:inline-block; padding:1px 4px; border:1px solid #7cb5ec; border-radius:50%; background-color:#e6f2ff; text-align:center;">θ</span> = 360° - 33° = 327°

C <span style="font-size:1.1em; display:inline-block; padding:1px 4px; border:1px solid #7cb5ec; border-radius:50%; background-color:#e6f2ff; text-align:center;">θ</span> = 360° - 125° = 235°

D <span style="font-size:1.1em; display:inline-block; padding:1px 4px; border:1px solid #7cb5ec; border-radius:50%; background-color:#e6f2ff; text-align:center;">θ</span> = - (360° - 134°) = - 226°
