Théorème 2 Si deux triangles ont deux paires de côtés de longueurs proportionnelles et
si les angles compris entre ces deux côtés ont même mesure, alors les deux
triangles sont semblables. (La démonstration n'est pas sujet à léxamen)

Hypothèses : $\angle \mathrm{A} \equiv \angle \mathrm{D}$, $\frac{\mathrm{AB}}{\mathrm{DE}} = \frac{\mathrm{AC}}{\mathrm{DF}}$

Conclusion : $\Delta \text{ABC} \sim \Delta \text{DEF}$

Démonstration : On détermine $\text{X} \in \overline{\text{AB}}$ tel
que $\text{AX} = \text{DE}$

$\text{On trace} \ \overleftrightarrow{\text{XY}} \ // \ \text{BC}$ \ $\text{qui coupe} \ \overline{\text{AC}} \ \text{en} \ \text{Y}$

$\because \text{XY} \ // \text{BC}$ \ \ \ \ \ $\therefore \Delta \text{ABC} \sim \Delta \text{AXY} \ \ \ \text{(corollaire)}$ \ \ \ \ \ \ $(1)$

$:\frac{\text{AB}}{\text{AX}} = \frac{\text{AC}}{\text{AY}}$

$\therefore \frac{\text{AB}}{\text{DE}} = \frac{\text{AC}}{\text{DF}} \ \ \ \text{(hypothèse)} \ \ , \ \text{AX} = \text{DE} \ \ \ \text{(construction)}$

$\therefore \frac{\text{AB}}{\text{AX}} = \frac{\text{AC}}{\text{DF}} \ \ , \ \text{AY} = \text{DF}$

$\therefore \Delta \text{AXY} \equiv \Delta \text{DEF}$ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ $\text{(deux côtés et un angle compris)}$

$\Delta \text{AXY} \sim \Delta \text{DEF}$ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ $(2)$

$\text{De } (1) \text{ et } (2), \text{ on déduit que } \Delta \text{ABC} \sim \Delta \text{DEF} \ \ \text{Ce qu'il fallait démonter.}$

Exemple

7 $\text{ABC est un triangle tel que } \text{AB} = 8 \text{ cm, } \text{AC} = 10 \text{ cm et } \text{BC} = 12 \text{ cm. } \text{E} \in \overline{\text{AB}} \text{ tel que}$
$\text{AE} = 2\text{cm, } \text{D} \in \text{BC} \text{ tel que } \text{BD} = 4\text{cm.}$

A $\text{Démontre que } \Delta \text{BDE} \sim \Delta \text{BAC} \text{ puis déduis la longueur de } \overline{\text{DE}} \text{.}$

B $\text{Démontre que le quadrilatère } \text{ACDE} \text{ est inscriptible.}$

Solution

$\because \text{AB} = 8\text{cm et } \text{AE} = 2\text{cm} \ \ \ \ \ \therefore \text{BE} = 6\text{cm}$

A $\text{Dans les deux triangles } \text{BDE} \text{ et } \text{BAC} \text{ on a} :$

$\angle \text{DBE} \equiv \angle \text{ABC}$ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ $(1)$

$, \frac{\text{BD}}{\text{BA}} = \frac{4}{8} = \frac{1}{2} \ \ , \ \frac{\text{BE}}{\text{BC}} = \frac{6}{12} = \frac{1}{2}$

$\therefore \frac{\text{BD}}{\text{BA}} = \frac{\text{BE}}{\text{BC}}$ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ $(2)$

$\text{De } (1) \text{ et } (2) \ \ \ \therefore \Delta \text{BDE} \sim \Delta \text{BAC} \ \ \ \ \text{(théorème)}$

$\text{De la similitude } \frac{\text{DE}}{\text{AC}} = \frac{1}{2}$

$\therefore \text{DE} = \frac{1}{2}\text{AC} \ \ , \ \text{DE} = \frac{1}{2} \times 10 = 5\text{cm}$
