تعريف اللبن الزبادي المطعم
اللبن الزبادي غذاء طبيعي ينتج من تخمير اللبن بواسطة بكتيريا حمض اللاكتيك، وهو غني بالبروتين والكالسيوم والبكتيريا النافعة (البروبيوتيك) المفيدة للجهاز الهضمي. يمكن تطعيمه بمكونات طبيعية مثل الفاكهة الطازجة أو المجففة أو العسل أو الفانيليا للحصول على نكهات متنوعة وصحية دون إضافة السكريات الصناعية أو المواد الحافظة.

ما هي المكونات والأدوات اللازمة لعمل اللبن الزبادي المطعم ؟

| المكون / الأداة | الغرض |
| :--- | :--- |
| لبن كامل الدسم (١ لتر) | الأساس الرئيسي لصناعة الزبادي |
| زبادي طبيعي (٢ ملعقة كبيرة) | بادئ التخمير (العترة البكتيرية) |
| فاكهة طازجة أو عسل نحل أو فانيليا | مواد التطعيم الطبيعية للنكهة |
| ترمومتر مطبخ | التحكم في درجة حرارة التخمير (٤٠ - ٤٥°م) |
| أوعية زجاجية معقمة بأغطية | التعبئة والتخمير والتخزين |
| غطاء من القماش أو حاضنة حرارية | الحفاظ على حرارة التخمير لمدة ٦-٨ ساعات |
