تقييم ذاتي (1)
أوجد مجموعة قيم x التي تجعل الكسر الجبري النسبي غير معرف في كل مما يأتي:
1) 2x - 6 / x - 3
2) x^2 + x / x^2 - x - 2

التحقق من صحة الحل
يمكنك التحقق من صحة الحل في جزئية 1 كما يلي:
بالتعويض عن قيمة x = 1:
x - 3 / x^2 - 3x + 2
= 1 - 3 / 1^2 - 3(1) + 2
= -2 / 0 (غير معرف)
تحقق بنفسك بالتعويض عن قيمة x = 2

ناقش
هل تعتبر الدوال كثيرات الحدود دوال كسور جبرية نسبية أم لا ؟

مثال (1)
أوجد مجموعة قيم x التي تجعل الكسر الجبري النسبي غير معرف في كل مما يأتي:
1) x - 3 / x^2 - 3x + 2
2) x + 4 / x^2 + 16

1) بوضع x^2 - 3x + 2 = 0
(x - 2) (x - 1) = 0
x - 2 = 0 أو x - 1 = 0
x = 2 أو x = 1
مجموعة أصفار المقام = {1، 2}
الكسر غير معرف عندما x ∈ {1، 2}

2) بوضع x^2 + 16 = 0
x^2 = -16
x = ±√-16 ∉ R
مجموعة أصفار المقام = ∅
مجموعة قيم x التي تجعل الكسر غير معرف = ∅

دوال الكسور الجبرية النسبية
إذا كان p(x) / q(x) كسرًا جبريًا نسبيًا فإن:
الدالة f حيث f(x) = p(x) / q(x) دالة كسر جبري نسبي مجالها هو مجموعة الأعداد الحقيقية R ما عدا مجموعة أصفار المقام، ويرمز لمجال الدالة f بالرمز Df
أي أن: Df = R - {x : q(x) = 0}

تقييم ذاتي (2)
عين مجال الدالة r حيث:
r(x) = 2x + 1 / x^2 - 4x - 5
ثم أوجد إن أمكن:
r(5) ، r(0) ، r(-1)

مثال (2)
عين مجال كل من دوال الكسور الجبرية الآتية:
1) الدالة f حيث f(x) = x^2 - 25 / x - 5 ثم أوجد إن أمكن f(-5) ، f(5)
2) الدالة g حيث g(x) = x^2 - 2x / x^2 + x - 6 ثم أوجد إن أمكن g(-3) ، g(0)

1) بوضع x - 5 = 0
مجموعة أصفار المقام = {5}
x = 5
Df = R - {5}
f(5) غير معرفة لأن: 5 ∉ Df
f(-5) = (-5)^2 - 25 / (-5) - 5 = 0 / -10 = 0
-5 ∈ Df
