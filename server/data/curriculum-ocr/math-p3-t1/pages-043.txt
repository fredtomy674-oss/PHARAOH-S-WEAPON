العمليات على الكسور الجبرية النسبية
(Operations on Rational Algebraic Fractions)

■ نواتج التعلم
• تجرى العمليات على الكسور الجبرية النسبية.
• تعرف مفهوم المعكوس الجمعى، والمعكوس الضربي للكسر الجبرى النسبى.
• تعرف خواص العمليات على الكسور الجبرية النسبية.

استعد!
لكى يحصل خالد على تقدير ممتاز فى امتحان الرياضيات فى السنة الأخيرة من دراسته الجامعية لا بد وأن يكون مجموع درجاته 8 على الأقل.
فإذا كانت درجاته فى امتحان الفصل الدراسي الأول تساوى 3x^2 + 16x + 21 / x^2 + 5x + 6
ودرجاته فى امتحان الفصل الدراسي الثانى تساوى 5x^2 + 34x + 45 / x^2 + 7x + 10
فهل سيحصل خالد على تقدير ممتاز؟
فى هذا الدرس، سوف تتعلم العمليات على الكسور الجبرية النسبية؛ مما سيمكنك من حل مثل هذه المشكلات الحياتية.

فكر وناقش!
كتب سامح : إذا كانت f(x) = x / x+3 + 3 / x+3
فإن (f(x) = 1 لجميع قيم x الحقيقية. هل ما كتبه سامح صحيح؟ ولماذا؟ ناقش.

تعلم!
أولاً | جمع وطرح الكسور الجبرية النسبية
عمليتا جمع وطرح الكسور الجبرية النسبية تماثل عمليتى جمع وطرح الأعداد النسبية متبعًا الخطوات التالية :
1 تحليل بسط ومقام كل كسر ثم اختزاله على حدة إن أمكن.
2 توحيد المقامات ثم إجراء عملية الجمع أو الطرح.
3 وضع الناتج النهائى فى أبسط صورة.
فمثلاً : بفرض أن الكسور الجبرية النسبية التالية معرفة فإن :
1) 2x-1 / x+1 + x+3 / x+1 = 2x-1+x+3 / x+1 = 3x+2 / x+1
2) x^2-x / x^2+2x-3 + 3 / x+3 = x(x-1) / (x+3)(x-1) + 3 / x+3 = x / x+3 + 3 / x+3 = x+3 / x+3 = 1
3) 2 / x - 2 / 1+x = 2(1+x) / x(1+x) - 2(x) / x(1+x) = 2+2x-2x / x(1+x) = 2 / x(1+x)

■ المفردات
• الكسور الجبرية النسبية Rational algebraic fractions
• مقلوب الدالة Reciprocal of the function

■ معلومة سابقة
جمع وطرح الأعداد النسبية :
إذا كانت a/b , c/d أعدادًا نسبية فإن :
1) a/b ± c/b = a±c / b
فمثلاً : 1/7 + 4/7 = 5/7
2) a/b ± c/d = ad ± cb / bd
فمثلاً : 3/7 - 1/3 = 3×3 / 7×3 - 1×7 / 7×3 = 9/21 - 7/21 = 2/21
