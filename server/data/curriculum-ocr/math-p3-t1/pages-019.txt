الدالة التربيعية
الدالة التربيعية هي دالة من الدرجة الثانية في متغير واحد، تمثل بمنحنى يُسمى «قطعًا
مكافئًا»، وهو منحنى متماثل حول مستقيم رأسي يُسمى محور التماثل ويمر برأس المنحنى.

الصيغة القياسية للدالة التربيعية
الصيغة القياسية للدالة التربيعية f هي : f(x) = ax² + bx + c حيث 0 ≠ a
• الإحداثي x لرأس المنحنى : x = -b / 2a
• رأس المنحنى : ( -b / 2a , f(-b / 2a) )
• الإحداثي y لرأس المنحنى : y = f(-b / 2a)
• المقطع y يساوي c
