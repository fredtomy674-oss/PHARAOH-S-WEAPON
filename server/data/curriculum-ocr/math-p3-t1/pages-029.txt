إيجاد الأصفار الحقيقية لدالة كثيرة حدود مرسومة بيانيًا
إذا قطع منحنى دالة كثيرة حدود f محور x في النقطة (a, 0) فإن a يكون صفرًا للدالة f

مثال 2
أوجد مجموعة الأصفار الحقيقية لكل من الدوال الممثلة بالمنحنيات التالية :

1 : ∵ منحنى الدالة p يقطع محور x عند 1 = x
∴ مجموعة أصفار الدالة p هي {1}
2 : ∵ منحنى الدالة f يقطع محور x عند 1- = x ، 0 = x ، 2 = x
∴ مجموعة أصفار الدالة f هي {2 , 0 , 1-}
3 : ∵ منحنى الدالة g يقطع محور x عند 2- = x ، 2 = x
∴ مجموعة أصفار الدالة g هي {2 , 2-}

مثال 3
إذا كان 3- أحد أصفار الدالة كثيرة الحدود f حيث 3 + f(x) = 2x² + bx
أوجد قيمة b ثم أوجد (4)f

∵ 3- أحد أصفار الدالة f حيث 3 + f(x) = 2x² + bx
∴ f(-3) = 0
∴ 2 (-3)² + b (-3) + 3 = 0
∴ - 3 b = - 21 ∴ b = 7
∴ f(x) = 2x² + 7x + 3
∴ f(4) = 2 (4)² + 7 (4) + 3 = 63
