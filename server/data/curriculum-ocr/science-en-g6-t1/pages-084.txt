10-1 Aqueous Solutions and Metals Reaction between Solutions and Metals Chapter 10

Point! Properties that React with Metals
Some aqueous solutions have the properties that enable it to react with metals.
Hydrochloric acid has the properties that enable it to react with aluminum and iron. When you pour dilute hydrochloric acid on metals like aluminum and iron, the metals react and produce bubbles.
Metals are shiny materials with a luster and most of them are solid, we use them a lot in our daily lives such as iron, aluminium and gold.

Warm Up Let's observe changes in metals!
Let's safely check how aqueous solutions react with some metals.
1 Preparation:
•Dilute hydrochloric acid •Aluminum •Iron (Steel wool) •Beaker
•Test tube •Test tube rack •Rag •Pipette •Safety goggles
•Water
2 Experiment:
1 Cut aluminum into small pieces and put them in a test tube.
2 Tear off a small amount of steel wool, roll it into a ball, and put it in another test tube. Prepare two test tubes for each.
3 Use a pipette to add dilute hydrochloric acid to the first set of test tubes. And then use another pipette to add water to the second set of test tubes.
4 Observe the changes in each set of test tubes.
[Caution!]
•Be careful not to let the liquid touch your skin. If it does, wash it off right away with running water.
•Make sure to ventilate the room. Also, wear safety goggles.
