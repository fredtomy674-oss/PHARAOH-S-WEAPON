ثَانِيًا: ظَرْفُ الزَّمَانِ

أَقْرَأُ وَأُلاَحِظُ:

اِسْتَيْقَظْتُ صَبَاحًا.
يَظْهَرُ الْقَمَرُ لَيْلًا.
يَسْقُطُ الْمَطَرُ شِتَاءً.
نَلْبَسُ مَلَابِسَ خَفِيفَةً صَيْفًا.
ظَرْفُ الزَّمَانِ
اسْمٌ يَدُلُّ عَلَى الزَّمَنِ،
مِثْلَ: (صَبَاحًا، مَسَاءً،
لَيْلًا...).

نِشَاط (١) أَخْتَارُ ظَرْفَ الزَّمَانِ الْمُنَاسِبَ:
( أ ) تَشْتَدُّ حَرَارَةُ الشَّمْسِ (ظُهْرًا - لَيْلًا).
( ب ) غَنَّيْتُ فِي طَابُورِ الْمَدْرَسَةِ (لَيْلًا - صَبَاحًا).
( ج ) حَكَتْ لِي أُمِّي قِصَّةً (بَعْدَ - قَبْلَ) النَّوْمِ.
( د ) أَعْلَنَ الْحَكَمُ فَوْزَ فَرِيقِي (بَعْدَ - قَبْلَ) الْمُبَارَاةِ.
( ه ) أَرْجِعُ مِنَ الْمَدْرَسَةِ الثَّالِثَةَ (عَصْرًا - صَبَاحًا).

نِشَاط (٢) أُعَبِّرُ عَنْ كُلِّ صُورَةٍ بِجُمْلَةٍ مُسْتَخْدِمًا اسْمًا يَدُلُّ عَلَى الزَّمَانِ:
