تَذَكَّرْ أَنَّ
• اَلْمَقْطَعُ اَلصَّوْتِيُّ = حَرْفٌ مُتَحَرِّكٌ، مِثْلُ: (سَ)
حَرْفٌ مُتَحَرِّكٌ + حَرْفٌ سَاكِنٌ، مِثْلُ: (سَلْ)
• اَلْحَرْفُ اَلْمُشَدَّدُ، مِثْلُ: (طَّ) = طْ + طَ

(ب) اَلْمَوْزُ: (ا / لْ / مَ / وْ / زُ - اَلْ / مَوْ / زُ - اَلْمَ / وْزُ)
(ج) اَلطَّائِرُ: (اَلطْ / طَا / ئِ / رُ - اَلطَّ / ا / تُر - اَلطَّ / ا/ ئِ / رُ)
