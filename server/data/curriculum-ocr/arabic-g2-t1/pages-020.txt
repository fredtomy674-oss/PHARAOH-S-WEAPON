الْقَوَاعِدُ
الْإِمْلَائِيَّةُ تَحْلِيلُ الْكَلِمَاتِ إِلَى مَقَاطِعَ صَوْتِيَّةٍ

نَشَاط ١ أُلَاحِظُ تَحْلِيلَ الْكَلِمَاتِ الْآتِيَةِ إِلَى مَقَاطِعَ صَوْتِيَّةٍ:
الْقَرْيَةُ: أَلْ / قَرْ / يَةُ
تُفَّاحَةٌ: تُفْ / فَا / حَةٌ
الرِّيَاضَةُ: الرِّ / رِ / يَا / ضَةُ

انْتَبِهْ
• الْمَقْطَعُ الصَّوْتِيُّ = حَرْفٌ مُتَحَرِّكٌ، مِثْلَ: (حَ).
أَوْ = حَرْفٌ مُتَحَرِّكٌ + حَرْفٌ سَاكِنٌ، مِثْلَ: (قَرْ).
• الْحَرْفُ الْمُشَدَّدُ، مِثْلَ: (فَّ) = فَ + فَ.

نَشَاط ٢ أُكْمِلُ الْمَقَاطِعَ الصَّوْتِيَّةَ لِلْكَلِمَاتِ الْآتِيَةِ:
فَاكِهَةٌ
فَا / كِ / هَةٌ
أَلْعَابٌ
أَلْ / عَ / ابٌ
الْكُرَةُ
الْ / كُ / رَةُ
التَّمْرِينُ
التَّ / مْرِ / ي / نُ

نَشَاط ٣ أُكْمِلُ الْجَدْوَلَ كَالْمِثَالِ:
تَحْلِيلٌ
مَرْكَزٌ
مَرْ / كَ / زٌ
أَصْدِقَاءُ
أَ / صْ / دِ / قَا / ءُ
الْمُدَرِّبُ
الْ / مُ / دَرْ / رِ / بُ

دَمْجٌ
الْعُطْلَةُ
الْ / عُطْ / لَ / ةُ
لَا / عِ / بٌ
