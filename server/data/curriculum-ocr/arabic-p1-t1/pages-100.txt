أُطَوِّرُ قَامُوسِي اللُّغَوِيَّ
أَتَعَرَّفُ مَعَانِيَ الكَلِمَاتِ المُلَوَّنَةِ التَّالِيَةِ مُسْتَعِينَا بِالسِّيَاقِ:
١. «تَحْتَفِي بِالمَعْرِفَةِ»:
(تَهْتَمُّ - تَلْتَزِمُ - تَفْتَخِرُ - تَتَنَافَسُ).
٢. «لَا يَقْبَلُ أَيَّ فِكْرَةٍ دُونَ تَمْحِيصٍ»:
(تَغْيِيرٍ - تَعْدِيلٍ - تَدْقِيقٍ - تَعْلِيقٍ).
٣. «نَحْتَاجُ أَنْ نُعِيدَ قِرَاءَةَ تِلْكَ السِّيرَةِ»:
(نَفْعَلُ - نَبْدَأُ - نُكَرِّرُ - نَتَجَاوَزُ).

أَفْهَمُ المَقْرُوءَ، وَأُحَلِّلُهُ
أَمْلَأُ الشَّكْلَ بَعْدَ قِرَاءَةِ النَّصِّ قِرَاءَةً صَامِتَةً:
الفِكْرَةُ الرَّئِيسَةُ
الفِكْرَةُ الفَرْعِيَّةُ (١)
الفِكْرَةُ الفَرْعِيَّةُ (٢)
الفِكْرَةُ الفَرْعِيَّةُ (٣)

أَضَعُ عَلَامَةَ (✔) أَمَامَ العِبَارَةِ الصَّحِيحَةِ، وَعَلَامَةَ (X) أَمَامَ العِبَارَةِ الخَطَأِ فِيمَا يَلِي :
١. كَانَتِ الحَضَارَةُ العَرَبِيَّةُ وَالإِسْلَامِيَّةُ مَنْبَعَ العِلْمِ وَالعُلَمَاءِ. ( )
٢. نَظَرَتْ بِيئَةُ ابْنِ النَّفِيسِ لِلمَعْرِفَةِ عَلَى أَنَّهَا وَسِيلَةٌ لِلتَّمَيُّزِ. ( )
٣. وَافَقَ ابْنُ النَّفِيسِ (جَالِينُوسَ) فِيمَا قَالَهُ عَنِ الدَّوْرَةِ الدَّمَوِيَّةِ. ( )
٤. كَانَ ابْنُ النَّفِيسِ يُعَالِجُ النَّاسَ جَمِيعًا دُونَ تَفْرِقَةٍ بَيْنَ غَنِيٍّ وَفَقِيرٍ. ( )
٥. أَوْصَى ابْنُ النَّفِيسِ أَنْ تُوهَبَ كُتُبُهُ إِلَى مُسْتَشْفَى المَنْصُورِيِّ. ( )

أُجِيبُ عَنِ الأَسْئِلَةِ التَّالِيَةِ :
١. كَيْفَ رَسَمَ ابْنُ النَّفِيسِ السَّعَادَةَ عَلَى شِفَاءِ المَرْضَى؟
٢. مِنْ خِلَالِ فَهْمِيَ النَّصَّ، مَا أَعْظَمُ إِنْجَازَاتِ ابْنِ النَّفِيسِ؟
٣. أُعَلِّلُ: يَنْبَغِي عَلَيْنَا أَنْ نُعِيدَ قِرَاءَةَ سِيرَةِ ابْنِ النَّفِيسِ.
