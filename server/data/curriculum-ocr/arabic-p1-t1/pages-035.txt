أَسْتَنْتِجُ
* الْفِعْلُ مِنْ حَيْثُ التَّجَرُّدِ وَالزِّيَادَةِ قِسْمَانِ: مُجَرَّدٌ وَمَزِيدٌ:
- الْفِعْلُ الْمُجَرَّدُ: مَا كَانَتْ كُلُّ حُرُوفِهِ أَصْلِيَّةً لَا يُمْكِنُ الِاسْتِغْنَاءُ عَنْهَا.
وَهُوَ نَوْعَانِ: ١. مُجَرَّدٌ ثُلَاثِيٌّ. ٢. مُجَرَّدٌ رُبَاعِيٌّ.
- الْفِعْلُ الْمَزِيدُ: مَا زِيدَ فِيهِ حَرْفٌ أَوْ حَرْفَانِ أَوْ ثَلَاثَةٌ عَلَى حُرُوفِهِ الْأَصْلِيَّةِ،
وَهُوَ نَوْعَانِ:
١. مَزِيدٌ ثُلَاثِيٌّ، وَالزَّائِدُ قَدْ يَكُونُ حَرْفًا أَوْ اثْنَيْنِ أَوْ ثَلَاثَةً.
٢. مَزِيدٌ رُبَاعِيٌّ، وَالزَّائِدُ قَدْ يَكُونُ حَرْفًا أَوْ اثْنَيْنِ.
* أَقَلُّ مَا يَتَكَوَّنُ مِنْهُ الْفِعْلُ ثَلَاثَةُ أَحْرُفٍ، وَأَقْصَى مَا يَصِلُ إِلَيْهِ بِالزِّيَادَةِ سِتَّةُ أَحْرُفٍ.

نَشَاط (١) : أَضَعُ خَطًّا تَحْتَ الْأَفْعَالِ، ثُمَّ أُحَدِّدُ نَوْعَهَا مِنْ حَيْثُ التَّجَرُّدِ وَالزِّيَادَةِ :
١. شَارَكَتِ الْمَرْأَةُ الْمِصْرِيَّةُ فِي صُنْعِ الْقَرَارِ.
٢. يَعْتَزُّ الْمِصْرِيُّ بِوَطَنِهِ وَتَارِيخِهِ.
٣. يَتَعَاوَنُ أَهْلُ الْقَرْيَةِ لِقَضَاءِ أَعْمَالِهِمْ.
٤. يَقِفُ الْجُنْدِيُّ حَامِيًا أَرْضَ بِلَادِهِ.

نَشَاط (٢) : أَضَعُ خَطًّا تَحْتَ الْفِعْلِ الْمَزِيدِ، وَأُبَيِّنُ أَحْرُفَ الزِّيَادَةِ :
١. يُضَحِّي الْجُنُودُ بِأَرْوَاحِهِمْ.
٢. أَظْهَرَتِ الْمَرْأَةُ الْمِصْرِيَّةُ كَفَاءَتَهَا.
٣. اشْعُرُ الْبَدَنَ وَأَنَا أَقْرَأُ تَارِيخَ بِلَادِي.
٤. اسْتَرَدَّ الْمِصْرِيُّونَ سِينَاءَ بِالْحَرْبِ وَالتَّفَاوُضِ.

نَشَاط (٣) : أَضَعُ خَطًّا تَحْتَ الْفِعْلِ الْمُجَرَّدِ، وَأَجْعَلُهُ مَزِيدًا فِي جُمْلَةٍ مِنْ عِنْدِي :
١. وَصَلَتِ الْمَرْأَةُ إِلَى أَعْلَى الْمَنَاصِبِ.
٢. رَفَعَ الْمِصْرِيُّ شَأْنَ بَلَدِهِ.
٣. سَعِدْنَا بِالرُّجُوعِ إِلَى قَرْيَتِنَا.
٤. بَنَى الْمِصْرِيُّونَ حَضَارَةً عَظِيمَةً.

نَشَاط (٤) : أَضَعُ عَلَامَة (✓) أَوْ عَلَامَة (x) أَمَامَ الْجُمَلِ الْآتِيَةِ، مَعَ تَصْوِيبِ الْخَطَأ :
١. «أَقَرَّ الْجَمِيعُ بِقُدْرَةِ الْمَرْأَةِ الْمِصْرِيَّةِ». الْفِعْلُ مُجَرَّدٌ. ( )
٢. «أَحِنُّ إِلَى قَرْيَتِي». الْفِعْلُ مَزِيدٌ بِحَرْفٍ. ( )
٣. «انْتَصَرْنَا عَلَى كُلِّ الْأَعْدَاءِ». الْفِعْلُ مَزِيدٌ بِالْأَلِفِ وَالنُّونِ. ( )
٤. «يَرْتَقِي الْوَطَنُ بِسَوَاعِدِ أَبْنَائِهِ». الْفِعْلُ مَزِيدٌ بِحَرْفَيْنِ. ( )

نَشَاط (٥) : أُجِيبُ بِمَا هُوَ مَطْلُوبٌ :
١. «قَبِلَ». أَجْعَلُ الْفِعْلَ مَزِيدًا فِي ثَلَاثِ صُوَرٍ مُخْتَلِفَةٍ.
٢. «نَمَّا». أَجْعَلُ الْفِعْلَ مَزِيدًا بِحَرْفَيْنِ.
٣. «فَهِمَ». أَجْعَلُ الْفِعْلَ مَزِيدًا بِثَلَاثَةِ أَحْرُفٍ.
٤. «الْتَفَّ». أَجْعَلُ الْفِعْلَ مُجَرَّدًا.

نَشَاط (٦) : أُمَثِّلُ لِمَا يَأْتِي :
١. فِعْلٌ مَزِيدٌ بِحَرْفَيْنِ أَحَدُهُمَا التَّاءُ.
٢. فِعْلٌ رُبَاعِيٌّ مَزِيدٌ بِحَرْفَيْنِ أَحَدُهُمَا التَّضْعِيفُ.
٣. فِعْلٌ مُجَرَّدٌ رُبَاعِيٌّ.
٤. فِعْلٌ مَزِيدٌ بِحَرْفٍ وَاحِدٍ.
