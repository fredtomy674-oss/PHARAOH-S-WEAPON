الْقَوَاعِدُ النَّحْوِيَّةُ
( أَنْوَاعُ الْفِعْلِ الصَّحِيحِ )

أَقْرَأُ الْأَمْثِلَةَ الْآتِيَةَ، وَأَتَأَمَّلُ الْكَلِمَاتِ الْمُلَوَّنَةَ فِي كُلِّ مَجْمُوعَةٍ :

( أ )
• يَبْذُلُ الْمُجْتَهِدُ جُهْدَهُ كُلَّهُ.
• قَرَأْتُ كَثِيرًا حَتَّى أَصْبَحْتُ كَاتِبًا.
• هَدَّ شَبَابُنَا سُدُودَ الْيَأْسِ.

( ب )
• يَثِقُ النَّاشِئُ بِآرَاءِ النَّاصِحِينَ.
• زَادَ عَطَاءُ الشَّبَابِ.
• يَصِلُ الْمُثَابِرُ إِلَى مُرَادِهِ.

أَلَاحِظُ
• فِي الْمَجْمُوعَةِ الْأُولَى ( أ ) : أَنَّ الْأَفْعَالَ حُرُوفَهَا الْأَصْلِيَّةَ هِيَ (بَذَلَ - قَرَأَ - هَدَّ) فَهِيَ خَالِيَةٌ مِنْ أَحْرُفِ الْعِلَّةِ الثَّلَاثَةِ (الْأَلِفِ، وَالْوَاوِ، وَالْيَاءِ)؛ إِذَنْ فَهِيَ أَفْعَالٌ صَحِيحَةٌ.
• فِي الْمَجْمُوعَةِ الثَّانِيَةِ ( ب ) : أَنَّ الْأَفْعَالَ حُرُوفَهَا الْأَصْلِيَّةَ هِيَ (وَثَقَ - زَادَ - وَصَلَ)، فَفِي حُرُوفِهَا الْأَصْلِيَّةِ حَرْفٌ مِنْ حُرُوفِ الْعِلَّةِ؛ إِذَنْ فَهِيَ أَفْعَالٌ مُعْتَلَّةٌ.

أَقْرَأُ الْأَمْثِلَةَ التَّالِيَةَ، وَأَتَأَمَّلُ الْكَلِمَاتِ الْمُلَوَّنَةَ فِي كُلِّ مَجْمُوعَةٍ :

( أ )
• لَا يَجْهَلُ أَحَدٌ قِيمَةَ الْوَقْتِ.
• الْقِرَاءَةُ تَفْتَحُ آفَاقَ الْعَقْلِ.
• الشَّبَابُ يَصْنَعُونَ الْمَجْدَ.

( ب )
• يَأْمُرُ الْأَبُ أَبْنَاءَهُ بِالِاجْتِهَادِ.
• يَنْشَأُ الْمُجْتَهِدُ عَلَى حُبِّ الصِّدْقِ.
• نَسْأَلُ اللَّهَ تَوْفِيقًا فِي مُسْتَقْبَلِنَا.

( ج )
• أُحِبُّ قِرَاءَةَ كُتُبِ الْأَدَبِ.
• أَحَسَّ الشَّبَابُ بِقِيمَتِهِمْ فِي الْمُجْتَمَعِ.
• زَلْزَلَ شَبَابُنَا الْعَالَمَ بِاخْتِرَاعَاتِهِمْ.

أَلَاحِظُ
• فِي الْمَجْمُوعَةِ الْأُولَى ( أ ) : الْأَفْعَالُ (يَجْهَلُ - تَفْتَحُ - يَصْنَعُونَ) أَفْعَالٌ صَحِيحَةٌ لِأَنَّ حُرُوفَهَا الْأَصْلِيَّةَ خَالِيَةٌ مِنْ أَحْرُفِ الْعِلَّةِ، وَحُرُوفَهَا الْأَصْلِيَّةَ أَيْضًا خَالِيَةٌ مِنَ الْهَمْزَةِ وَالتَّضْعِيفِ؛ إِذَنْ فَهِيَ صَحِيحَةٌ سَالِمَةٌ.
• فِي الْمَجْمُوعَةِ الثَّانِيَةِ ( ب ) : الْأَفْعَالُ (يَأْمُرُ - يَنْشَأُ - نَسْأَلُ) أَفْعَالٌ صَحِيحَةٌ لِأَنَّ حُرُوفَهَا الْأَصْلِيَّةَ خَالِيَةٌ مِنْ أَحْرُفِ الْعِلَّةِ، وَأَحَدُ حُرُوفِهَا الْأَصْلِيَّةِ هَمْزَةٌ؛ إِذَنْ فَهِيَ صَحِيحَةٌ مَهْمُوزَةٌ.
• فِي الْمَجْمُوعَةِ الثَّالِثَةِ ( ج ) : الْفِعْلَانِ (أَحَبَّ - أَحَسَّ) فِعْلَانِ صَحِيحَانِ لِأَنَّ حُرُوفَهَا الْأَصْلِيَّةَ خَالِيَةٌ مِنْ أَحْرُفِ الْعِلَّةِ، وَحَرْفَيْهِمَا الثَّانِي وَالثَّالِثِ مِنْ جِنْسٍ وَاحِدٍ؛ إِذَنْ فَهُمَا صَحِيحَانِ مُضَعَّفَانِ ثُلَاثِيَّانِ، وَكَذَلِكَ الْفِعْلُ (زَلْزَلَ) حَرْفَاهُ الْأَوَّلُ وَالثَّالِثُ مِنْ جِنْسٍ وَاحِدٍ، وَالثَّانِي وَالرَّابِعُ مِنْ جِنْسٍ وَاحِدٍ؛ إِذَنْ فَهُوَ صَحِيحٌ مُضَعَّفٌ رُبَاعِيٌّ.

الْقَوَاعِدُ النَّحْوِيَّةُ ٦١
