النَّص
رَسَمْنَا عَلَى القَلْبِ وَجْهَ الوَطَنْ .. نَخِيلاً وَنِيلاً وَشَعْبًا أَصِيلاً
وَصُنَّاكَ يَا مِصْرُ طُولَ الزَّمَنْ .. لِيَبْقَى شَبَابُكِ جِيلاً فَجِيلاً
عَلَى كُلِّ أَرْضٍ تَرَكْنَا عَلامَةْ .. قِلاعًا مِنَ النُّورِ تَحْمِي الكَرَامَةْ
عُرُوبَتُنَا تَفْتَدِيكِ القُلُوب .. وَيَحْمِيكِ بِالدَّمِ جَيْشُ الكِنَانَةْ
وَتَنْسَابُ يَا نِيلُ حُرًّا طَلِيقًا .. لِتَحْكِي ضِفَافُكَ مَعْنَى النِّضَالْ
وَتَبْقَى مَدَى الدَّهْرِ حِصْنًا عَرِيقًا .. بِصِدْقِ القُلُوبِ وَعَزْمِ الرِّجَالْ
يَدُ اللهِ يَا مِصْرُ تَرْعَى سَمَاكِ .. وَفِي سَاحَةِ الحَقِّ يَعْلُو نِدَاكِ
وَمَا دَامَ جَيْشُكِ يَحْمِي حِمَاكِ .. سَتَمْضِي إِلَى النَّصْرِ دَوْمًا خُطَاكِ

كَلِمَاتِي الجَدِيدَةُ
أَصِيلاً : عَرِيقًا.
صُنَّاكَ : حَفِظْنَاكِ، وَحَمَيْنَاكِ، المِضَاد : ضَيَّعْنَاكِ.
تَفْتَدِيكِ : تُضَحِّي مِن أَجْلِكِ.
الكِنَانَةُ : وِعَاءُ السِّهَامِ، المُرَاد : مِصْر، الجَمْع : الكَنَائِن.
تَنْسَابُ : تَجْرِي.
ضِفَافُ : المُفْرَد : ضِفَّة.
النِّضَالُ : الكِفَاح.
حِمَاكِ : المُرَاد : أَرْضِكِ.
خُطَاكِ : المُفْرَد : خُطْوَة.

الدَّرْسُ الرَّابِعُ ٤١
